# Звёздный дракон

**Звёздный дракон** - особый босс Края, связанный с [Богом Космоса](/gods/6_cosm.md). Это альтернатива обычному Дракону Края: его можно призвать на острове, заблокировав портал выхода. Сражение проходит в **две фазы** - сперва игрок сталкивается с **4 пилонами**, каждый из которых хранит одну из **звёздных стихий** (огонь, вода, яд, гравитация), а затем в бой вступает сам Звёздный дракон.

::: info Важная информация
Сражение с Звёздным драконом - ключевой источник материалов для создания **[Звёздной брони](/guide/mechanics/star_armor.md)** и звездных мечей.
:::


## Призыв

Чтобы призвать Звёздного дракона, нужен предмет **«Звезда Апокалипсиса Эссенций»**.

### Крафт «Звезды Апокалипсиса Эссенций»

Крафтится из **4 кристаллов Края в форме плюса**, в центре - **звезда Ада**, а в **4 угловых слотах** - осколок призмарина, сгусток слизи, аметист и светопыль.

**Применение:**
- Предмет активируется **только в Краю**, лишь **около портала выхода** (на нулевых координатах).
- Активация призывает **подозрительное яйцо дракона** прямо на портал, **закрывая его**.
- Пока в радиусе **40 блоков** от яйца не появится игрок, босс-файт **не начнется**.

## Фаза 1: Пилоны

Как только игрок оказывается в радиусе **40 блоков** от подозрительного яйца, в текст выводится немного **лорной информации**, а затем в **4 точках острова** появляются **пилоны** - источники сил Космоса.

### Общие свойства пилонов

- Не атакуют игрока напрямую, но имеют вокруг себя **особую ауру** (у каждого пилона она разная).
- **Спавнят** рядом с собой **агрессивных монстров** (в виде кубиков).
- Пилоны **невозможно поразить стрелами**.
- При получении урона с **шансом** они **телепортируют игрока вдаль** от себя.

### Осколки и кольца яйца

- Каждый пилон после смерти **спавнит некоторое количество своих осколков** - они необходимы для создания **звёздной брони** и **звёздных мечей**.
- Яйцо в центре острова отображает вокруг себя **кольца** - **по 1 на каждый живущий пилон** (как только пилон погибает, кольцо исчезает).
- После уничтожения **всех 4 пилонов** яйцо через небольшую задержку **взлетает в воздух**, затем **взрывается** и призывает **Звёздного дракона**.

## Фаза 2: Звёздный дракон

После того как все пилоны сломаны, начинается главное сражение.

| Характеристика | Описание |
|:--------------|:---------|
| **Здоровье** | **600** ХП |
| **Аура** | **Циклично** (проходя через все варианты) активирует ауру **одного из пилонов** в самом центре острова |
| **Призыв мобов** | Там же, в центре, **призывает мобов** с каждого из пилонов |
| **Кристаллы Края** | Как только босс появляется (или его ХП достигает **50%** - один раз), он призывает на **каждой из башен** особый **кристалл Края** |

### Кристаллы Края

Кристаллы распространяют вокруг себя **ауру**, накладывающую на любого в зоне действия:

- ![Тьма](/assets/items/darkness.png) **Тьму**
- ![Слабость](/assets/items/weakness.png) **Слабость**

::: tip Совет
Сначала разрушьте кристаллы на башнях, чтобы убрать их негативную ауру, и только потом сосредоточьте урон на самом драконе.
:::

### После смерти

Умирая, Звёздный дракон:

- **Открывает портал из Края** (выход вновь становится доступным).
- Вместо обычного яйца **дропает подозрительное яйцо**.


## Подозрительное яйцо дракона

Подозрительное яйцо из фазы 2 - уникальный предмет с **двумя применениями**.

| Применение | Как использовать |
|:-----------|:----------------|
| **Мини-пилоны** | Скормить на ПКМ по **установленному яйцу**: стак светопыли / аметистовых блоков / блоков слизи / блоков призмарина |
| **Элементальный буран** | Соединить на верстаке с **2 осколками каждого вида** с пилонов |

### Мини-версии пилонов

На ПКМ по **установленному** подозрительному яйцу можно **скормить один стак**:

| Ресурс | Количество |
|:-------|:-----------|
| ![Светопыль](/assets/items/glowstone.png) Светопыль | 64 |
| ![Аметистовый блок](/assets/items/amethyst_block.png) Аметистовых блоков | 64 |
| ![Блок слизи](/assets/items/slime_block.png) Блоков слизи | 64 |
| ![Блок призмарина](/assets/items/prismarine.png) Блоков призмарина | 64 |

После этого создаются **мини-версии пилонов**.

### Элементальный буран

- **Крафт**: соединить на верстаке с **2 осколками каждого вида с пилонов** - получается **элементальный буран**.
- **Механика**: это **миниивент**, активируемый **только в Краю**.
- **Ход ивента**: во время бурана **волнами атакуют мобы с пилонов**.
- **Награда**: призываемые в ивенте мобы **дропают с шансом осколки своего пилона** - то есть это способ **пофармить осколки**, не сражаясь с драконом повторно.

::: warning Важно
После окончания буран с **шансом 50%** в его центре дропнется **подозрительное яйцо** (но может и не выпасть вовсе) - для возможного повторного использования.
:::
