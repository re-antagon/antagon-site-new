# Невидимые рамки

На сервере Re:Antagon можно сделать предметную рамку невидимой.

## Как сделать рамку невидимой

1. Возьмите в руку ![Ножницы](/assets/items/shears.png) **Ножницы**.
2. Нажмите **ПКМ** (правую кнопку мыши) по ![Предметная рамка](/assets/items/item_frame.png) **Предметной рамке**.
3. Рамка станет невидимой, а находящийся в ней предмет продолжит отображаться.
