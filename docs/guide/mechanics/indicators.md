# Зелья-индикаторы

На сервере Re:Antagon существует система **зелий-индикаторов** - специальных зелий, позволяющих узнать, какие игроки взаимодействовали с блоками в определенной области. Все зелья крафтятся на **верстаке**.

::: info Важно
Все зелья-индикаторы создаются на **верстаке**, а не в варочной стойке.
:::

---

## Общие сведения о взрывных индикаторах

Взрывные индикаторы - это готовые к применению зелья, которые при броске подсвечивают имена игроков, совершавших определенные действия в зоне поражения.

| Параметр | Значение |
|:---------|:--------:|
| Радиус действия | 15 блоков |
| Время действия подсветки | 10 секунд |
| Кулдаун на использование | 30 секунд |
| Окно учитываемых действий | не позднее чем 12 часов назад |

::: warning Важно
Взрывной индикатор учитывает только действия, совершенные **не позднее чем 12 часов** до момента броска зелья. Более старые действия не будут подсвечены.
:::

## Сводная таблица взрывных индикаторов

| Индикатор | Что подсвечивает |
|:----------|:-----------------|
| Синий | Игроков, **ставивших** блоки |
| Зеленый | Игроков, **ломавших** блоки |
| Розовый | Игроков, действовавших с **интерактивными блоками** |
| Красный | Игроков, **убивавших сущностей** |

::: tip Примечание
«Подозрительные» зелья (без приставки «взрывной») сами по себе не имеют эффекта - они являются полуфабрикатами. Добавление пороха (и, для синего/розового/красного, соответствующего ингредиента) превращает их во взрывные индикаторы, готовые к броску.
:::
