# Кастомные пластинки

На сервере Re:Antagon игроки могут добавлять **собственные музыкальные пластинки** (кастомные диски) с любой композицией. Вместо ванильных треков можно проигрывать свои файлы - для этого используются специальные команды `/cd`.

::: info Важно
Чтобы услышать кастомную пластинку, **обязательно требуется мод [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat/versions?g=1.21.11) версии 2.6.20**. Без мода звук воспроизводиться не будет.
:::

---

## Поддерживаемые форматы

Кастомные пластинки работают только с файлами следующих форматов:

- `.wav`
- `.flac`
- `.mp3`

::: warning Важно
Расширение в имени файла (`<filename.extension>`) **должно соответствовать реальному формату** загружаемого файла. Если назвать `.wav` файл как `.mp3` (или наоборот), произойдет ошибка загрузки.
:::

---

## Способы получения музыки

Существует два способа добавить музыку на сервер: по прямой ссылке (Direct URL) и через Google Drive.

### Direct URL

Подойдет **любая ссылка, которая при открытии в браузере сразу начинает скачивание файла**. То есть ссылка должна вести не на страницу прослушивания, а напрямую на сам аудиофайл.

Пример прямой ссылки:

```
https://example.com/mysong.mp3
```

### Google Drive

Ссылки Google Drive по умолчанию ведут на страницу просмотра, а не на скачивание. Чтобы получить прямую ссылку для скачивания, преобразуйте ее через сервис:

- **Google Drive Direct Download Link Generator**: https://lonedev6.github.io/gddl/

::: tip Совет
Скопируйте ссылку на общий доступ к файлу с Google Drive, вставьте в генератор выше и используйте полученную прямую ссылку в команде загрузки.
:::

## Команды

### Загрузка пластинки по ссылке

Скачивает аудиофайл по прямой ссылке на сервер:

```
/cd download "https://example.com/mysong.mp3" mysong.mp3
```

- Первый аргумент - **прямая ссылка** на файл в кавычках.
- Второй аргумент - **имя файла** с корректным расширением (`.wav`, `.flac` или `.mp3`).

### Выдача пластинки

Чтобы получить предмет-пластинку с загруженной музыкой, выполните команду, **держа в руке любую пластинку**:

```
/cd create LeviSctEndofSummertime.flac "test"
```

- Первый аргумент - имя ранее загруженного файла (с расширением).
- Второй аргумент (в кавычках) - **название/подпись** пластинки, которое будет отображаться на предмете.

::: info Как это работает
Команда берет музыку из загруженного файла и «записывает» ее на пластинку, которую вы держите в руке. В результате вы получаете кастомную пластинку с вашим треком и заданным названием.
:::

## Порядок действий (пошагово)

1. Подготовьте аудиофайл в формате `.wav`, `.flac` или `.mp3`.
2. Получите **прямую ссылку** на скачивание (Direct URL или через генератор Google Drive).
3. Загрузите файл на сервер: `/cd download "<ссылка>" <имя.расширение>`.
4. Возьмите в руку **любую пластинку**.
5. Создайте кастомную пластинку: `/cd create <имя.расширение> "<название>"`.
6. Установите [Simple Voice Chat](https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat) версии **2.6.20**, чтобы слышать звук.
