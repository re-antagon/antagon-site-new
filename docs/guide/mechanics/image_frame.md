# Мап арты со своими картинками

На сервере Re:Antagon игроки могут создавать **кастомные мап арты** - карты с собственными изображениями, загруженными по ссылке. Вместо рисования пиксель за пикселем в ванильном Minecraft, можно подгрузить любую картинку и разместить ее в рамках для предметов (item frames).

::: info Поддерживаемые форматы
Загружать можно изображения в следующих форматах:

- `PNG`
- `JPEG`
- `WEBP`
- `GIF`
:::

::: tip Откуда брать картинки
Изображения **загружаются по прямой ссылке (URL)**. Ссылка должна вести напрямую на файл изображения, а не на страницу просмотра.
:::

---

## Команды

Все команды используют префикс `/imageframe`.

### Создание нового мап арта

```
/imageframe create <name> <url> <width> <height>
```

Создает новую карту-изображение с заданным именем, загружает картинку по ссылке и задает ее размер в рамках (ширина × высота).

| Аргумент   | Описание                                                  |
|:-----------|:----------------------------------------------------------|
| `<name>`   | Уникальное имя мап арта (используется для повторного получения) |
| `<url>`    | Прямая ссылка на изображение (PNG, JPEG, WEBP или GIF)     |
| `<width>`  | Ширина мап арта в рамках                                  |
| `<height>` | Высота мап арта в рамках                                  |

### Создание и установка в выбранные рамки

```
/imageframe create <name> <url> selection
```

Создает новый мап арт и **сразу размещает** его в выбранных вами рамках для предметов. Удобно, когда вы уже подготовили область из рамок.

### Создание в виде Combined ImageMap

```
/imageframe create <name> <url> <width> <height> combined
```

Создает новый мап арт и выдает предмет **Combined ImageMap** - единый предмет, содержащий всю составную карту целиком.

### Получение ранее созданного мап арта

```
/imageframe get <name>
```

Получает ранее созданный вами мап арт по имени (выдается как набор карт для рук).

```
/imageframe get <name> selection
```

Помещает ранее созданный мап арт **напрямую в выбранные рамки** для предметов.

```
/imageframe get <name> combined
```

Получает ранее созданный мап арт в виде предмета **Combined ImageMap**.

::: info Что такое Combined ImageMap
Обычный мап арт большого размера состоит из множества отдельных карт, которые нужно расставить по рамкам вручную. Форма `combined` выдает **один предмет**, представляющий всю картину целиком, - это проще носить с собой и размещать.
:::

## Порядок действий (пошагово)

1. Подготовьте изображение в формате `PNG`, `JPEG`, `WEBP` или `GIF`.
2. Получите **прямую ссылку** на файл изображения (URL).
3. Расставьте рамки для предметов в нужной области (если планируете использовать режим `selection`).
4. Создайте мап арт: `/imageframe create <name> <url> <width> <height>` (или с `selection` / `combined`).
5. При использовании обычного режима - получите карты через `/imageframe get <name>` и разместите их в рамках.
6. При использовании `combined` - получите предмет через `/imageframe get <name> combined` и поставьте его в рамку.
