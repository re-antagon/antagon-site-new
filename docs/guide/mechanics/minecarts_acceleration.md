# Ускорение вагонеток от блока под рельсами

На сервере Re:Antagon блок, находящийся **под рельсами**, влияет на ускорение проезжающей по ним вагонетки. Механика работает только с **обычной вагонеткой**.

::: info Важно
Ускорение от блока под рельсами применяется **только к обычной вагонетке**. Другие типы вагонеток ускорение не получают.
:::


## Формула ускорения

Итоговое ускорение вагонетки считается по формуле:

```
ускорение = value * rail_type
```

Где:
- **`value`** - значение ускорения от **типа рельсы**:
  - Обычная рельса (rail): **1.0**
  - Рельса, запитанная редстоуном (powered rail): **1.2**
- **`rail_type`** - значение ускорения от **блока под рельсой** (см. таблицу ниже)

> Пример: медный блок (2.0) под обычной рельсой (1.0) дает ускорение `2.0 × 1.0 = 2.0`. Тот же блок под запитанной рельсой (1.2) даст `2.0 × 1.2 = 2.4`.

::: tip Примечание
Чем выше стадия окисления меди, тем **ниже** ее ускоряющий эффект. Вощение меди также немного уменьшает значение по сравнению с невощеной той же стадии. Максимальный эффект дает чистый/резной медный блок (2.0), минимальный из полезных - песок душ (0.2).
:::
