# Улучшение арбалета "Тройной выстрел"

На сервере Re:Antagon изменена механика работы зачарования **Тройной выстрел** (`Multishot`) на арбалетах.

В ванильном Minecraft при выстреле из арбалета в упор из 3 выпущенных стрел урон наносит только **одна** стрела, так как цель получает кадры неуязвимости (i-frames). На Re:Antagon урон от стрел одного залпа суммируется с адаптивными коэффициентами.

::: info Важно
Суммирование урона применяется **только к стрелам из одного залпа**. Кадры неуязвимости цели относительно других источников урона (мечи, магия, лава) не нарушаются.
:::


## Расчет суммарного урона

При попадании нескольких стрел одного залпа по одной и той же цели урон каждой последующей стрелы пересчитывается с понижающим коэффициентом:

| Попадание | Множитель урона | Накапливаемый суммарный урон |
|:----------|:---------------:|:----------------------------:|
| **1-я стрела** | ×1.0 (100%) | **1.0x** |
| **2-я стрела** | ×0.8 (80%) | **1.8x** |
| **3-я стрела** | ×0.9 (90%) | **2.7x** |

> **Пример:** Если базовый урон одной стрелы арбалета равен **10 HP**, то при выстреле в упор, когда все 3 стрелы попадают в одну цель:
> - 1-я стрела нанесет `10.0 HP`
> - 2-я стрела нанесет `8.0 HP`
> - 3-я стрела нанесет `9.0 HP`  
> **Итоговый урон за один выстрел составит 27.0 HP.**


## Зависимость от дистанции

Эффективность зачарования напрямую зависит от дистанции до цели:

- **В упор (в близком бою):** в цель попадают все 3 стрелы, нанося максимальный урон **2.7x** от базового.
- **На средней дистанции:** из-за веерного разлета в цель могут попасть 2 стрелы из 3, нанося суммарный урон **1.8x**.
- **На дальней дистанции:** в цель попадает 1 стрела, нанося стандартный урон **1.0x**.

::: tip Примечание
Эта механика делает арбалет с зачарованием «Тройной выстрел» мощным оружием ближнего боя, позволяя наносить сильный урон по одиночным крупным или близко расположенным целям.
:::
