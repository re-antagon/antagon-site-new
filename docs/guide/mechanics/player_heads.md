# Головы игроков при PVP

При победе над другим игроком в PVP-сражении вы получаете особый трофей.

## Механика

При убийстве игрока на сервере с него выпадает ![Голова](/assets/items/player_head.png) **Голова игрока** (с его скином и никнеймом).

Голову можно использовать в качестве декорации, трофея на вашей базе или элемента коллекционирования.
