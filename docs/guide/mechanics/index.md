# Механики

Раздел **Механики** содержит описание изменившихся или уникальных механик сервера Re:Antagon, обогащающих ванильное выживание.

::: tip Подсказка
Механики, заклинания и реликвии, принадлежащие конкретным Богам, вынесены в соответствующие **[Хабы Богов](/gods/)**.
:::
