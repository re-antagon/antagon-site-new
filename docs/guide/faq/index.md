# Часто задаваемые вопросы

Здесь собраны ответы на самые частые вопросы по серверу Re:Antagon.

::: info Как выбрать бога?
Для начала нужно найти алтарь нужного вам бога, после чего повзаимодействовать пустой рукой дважды.
:::

::: info Как сменить бога?
Невозможно выбрать покровителем иного Бога, пока не сброшен текущий. Существует предмет, который при использовании снимает с активировавшего его игрока выбранного им Бога-покровителя.
:::

::: info Что такое реферальная система?
Реферальная система - это система, которая награждает 9-ью антакоинами реферера за приглашение новых игроков на сервер. Для того, чтобы пригласить реферала нужно прописать команду `/link <ник_реферала>`, после чего необходимо, чтобы реферал принял приглашение нажав на `[ДА]` в чате в появившемся сообщении. Награда выдается автоматически сразу после того, как реферал отыграет 7 часов на сервере (время, проведенное в АФК не учитывается).
:::

::: info Что такое антакоины и где их взять?
Антакоины - это внутриигровая валюта сервера, необходимая для покупки косметики. Их можно получить, купив на [сайте](https://donate.antagon.su/), пригласив реферала на сервер и отыграть на сервере 7 часов, в ежедневных подарках на сервере и на [сайте](https://donate.antagon.su/).
:::
