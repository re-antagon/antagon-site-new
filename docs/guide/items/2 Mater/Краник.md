# Описание
**Краник** - инструмент Бога Естества, «индустриальное наследие». Используется для получения жидких компонентов из соответствующих источников. Для наполнения нужны пустые бутылки в инвентаре.

| Характеристика    | Значение             |
| ------------------ | -------------------- |
| Тип предмета       | Инструмент          |
| Активация          | При использовании    |
| Наполнение бутылок | 1                   |

---

## Эффект
При использовании (ПКМ) по подходящему источнику наполняет одну пустую бутылку в инвентаре жидким компонентом. Применяется для добычи берёзового сиропа, эфирного масла и сока древня.

## Использование
1. Положите пустые бутылки в инвентарь.
2. Возьмите Краник в руку.
3. Активируйте (ПКМ) по источнику - бутылка наполняется.
