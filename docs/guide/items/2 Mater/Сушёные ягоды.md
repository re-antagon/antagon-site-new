# Описание
**Сушёные ягоды** - кулинарный предмет Бога Естества, «у каждой девушки - свой изюм». Служит сушёным лакомством, выпариваемым из сладких ягод в печи. Восстанавливает небольшое количество голода и сытости.

| Характеристика        | Значение |
| ---------------------- | --------- |
| Тип предмета          | Кулинария |
| Восстановление голода | 1         |
| Восстановление сытости | 3       |
| Стакается             | Да        |

---

## Получение
Выпаривается в печи из сладких ягод.

- ![Сладкие ягоды](/assets/items/sweet_berries.png) Сладкие ягоды (в печи) → Сушёные ягоды
