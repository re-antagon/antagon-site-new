# Описание
**Штаны Садовника** - поножи Бога Естества, «в чужой огород со своим уставом». При сборе урожая дают дополнительный дроп (кроме семян).

| Характеристика            | Значение                              |
| ------------------------- | ------------------------------------- |
| Тип предмета             | Одежда (штаны)                      |
| Активация                | Ломание растения (культуры)         |
| Броня                    | 5 (железо)                         |
| Увеличение дропа        | 1 (кроме семян)                     |
| Радиус эффекта          | Целевой блок                        |
| Перезярядка             | Нет                                  |
| Совместимость с костюмом | Лёгкая броня                       |
| Зачаровываемое          | Да                                   |

---

## Эффект
При сборе любой выращенной культуры (растения) штаны автоматически добавляют +1 к дропу (кроме самих семян). Броня соответствует железной.

## Использование
1. Наденьте Штаны Садовника в слот поножей.
2. Ломайте выращенные растения - дополнительный дроп выпадает автоматически.

## Примечания
- Дополнительный дроп не касается семян, что удобно для массового сбора урожая.
