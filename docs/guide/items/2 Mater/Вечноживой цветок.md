# Описание
**Вечноживой цветок** - инструмент Бога Естества, «божественное соцветие». Чистит мицелий рядом и лечит окружающих при использовании.

| Характеристика    | Значение             |
| ------------------ | -------------------- |
| Тип предмета       | Инструмент          |
| Активация          | При использовании    |
| Перезарядка        | 8 с                  |
| Радиус эффекта    | 8 блоков            |
| Лечение            | 8 хп                 |


## Эффект
При использовании (ПКМ) очищает блоки мицелия в радиусе 8 блоков и восстанавливает 8 единиц здоровья (4 сердца) всем союзным существам вокруг.

## Использование
1. Возьмите цветок в руку.
2. Активируйте (ПКМ) - мицелий очищается, союзники лечатся.
3. Перезарядка 8 с.


## Получение
Выпадает из босса **Жизнепламень Силвы**. Не крафтится.

## Используется для
- [Посох природы](/guide/items/2%20Mater/Посох%20природы)

## Примечания
- Является компонентом для сборки [Посоха природы](/guide/items/2%20Mater/Посох%20природы).
- Дроп только с босса, что делает предмет ценным.


## Связанные предметы
- [Посох природы](/guide/items/2%20Mater/Посох%20природы) - требует Вечноживой цветок.
