# Описание
**Древесная броня** - полный сет брони Бога Естества, «из берёзовой коры». Свойства брони зависят от биома: в жарких биомах даёт бонус брони, в умеренных периодически лечит, в холодных снимает замедление. Везде удваивает урон от огня.

| Характеристика            | Значение                                  |
| ------------------------- | ----------------------------------------- |
| Тип предмета             | Одежда (полный сет)                     |
| Прочность               | не указано                                |
| Броня                    | 2 / 5 / 4 / 1 (шлем-нагрудник-штаны-ботинки) |
| Разрешена наковальня    | Нет                                       |
| Зачаровываемое          | Да                                        |
| Множитель огненного урона | 2                                      |
| Снятие эффектов        | замедление                                |
| Периодичность снятия    | 1 с                                       |
| Лечение                  | 1 (каждый элемент)                      |
| Периодичность лечения   | 15 с                                      |
| Увеличение брони        | 1 (каждый элемент)                      |

---

## Эффект
- **Жаркие биомы:** +1 к броне за каждый надетый элемент.
- **Умеренные биомы:** каждые 15 с лечит 1 ед. здоровья за каждый элемент.
- **Холодные биомы:** каждую секунду снимает эффект замедления.
- **Везде:** урон от огня удваивается (множитель 2).

## Использование
1. Наденьте полный сет (шлем, нагрудник, штаны, ботинки) из коры древня.
2. Эффекты срабатывают автоматически в зависимости от биома.

## Примечания
- Сет сильно зависит от биома: в холоде защищает от замедления, в жаре усиливает броню, в умеренном лечит.
- Удвоенный урон от огня делает сет опасным около лавы и огненных мобов.
- Нельзя починить на наковальне.
