# Описание
**Семена огнецвета** - расходник Бога Естества, «возрождённые из пепла». При использовании дают эффект огнестойкости.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При использовании |
| Наложение эффектов | Огнестойкость 1 |
| Время эффекта  | 90 сек |

---

## Эффект
При использовании (ПКМ) накладывает на владельца эффект огнестойкости I на 90 секунд, делая его невосприимчивым к урону огня и лавы.

## Использование
1. Возьмите Семена огнецвета в руку.
2. Активируйте (ПКМ) для получения огнестойкости.
3. Эффект длится 90 секунд.

---

## Примечания
- Даёт огнестойкость на 90 секунд - полезно при работе с лавой и огнём.
- Требует огненный заряд, что делает семена ресурсозатратными.
