# Описание
**Плащ Листьев** - накидка Бога Естества, «уже осень?». Даёт защиту владельцу, находящемуся в лесных биомах.

| Характеристика            | Значение            |
| ------------------------- | ------------------- |
| Тип предмета             | Одежда (плащ)    |
| Активация                | Пока надето         |
| Перезарядка             | 1 с                 |
| Радиус эффекта          | Себе                |
| Наложение эффектов      | Защита 1            |
| Зачаровываемое          | Да                  |
| Ограничение местности    | Только лес          |


## Эффект
Пока плащ надет и игрок находится в лесном биоме, каждую секунду на владельца накладывается эффект Защиты I. Вне леса эффект не действует.

## Использование
1. Наденьте Плащ Листьев в слот накидки (грудь).
2. Находитесь в лесном биоме - защита срабатывает автоматически.

## Примечания
- Защита действует только в лесных биомах, что делает плащ ситуативным.
- Совместим с элитрами как базовая накидка.
