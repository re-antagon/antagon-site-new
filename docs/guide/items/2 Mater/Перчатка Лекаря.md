# Описание
**Перчатка Лекаря** - инструмент Бога Естества, «полевой набор алхимика». При использовании накладывает на целевого моба или игрока эффект регенерации III.

| Характеристика    | Значение             |
| ------------------ | -------------------- |
| Тип предмета       | Инструмент          |
| Активация          | Использование        |
| Цель               | Целевой моб/игрок   |
| Перезарядка        | 3 с                  |
| Наложение эффектов | Регенерация 3        |



## Эффект
При использовании (ПКМ по цели) накладывает на выбранного моба или игрока эффект Регенерации III. Перезарядка между применениями - 3 секунды.

## Использование
1. Возьмите Перчатку Лекаря в руку.
2. Активируйте (ПКМ) по союзнику или себе.
3. Цель получает регенерацию III. Перезарядка 3 с.



## Получение
Крафтится из сока древня и бинтов:
