# Описание
**Сапоги Лесника** - ботинки Бога Естества, «экзоскелет "Леший"». Дают эффект скорости владельцу, находящемуся в лесных и равнинных биомах.

| Характеристика            | Значение                              |
| ------------------------- | ------------------------------------- |
| Тип предмета             | Одежда (ботинки)                    |
| Активация                | Пока надето                          |
| Броня                    | 2 (железо)                         |
| Радиус эффекта          | Себе                                 |
| Наложение эффектов      | Скорость 2                           |
| Ограничение местности    | Лесные и равнинные биомы            |
| Совместимость с костюмом | лёгкая броня                       |
| Зачаровываемое          | да                                    |

---

## Эффект
Пока сапоги надеты и игрок находится в лесном или равнинном биоме, на владельца накладывается эффект Скорости II. Вне этих биомов эффект не действует.

## Использование
1. Наденьте Сапоги Лесника в слот ботинок.
2. Находитесь в лесу или на равнине - скорость срабатывает автоматически.

## Примечания
- Скорость действует только в лесных и равнинных биомах, что делает сапоги ситуативными.
- Совместимы с лёгкой бронёй Бога Естества.
