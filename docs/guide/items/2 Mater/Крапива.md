# Описание
**Крапива** - компонент Бога Естества, «жжётся!». При взятии в руку наносит владельцу небольшой урон. Служит растительным компонентом для изготовления медовой мази.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активация       | При взятии в руку |
| Урон            | 1         |
| Радиус         | Себе      |
| Стакается       | Да        |



## Эффект
При взятии в руку наносит владельцу 1 единицу урона (половина сердца). Эффект мгновенный и действует только на себя.

## Использование
1. Возьмите крапиву в руку - получите 1 урон.
2. Используйте как компонент для крафта медовой мази.



## Получение
Выпадает с травы с шансом **3%** при ее разрушении.

- ![Трава](/assets/items/short_grass.png) Трава - источник крапивы (шанс 3%).

## Используется для
- [Медовая мазь](/guide/items/2%20Mater/Медовая%20мазь)

## Примечания
- Является неприятным в обращении компонентом: при ношении в руке жжёт владельца.
- Как компонент не обладает иным действием, кроме микроурона при взятии.



## Связанные предметы
