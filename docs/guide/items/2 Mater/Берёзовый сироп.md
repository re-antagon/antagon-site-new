# Описание
**Берёзовый сироп** - кулинарный предмет Бога Естества, «сахарозаменитель». Служит вторичным компонентом Жизни и добывается с берёзовых брёвен с помощью Краника. Сам по себе восстанавливает лишь сытость, не утоляя голод.

| Характеристика        | Значение |
| ---------------------- | --------- |
| Тип предмета          | Кулинария |
| Восстановление голода | 0         |
| Восстановление сытости | 10       |
| Стак                  | 1         |
| Остаётся бутылка     | Да        |
| Стакается             | Да        |

---

## Получение
Добывается ПКМ ![Краник](/assets/items/custom/big/kranik.png) [Краником](/guide/items/2%20Mater/Краник) по ![Берёзовое бревно](/assets/items/birch_log.png) берёзовому бревну (требуется пустая бутылка в инвентаре). После наполнения бутылка остаётся.

## Используется для
_Не используется в других рецептах (вторичный компонент Жизни)._

## Примечания
- Восстанавливает только сытость (10), голод не трогает.
- После использования бутылка возвращается в инвентарь.
- Требует Краник и пустую бутылку для добычи.
