# Описание
**Клубок корней** - расходник Бога Естества, «√‾‾‾‾‾‾‾‾». При использовании опутывает корнями всех существ вокруг, обездвиживая их.

| Характеристика  | Значение      |
| ----------------- | -------------- |
| Тип предмета     | Расходник      |
| Активация         | При использовании |
| Длительность      | 6 с            |
| Перезарядка       | 15 с           |
| Радиус эффекта   | 8 блоков       |
| Наложение эффектов | Оплетание    |

---

## Эффект
При использовании (ПКМ) накладывает на всех существ в радиусе 8 блоков эффект оплетания (обездвиживание) на 6 секунд. Перезарядка - 15 секунд.

## Использование
1. Возьмите Клубок корней в руку.
2. Активируйте (ПКМ) для опутывания врагов корнями.
3. Ждите перезарядки 15 с.

---
