# Описание
**Полотно** - компонент Бога Естества, «вдоль и поперёк». Служит тканым полотном для изготовления бинтов и деталей лёгкой брони. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |

## Используется для
- Плащ Полководца
- [Бинты](/guide/items/2%20Mater/Бинты)
- Лёгкая броня

## Примечания
- Базовый тканый материал лёгкой брони и перевязочных средств Бога Естества.
- Как компонент не обладает собственным действием.
