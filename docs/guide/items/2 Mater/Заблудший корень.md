# Описание
**Заблудший корень** - кулинарный предмет Бога Естества, «обед спелеолога». Служит съедобным корнем, добываемым из светящегося лишайника. Сам по себе не обладает активным эффектом и используется как сырьё для крафта скрытого мха, клубка корней и корней водного кустарника.

| Характеристика | Значение |
| -------------- | --------- |
| Тип предмета   | Кулинария |
| Активный эффект | Нет      |
| Стакается      | Да        |

---

## Получение
Выпадает из ![Светящийся лишайник](/assets/items/glow_lichen.png) Светящегося лишайника без зачарования «Шёлковое касание» (при обычной добыче).

## Используется для
- [Кусочек скрытого мха](/guide/items/2%20Mater/Кусочек%20скрытого%20мха)
- [Клубок корней](/guide/items/2%20Mater/Клубок%20корней)
- ![Корни водного кустарника](/assets/items/custom/big/aqua_root.png) [Корни водного кустарника](/guide/items/6%20Cosm/Корни%20водного%20кустарника)

## Примечания
- Съедобный, но применяется преимущественно как компонент крафтов Бога Естества.
- Как компонент не обладает собственным действием.
