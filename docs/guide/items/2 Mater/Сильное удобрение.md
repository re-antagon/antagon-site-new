# Описание
**Сильное удобрение** - расходник Бога Естества, «иногда вопросы решаются количеством». Выращивает растения в небольшой области вместо одного.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При использовании |
| Наложение эффектов | Костная мука |
| Радиус          | 2 блока |

---

## Эффект
При использовании (ПКМ) применяет эффект костной муки сразу к нескольким растениям в радиусе 2 блоков, мгновенно выращивая их.

## Использование
1. Возьмите Сильное удобрение в руку.
2. Активируйте (ПКМ) по растениям.
3. Все растения в радиусе 2 блоков вырастают.
