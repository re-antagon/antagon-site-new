# Описание
**Древесное волокно** - компонент Бога Естества, «перекати-поле». Служит растительным волокном для изготовления тканей и деталей лёгкой брони. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |



## Получение
Выпадает при убийстве [Древня](/guide/items/2%20Mater/Древень) мечом (без шёлкового касания).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/guide/items/2%20Mater/Древень) - источник волокна при убийстве мечом.

## Используется для
- Нить
- [Сапоги Лесника](/guide/items/2%20Mater/Сапоги%20Лесника)
- [Полотно](/guide/items/2%20Mater/Полотно)

## Примечания
- Базовый материал лёгкой брони и тканей Бога Естества.
- Как компонент не обладает собственным действием.



## Связанные предметы
- [Древень](/guide/items/2%20Mater/Древень) - моб, с которого добывается волокно.
- [Сапоги Лесника](/guide/items/2%20Mater/Сапоги%20Лесника) - требует Древесное волокно.
- [Полотно](/guide/items/2%20Mater/Полотно) - требует Древесное волокно.
