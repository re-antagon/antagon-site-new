# Описание
**Опасное удобрение** - расходник Бога Естества, «а иногда не решаются». Уничтожает растения в небольшой области вместо их выращивания.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При использовании |
| Уничтожение    | Культуры |
| Радиус          | 2 блока |


## Эффект
При использовании (ПКМ) уничтожает все растения и культуры в радиусе 2 блоков. В отличие от обычного удобрения, действует во вред посадкам.

## Использование
1. Возьмите Опасное удобрение в руку.
2. Активируйте (ПКМ) по растениям для их уничтожения.
3. Растения в радиусе 2 блоков исчезают.
