# Описание
**Кора древня** - компонент Бога Естества, «жизненный проводник». Служит прочным растительным материалом для сборки древесной брони и посоха природы. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |

---

## Получение
Выпадает с [Древня](/guide/items/2%20Mater/Древень) при убийстве топором (без шёлкового касания).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/guide/items/2%20Mater/Древень) - источник коры при убийстве топором.

## Используется для
- [Посох природы](/guide/items/2%20Mater/Посох%20природы)
- [Древесная броня](/guide/items/2%20Mater/Древесная%20броня)

## Примечания
- Прочный базовый материал древесной брони и посоха Бога Естества.
- Как компонент не обладает собственным действием.
