# Описание
**Кусочек скрытого мха** - расходник Бога Естества, «ты меня видишь?». При использовании накладывает минутную невидимость с частицами падающих спор.

| Характеристика  | Значение          |
| ----------------- | ----------------- |
| Тип предмета      | Расходник         |
| Активация         | При использовании  |
| Наложение эффектов | Скрытность, 60 с |



## Эффект
При использовании (ПКМ) накладывает на владельца эффект скрытности (невидимости) на 60 секунд. Во время действия вокруг персонажа появляются падающие споры, обозначающие маскировку.

## Использование
1. Возьмите Кусочек скрытого мха в руку.
2. Активируйте (ПКМ) для получения невидимости.
3. Эффект длится 60 секунд.



## Получение
Крафтится из пятна тени и заблудшего корня:

## Примечания
- Даёт полную невидимость на 60 секунд, но споры выдают местоположение.
- Требует заблудший корень, добываемый из светящегося лишайника.
