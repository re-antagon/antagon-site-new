# Описание
**Древень** - моб Бога Естества, «живое древо». Служит источником уникальных компонентов: коры, сока, вечнозелёного листа и древесного волокна. При взаимодействии с разными инструментами даёт различные материалы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип сущности   | Моб      |
| Активный эффект | Нет   |
| Источник компонентов | Да |


## Добыча компонентов
В зависимости от используемого инструмента Древень даёт разные материалы:

- **Кора древня** - дроп при убийстве топором.
- **Сок древня** - добывается [Краником](/guide/items/2%20Mater/Краник) (ПКМ по Древню при наличии пустой бутылки).
- **Вечнозелёный лист** - состригается ножницами.
- **Древесное волокно** - дроп при убийстве мечом.
