# Описание
**Вечнозелёный лист** - компонент Бога Естества, «линия жизни». Служит базовым растительным материалом для множества предметов Бога Естества. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |

---

## Получение
Состригается с [Древня](/guide/items/2%20Mater/Древень) ножницами (ПКМ по мобу с ножницами в руке).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/guide/items/2%20Mater/Древень) - источник листьев при состригании ножницами.

## Используется для
- [Чаша Здравия](/guide/items/2%20Mater/Чаша%20Здравия)
- [Плащ Листьев](/guide/items/2%20Mater/Плащ%20Листьев)
- [Венец Цветения](/guide/items/2%20Mater/Венец%20Цветения)

## Примечания
- Базовый растительный компонент, без которого невозможно собрать броню, головной убор и защитную чашу Бога Естества.
- Как компонент не обладает собственным действием.
