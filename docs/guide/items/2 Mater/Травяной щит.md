# Описание
**Травяной щит** - инструмент Бога Естества. При взмахе даёт владельцу регенерацию, расходуя прочность предмета.

| Характеристика  | Значение       |
| ----------------- | -------------- |
| Тип предмета     | Инструмент    |
| Активация        | При использовании |
| Перезарядка      | -              |
| Наложение эффектов | Регенерация 2 (15 с) |
| Прочность        | 336            |
| Расход прочности | 5 за взмах    |

---

## Эффект
При взмахе (ПКМ) накладывает на владельца эффект Регенерации II на 15 секунд. Каждый взмах расходует 5 единиц прочности (всего 336). Когда прочность заканчивается, щит ломается.

## Использование
1. Возьмите Травяной щит в руку.
2. Взмахните (ПКМ) для получения регенерации.
3. Следите за прочностью - каждый взмах тратит 5 единиц.

---

## Получение
Выпадает с босса Силвы. Не крафтится.

## Используется для
_Не используется в других рецептах._

## Примечания
- Даёт сильную регенерацию (II на 15 с) за счёт прочности.
- Прочность 336 позволяет сделать около 67 взмахов.

---

## Связанные предметы
_Нет._
