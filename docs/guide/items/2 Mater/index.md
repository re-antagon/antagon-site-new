# Бог Естества

Предметы **Бога Естества** - уникальные инструменты, броня, оружие, расходники и компоненты сервера Re:Antagon. Механика Бога Естества строится вокруг жизни, природы и лесов: от выращивания культур через [Сильное удобрение](/guide/items/2%20Mater/Сильное%20удобрение) до лечения союзников [Перчаткой Лекаря](/guide/items/2%20Mater/Перчатка%20Лекаря) и призыва водных существ [Чёрным веером](/guide/items/2%20Mater/Чёрный%20веер).

::: info Сводка
Всего предметов: **41**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
