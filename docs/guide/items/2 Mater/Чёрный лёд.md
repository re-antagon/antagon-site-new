# Описание
**Чёрный лёд** - расходник Бога Естества, «призывалка Бурана». При использовании запускает систему сражения из нескольких усложняющихся волн (Буран). Мобы, появляющиеся в Буране, дропают [Снежки с ледышкой](/guide/items/2%20Mater/Снежок%20с%20ледышкой), а по итогу всех волн гарантированно выпадает [Сосулька](/guide/items/2%20Mater/Сосулька) - меч Бога Естества, при атаках накладывающий заморозку и медлительность.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Расходник |
| Активный эффект | Призыв Бурана (волны мобов) |



## Эффект: Буран

При использовании (ПКМ) в указанной точке мира призывается **Буран** - область боевого события радиусом **50 блоков**. Внутри бурана:

- Повсюду спавнится большое количество **снежных частиц**;
- На игрока накладывается эффект **слепоты** (затрудняет ориентацию);
- По волнам спавнятся монстры. **Чем дальше волна, тем больше врагов и тем они сильнее.**

### Эпицентр Бурана

В центре бурана находится его **эпицентр**:

- При взаимодействии (ПКМ) с эпицентром отображается, **сколько врагов осталось** в текущей волне.
- При ударе по эпицентру **все существа текущей волны перемещаются к эпицентру** - удобно для сбора мобов в одну точку.

### Награда

После прохождения **всех волн** гарантированно выпадает [Сосулька](/guide/items/2%20Mater/Сосулька) - меч Бога Естества, при атаках накладывающий на цель эффекты **заморозки и медлительности**.

::: info Дополнительный дроп
Мобы Бурана также дропают [Снежки с ледышкой](/guide/items/2%20Mater/Снежок%20с%20ледышкой).
:::



## Мобы Бурана

| Моб | Описание |
|:----|:---------|
| **Песцы** | Белые быстрые лисы. Атакуют в **ближнем бою**. |
| **Ледовики** | Снеговики, кидаются снежками, наносящими урон. Действуют аналогично эффекту расходника-артефакта [«Снежок с ледышкой»](/guide/items/2%20Mater/Снежок%20с%20ледышкой). |
| **Замороженные зомби** | Обычные зомби с куском льда на голове. Атаками накладывают дебаффы (в частности, ослабление). |
| **Замороженные скелеты** (зимогоры) | Зимогоры с куском льда на голове. Выстрелами накладывают **ослабление**, а сами по себе (как зимогоры) - **замедление**. |
| **Криомант** | **Минибосс** события. Атакует как замороженные скелеты, но в радиусе **5 блоков** вокруг себя имеет **дамажащую морозную ауру**. Если у него остаётся **меньше половины здоровья**, может сколдовать **Ледниковый период** - мощную атаку по площади радиусом **30 блоков**. |

::: warning Осторожно
Ледниковый период Криоманта бьёт по огромной площади (30 блоков). При падении его здоровья ниже 50% держите дистанцию или укрытие.
:::



## Использование
1. Возьмите Чёрный лёд в руку.
2. Активируйте (ПКМ) в нужной точке для запуска Бурана.
3. Справляйтесь с волнами мобов, ориентируясь по эпицентру.
4. Пройдите все волны - в награду получите [Сосульку](/guide/items/2%20Mater/Сосулька).

## Примечания
- Является ключевым предметом ледяного цикла Бога Естества: без него нельзя запустить Буран и получить Сосульку.
- Как расходник не обладает собственным постоянным действием.



## Связанные предметы
- [Чёрный веер](/guide/items/2%20Mater/Чёрный%20веер) - требует Чёрный лёд для крафта.
- [Сосулька](/guide/items/2%20Mater/Сосулька) - награда за прохождение всех волн Бурана (меч с заморозкой и медлительностью).
- [Снежок с ледышкой](/guide/items/2%20Mater/Снежок%20с%20ледышкой) - дроп мобов Бурана.
