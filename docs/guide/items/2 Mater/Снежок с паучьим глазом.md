# Описание
**Снежок с паучьим глазом** - расходник Бога Естества, «воздушно-капельный токсин». При попадании в цель накладывает эффект отравления.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При попадании |
| Наложение эффектов | Отравление (урон ?) |

---

## Эффект
При попадании в моба или игрока накладывает эффект отравления. Точные уровень и длительность не задокументированы (отмечено как «?» в исходных данных).

## Использование
1. Возьмите снежок в руку.
2. Бросьте (ПКМ) в цель.
3. При попадании цель получает отравление.
