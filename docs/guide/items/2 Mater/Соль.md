# Описание
**Соль** - кулинарный предмет Бога Естества, «рассыпая кличи беду». Служит кристаллической солью, выпариваемой из воды в печи. Сама по себе не обладает активным эффектом и используется как сырьё для крафта солёного снежка и прочной кожи.

| Характеристика | Значение |
| -------------- | --------- |
| Тип предмета   | Кулинария |
| Активный эффект | Нет      |
| Стакается      | Да        |

---

## Получение
Выпаривается в печи из ведра воды (ведро остаётся в инвентаре).

- ![Ведро воды](/assets/items/water_bucket.png) Ведро воды (в печи) → Соль + ведро

## Используется для
- [Солёный снежок](/guide/items/2%20Mater/Солёный%20снежок)
- Прочная кожа

## Примечания
- Выпаривается из воды, ведро при этом сохраняется.
- Как компонент не обладает собственным действием.
