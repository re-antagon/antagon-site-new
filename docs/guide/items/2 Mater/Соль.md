# Описание
**Соль** - кулинарный предмет Бога Естества, «рассыпая кличи беду». Служит кристаллической солью, выпариваемой изо льда в печи. Сама по себе не обладает активным эффектом и используется как сырьё для крафта солёного снежка и прочной кожи.

| Характеристика | Значение |
| -------------- | --------- |
| Тип предмета   | Кулинария |
| Активный эффект | Нет      |
| Стакается      | Да        |


## Получение
Выпаривается в печи изо льда (любого).

- <span class="ice-cycle"></span> Лед (любой, в печи) → ![соль](/assets/items/custom/big/salt.png) Соль

## Используется для
- [Солёный снежок](/guide/items/2%20Mater/Солёный%20снежок)
- Прочная кожа

## Примечания
- Выпаривается изо льда.
- Как компонент не обладает собственным действием.


## Связанные предметы
- [Солёный снежок](/guide/items/2%20Mater/Солёный%20снежок) - требует Соль.
- Прочная кожа - требует Соль.
