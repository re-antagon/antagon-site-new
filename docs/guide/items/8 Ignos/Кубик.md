# Описание
Случайный эффект
1: урона
2: иссушение и отравление (и всем вокруг!)
3: горение
4: левитация
5: щит
6: полное лечение

| Активация   | при использовании                                                  |
| ----------- | ------------------------------------------------------------------ |
| Перезарядка | 10с                                                                |
| Особое      | использует один из шести эффектов                                  |
| Эффект 1    | иссушение 1 10c, отравление 1 10с (себе и всем в радиусе 5 блоков) |
| Эффект 2    | горение (себе)                                                     |
| Эффект 3    | левитация 10с (себе)                                               |
| Эффект 4    | 4 щита (себе, макс. 20)                                            |
| Эффект 5    | х2 урон при ударах 10с                                             |
| Эффект 6    | лечение 20 (себе)                                                  |
