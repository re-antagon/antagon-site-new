# Описание
**Проклятая кость** - компонент Бога Искажения, «кто нажал красную кнопку?!». Служит проклятым костяным материалом, выпадающим с личей и визер-скелетов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

## Получение
Падает с **личей** и **визер-скелетов**.
