# Описание
**Полая кость** - компонент Бога Искажения, «шкала HP». Наполняется при убийстве в ближнем бою. При полной прочности превращается в Кость с кровью.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активация      | При убийстве, при удержании |
| Перезарядка    | - |
| Особое         | Чинит себя |
| Восстановление прочности | 1 от мобов, 16 от игроков |
| При полной прочности | Превращается в Кость с кровью |
| Стакается      | Нет |


## Эффект
При убийстве в ближнем бою кость восстанавливает прочность: **+1** за моба, **+16** за игрока. При полной прочности превращается в **Кость с кровью** - наполненный вариант, используемый в крафтах.

## Использование
1. Держите кость в инвентаре.
2. Убивайте мобов и игроков в ближнем бою.
3. При полной прочности кость наполнится кровью.
