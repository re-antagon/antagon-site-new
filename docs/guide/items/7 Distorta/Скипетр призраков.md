# Описание
**Скипетр призраков** - инструмент Бога Искажения, «армия прошлого». Тратит 3 проклятых кости при использовании. Призывает скелета-лучника или зомби, случайно, на минуту.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Расход         | 3 проклятых кости |
| Призыв         | Скелет-лучник или зомби (случайно) |
| Время жизни    | 1 минута |


## Эффект
При использовании (ПКМ) тратит **3 проклятых кости** из инвентаря и призывает случайного скелета-лучника или зомби на 1 минуту.

## Использование
1. Возьмите скипетр в руку.
2. Имейте 3 проклятых кости в инвентаре.
3. Активируйте (ПКМ) - призовётся нежить на 1 минуту.
