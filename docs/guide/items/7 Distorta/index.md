# Бог Искажения

Предметы **Бога Искажения** - уникальные инструменты, оружие, броня, расходники и компоненты сервера Re:Antagon. Механика Бога Искажения строится вокруг крови, договоров, проклятий и жертв: от кровавых свечей, расходующих здоровье владельца, до договоров, связывающих игроков между собой, и тотемов, меняющих саму суть боя.

::: info Сводка
Всего предметов: **27**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
