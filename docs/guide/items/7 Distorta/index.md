# Бог Искажения

Предметы **Бога Искажения** (Distorta) — уникальные инструменты, оружие, броня, расходники и компоненты сервера Re:Antagon. Механика Бога Искажения строится вокруг крови, проклятий, жертвоприношений, костей, свечей и заменяющих договоров.

::: info Сводка
Всего предметов: **27**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
