# Описание
При использовании рядом с игроком с таким же договором, связывает эффектом
При получении урона лечит другого игрока


| Активация          | при использовании    |
| ------------------ | -------------------- |
| Перезарядка        | 5мин                 |
| Радиус эффекта     | 4 блока + себе       |
| Наложение эффектов | Договор Ремонта 5мин |
Договор Ремонта:

| Активация              | при уроне                                               |
| ---------------------- | ------------------------------------------------------- |
| Радиус эффекта         | связанный игрок                                         |
| Лечение                | 50% от полученного урона                                |
| Прекращение эффекта    | при потере Договора Замены одним из игроков             |
| При завершении эффекта | даёт Незавершённый договор, уничтожение Договор Ремонта |
