# Описание
**Договор Ремонта** - инструмент Бога Искажения, «хардкор-переработка». При использовании рядом с игроком, держащим такой же договор, связывает обоих эффектом. При получении урона лечит другого игрока.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 5 мин |
| Радиус эффекта | 4 блока + себе |
| Наложение эффектов | Договор Ремонта, 5 мин |

---

## Эффект: Договор Ремонта

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При уроне |
| Радиус эффекта | Связанный игрок |
| Лечение        | 50% от полученного урона |
| Прекращение эффекта | При потере Договора Замены одним из игроков |
| При завершении эффекта | Даёт Незавершённый договор, уничтожение Договора Ремонта |

## Использование
1. Возьмите договор в руку.
2. Активируйте (ПКМ) рядом с игроком, держащим такой же договор - вы свяжетесь эффектом.
3. При получении урона связанный игрок лечится на 50% от него.
