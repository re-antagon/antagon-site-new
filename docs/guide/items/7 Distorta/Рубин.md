# Описание
**Рубин** - компонент Бога Искажения, «он всё ещё зелёный».

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |


## Получение
С шансом 5% выпадает при убийстве жителей.
