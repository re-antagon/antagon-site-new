# Описание
**Свеча Добычи** - расходник Бога Искажения, «так и манит». Ненадолго даёт мощную спешку. Цена: 2 сердца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Расход хп на использование | 4 |
| Радиус эффекта | Себе |
| Наложение эффекта | Спешка III, 10 с |
| Размер стака   | 64 |

---

## Эффект
При использовании (ПКМ) накладывает на владельца эффект **Спешки III** на 10 секунд. Использование стоит **4 хп** (2 сердца).

## Использование
1. Возьмите свечу в руку.
2. Активируйте (ПКМ) - получите мощную спешку на 10 с.
