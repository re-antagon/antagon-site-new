# Описание
**Сгусток крови** - компонент Бога Искажения, «один из сотни». Служит кровавым материалом, попадающим в инвентарь при попадании снаряда лужи крови в игрока.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |


## Получение
Попадает в инвентарь при попадании снаряда [Лужи крови](/guide/items/7%20Distorta/Лужа%20крови) в игрока.
