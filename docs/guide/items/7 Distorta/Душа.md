# Описание
**Душа** - компонент Бога Искажения, «не этично». Служит духовным материалом, выпадающим из тихони. Используется для крафта оружия и плащей Бога Искажения.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

## Получение
Падает с **эллея**.
