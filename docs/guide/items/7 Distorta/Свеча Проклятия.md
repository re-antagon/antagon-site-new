# Описание
Накладывает Проклятие по области
При любом действии наносит урон, также увеличивает входящий урон
Цена: 2 сердца

| Активация                  | при использовании |
| -------------------------- | ----------------- |
| Перезарядка                | -                 |
| Расход хп на использование | 4                 |
| Радиус эффекта             | 5 блоков + себе   |
| Наложение эффекта          | Проклятие 20с     |
| Размер стака               | 64                |
Проклятие:

| Активация      | при использовании, при взмахе, при уроне |
| -------------- | ---------------------------------------- |
| Радиус эффекта | себе                                     |
| Урон           | 1 (неблокируемый)                        |
