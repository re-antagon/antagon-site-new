# Описание
**Красная броня** - броня Бога Искажения, «целиком не стоит того». При получении урона иногда призывает лужи крови.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Активация      | При ношении, при уроне |
| Перезарядка    | Нет |
| Шанс активации | 5% (каждый компонент) |
| Особое         | Спавнит Лужу крови |
| Основа         | Алмаз |


## Эффект
При получении урона каждый надетый элемент брони с шансом **5%** призывает ![Лужа крови](/assets/items/custom/big/blood_ball.png) [Лужу крови](/guide/items/7%20Distorta/Лужа%20крови). Чем больше элементов надето, тем выше суммарный шанс. Броня соответствует алмазной.

## Использование
1. Наденьте один или несколько элементов брони.
2. При получении урона есть шанс призыва лужи крови.
