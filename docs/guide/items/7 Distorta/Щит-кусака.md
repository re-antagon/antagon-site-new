# Описание
**Щит-кусака** - предмет Бога Искажения, «Милый котик». При активации даёт эффект Возмездие

| Активация            | при использовании |
| -------------------- | ----------------- |
| Радиус эффекта       | себе              |
| Длительность эффекта | 5с                |
| Наложение эффектов   | возмездие         |
| Активация                     | при уроне        |
| ----------------------------- | ---------------- |
| Радиус эффекта                | атакующий        |
| Урон                          | входящий урон*2  |
| Отмена входящего урона        | да               |
| Урон(себе)                    | 3(неблокируемый) |
| Срабатывание от урона пустоты | нет              |
