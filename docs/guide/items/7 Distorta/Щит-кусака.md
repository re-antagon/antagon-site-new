# Описание
**Щит-кусака** - оружие Бога Искажения, «милый котик». При активации даёт эффект Возмездие.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (щит) |
| Активация      | При использовании |
| Радиус эффекта | Себе |
| Длительность эффекта | 5 с |
| Наложение эффектов | Возмездие |

---

## Эффект: Возмездие

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При уроне |
| Радиус эффекта | Атакующий |
| Урон           | Входящий урон × 2 |
| Отмена входящего урона | Да |
| Урон (себе)    | 3 (неблокируемый) |
| Срабатывание от урона пустоты | Нет |

## Использование
1. Возьмите щит-кусака в руку.
2. Активируйте (ПКМ) - получите эффект Возмездие на 5 с.
3. При получении урона атакующий получит двойной урон, но вы тоже пострадаете.
