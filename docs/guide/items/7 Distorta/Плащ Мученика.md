# Описание
**Плащ Мученика** - броня Бога Искажения, «незаслуженное спасение». Компенсирует часть урона в виде щита.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | При ношении, при уроне |
| Получаемый щит | 50% урона |


## Эффект
При получении урона плащ компенсирует **50%** полученного урона в виде щита (абсорбции).

## Использование
1. Наденьте плащ в слот нагрудника.
2. При получении урона часть его превращается в щит.
