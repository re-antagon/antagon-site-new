# Описание
**Клинок Безмолвия** - оружие Бога Искажения, «гниющая рана». Эффективен против раненых противников: наносит дополнительный урон за каждые 10% недостающего здоровья цели.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | При ударе |
| Перезарядка    | - |
| Добавочный урон | 1 за каждые 10% недостающих хп цели |
| Прочность      | Незеритовый меч |
| Урон           | 5 |

---

## Эффект
При ударе наносит базовый урон 5, плюс дополнительный урон, зависящий от здоровья цели: **+1 за каждые 10% недостающих хп**. Чем раненнее цель, тем сильнее удар.

## Использование
1. Возьмите клинок в руку.
2. Атакуйте цель - урон растёт с потерей здоровья цели.
