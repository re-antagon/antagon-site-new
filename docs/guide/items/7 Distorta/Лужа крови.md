# Описание
**Лужа крови** - моб Бога Искажения. Через 10 секунд после спавна запускает самонаводящийся снаряд в призвавшего её игрока, после чего умирает.

| Характеристика | Значение |
| -------------- | -------- |
| Тип сущности   | Моб |
| Хп             | 1 |
| Активация      | 10 с после спавна |
| Особое         | Запускает снаряд в призвавшего лужу и умирает |
| Пронзание снаряда | Блоки |
| Самонаведение снаряда | Да |
| Эффект при попадании в призвавшего | Лечение 4, даёт Сгусток крови в инвентарь |
| Эффект при попадании в моба/игрока | Урон 4 |

---

## Эффект
Через 10 секунд после спавна лужа крови запускает самонаводящийся снаряд в игрока, который её призвал. Снаряд пронзает блоки.

- **При попадании в призвавшего:** лечит его на 4 хп и кладёт ![Сгусток крови](/assets/items/custom/big/blood_ball.png) [Сгусток крови](/guide/items/7%20Distorta/Сгусток%20крови) в инвентарь.
- **При попадании в другого моба/игрока:** наносит 4 урона.
