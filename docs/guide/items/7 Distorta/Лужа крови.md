# Описание
**Лужа крови** - предмет Бога Искажения. 

| Хп                                 | 1                                             |
| ---------------------------------- | --------------------------------------------- |
| Активация                          | 10с после спавна                              |
| Особое                             | запускает снаряд в призвавшего лужу и умирает |
| Пронзание снаряда                  | блоки                                         |
| Самонаведение снаряда              | да                                            |
| Эффект при попадания в призвавшего | лечение 4, даёт Сгусток крови в инвентарь     |
| Эффект при попадании в моба/игрока | урон 4                                        |
