# Описание
**Договор Замены** - предмет Бога Искажения, «Немного не в себе». При использовании рядом с игроком с таким же договором, связывает эффектом При повторном использовании меняет местами

| Активация          | при использовании   |
| ------------------ | ------------------- |
| Перезарядка        | 5мин                |
| Радиус эффекта     | 4 блока + себе      |
| Наложение эффектов | Договор Замены 5мин |
| Активация              | при использовании Договор Замены                        |
| ---------------------- | ------------------------------------------------------- |
| Радиус эффекта         | связанный игрок                                         |
| Особое                 | меняет игроков местами                                  |
| Прекращение эффекта    | при потере Договора Замены одним из игроков             |
| При завершении эффекта | даёт Незавершённый договор, уничтожение Договор Ремонта |
