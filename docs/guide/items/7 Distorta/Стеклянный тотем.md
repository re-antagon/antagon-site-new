# Описание
**Стеклянный тотем** - инструмент Бога Искажения, «танцуют не только лишь все». При размещении накладывает хрупкость на всех вокруг кроме владельца, но наносит ему урон, когда тотем получает урон или остаётся вдали от владельца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При размещении, при уроне |
| Частота активации | 1 тик |
| Перезарядка (предмет) | - |
| Радиус эффекта | 17 блоков |
| Наложение эффектов | Хрупкость II, 10 с |
| Урон владельцу при уроне | Входящий урон / 2 |
| Учитывает урон типа VOID | Нет |
| Радиус для самоуничтожения | 30 блоков |
| Превращение в предмет при ударе владельцем | Да (без отмены урона) |

---

## Эффект: Хрупкость

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При уроне |
| Добавочный урон | +1 за уровень |

## Использование
1. Возьмите тотем в руку.
2. Разместите (ПКМ) - все в радиусе 17 блоков получают Хрупкость II.
3. Будьте осторожны: при уроне тотема владелец получает половину урона.
