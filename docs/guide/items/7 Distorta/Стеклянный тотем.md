# Описание
При размещении накладывает хрупкость на всех вокруг кроме владельца, но наносит ему урон когда тотем получает урон или остается вдали от владельца

| активация                                  | при размещении, при уроне |
| ------------------------------------------ | ------------------------- |
| частота активации                          | 1 тик                     |
| перезарядка(предмет)                       | -                         |
| Радиус эффекта                             | 17 блоков                 |
| Наложение эффектов                         | Хрупкость 2 10с           |
| Урон владельцу при уроне                   | входящий урон/2           |
| Учитывает урон типа VOID                   | нет                       |
| Радиус для самоуничтожения                 | 30 блоков                 |
| Превращение в предмет при ударе владельцем | да(без отмены урона)      |
Хрупкость:

| активация       | при уроне     |
| --------------- | ------------- |
| добавочный урон | +1 за уровень |
