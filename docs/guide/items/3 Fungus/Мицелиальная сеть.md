# Описание
**Мицелиальная сеть** - компонент Бога Расширения, «5G!». Представляет собой продвинутую мицелиальную структуру, используемую для крафта глаз грибницы, брони и импульсного меча. Сам по себе не имеет активного эффекта.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет     |
| Стакается      | Да       |

---
