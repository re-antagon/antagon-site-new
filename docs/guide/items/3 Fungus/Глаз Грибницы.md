# Описание
**Глаз Грибницы** - инструмент Бога Расширения, «ПНВ». При удержании в руке даёт эффект ночного зрения. Позволяет видеть в темноте без необходимости пить зелья.

| Характеристика    | Значение                 |
| ----------------- | ------------------------ |
| Тип предмета      | Инструмент               |
| Активация         | При удержании            |
| Перезарядка       | 5 тиков                  |
| Радиус эффекта    | Себе                     |
| Наложение эффектов | Ночное зрение III, 10 тиков |

---

## Эффект
При удержании в руке каждые 5 тиков накладывает на владельца эффект **Ночного зрения III** на 10 тиков. Эффект автоматически продлевается, пока предмет находится в руке.

## Использование
1. Возьмите Глаз Грибницы в руку.
2. Ночное зрение включается автоматически.
3. Уберите предмет из руки - эффект исчезнет.
