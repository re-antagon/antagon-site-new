# Описание
**Кастрюля грибного супа** - кулинарный предмет Бога Расширения, «какао-грибы». Многоразовая еда, вмещающая несколько порций супа. Правая кнопка мыши - заполнить кастрюлю, левая кнопка мыши - съесть порцию.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Кулинария |
| Активация      | ПКМ (наполнение), ЛКМ (поедание) |
| Вместимость    | Несколько порций |
| Стакается      | Нет      |



## Эффект
- **ПКМ** по кастрюле - наполнить её супом.
- **ЛКМ** - съесть одну порцию супа.

Кастрюля вмещает несколько порций, что делает её удобным многоразовым источником пищи.

## Использование
1. Возьмите пустую кастрюлю в руку.
2. Наполните (ПКМ), используя ингредиенты.
3. Поедайте (ЛКМ) порции по мере необходимости.
