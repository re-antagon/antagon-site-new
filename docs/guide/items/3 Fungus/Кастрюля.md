# Описание
**Кастрюля** - кулинарный предмет Бога Расширения, «отличный шлем до первого удара». Можно надеть на голову - она заблокирует **один любой урон** и сломается. Также служит основой для приготовления грибного супа: при использовании (ПКМ) с грибным супом в руке наполняется и превращается в [Кастрюлю грибного супа](/guide/items/3%20Fungus/Кастрюля%20грибного%20супа).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Кулинария |
| Активный эффект | Блокировка одного удара (при ношении на голове) |
| Стакается      | Нет      |



## Эффект

### Защита
Кастрюлю можно надеть в слот шлема. При получении урона она **блокирует один любой удар** (вне зависимости от силы) и после этого **ломается**. Полезно как экстренная защита от сильной атаки.

### Наполнение супом
Если взять Кастрюлю в руку и нажать ПКМ, имея в инвентаре [Грибной суп](/assets/items/mushroom_stew.png), кастрюля наполняется и превращается в [Кастрюлю грибного супа](/guide/items/3%20Fungus/Кастрюля%20грибного%20супа) - многоразовый источник питания.

## Использование
1. **Как шлем:** наденьте кастрюлю на голову - она заблокирует один удар и сломается.
2. **Для супа:** возьмите кастрюлю в руку и нажмите ПКМ с грибным супом в инвентаре.
