# Описание
**Кастрюля** - кулинарный предмет Бога Расширения, «отличный шлем до первого удара». Служит основой для приготовления грибного супа. Сама по себе не имеет активного эффекта.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Кулинария |
| Активный эффект | Нет     |
| Стакается      | Нет      |
