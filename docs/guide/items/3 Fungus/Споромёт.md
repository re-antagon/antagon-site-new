# Описание

Стреляет спорой, которая наносит урон и остаётся висеть при попадании в блок

| Активация                           | использование |
| ----------------------------------- | ------------- |
| Перезарядка                         | 10 тиков      |
| Боеприпас                           | Спора         |
| Скорость снаряда                    | 7 блоков/с    |
| Время жизни снаряда                 | 10с           |
| Урон                                | 6             |
| При разрушении снаряда(кроме удара) | минирование   |
| Урон мины                           | 6             |
| Время жизни мины                    | 10с           |
