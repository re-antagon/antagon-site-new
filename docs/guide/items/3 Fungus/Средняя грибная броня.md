# Описание
**Средняя грибная броня** - улучшенный сет брони Бога Расширения, «всегда второй». Полный сет даёт скорость и регенерацию при нахождении на мицелии.

| Характеристика     | Значение                          |
| ------------------ | --------------------------------- |
| Тип предмета       | Одежда (полный сет)               |
| Активация          | При ношении (полный сет)          |
| Условие активации  | На мицелии                        |
| Перезарядка        | 2 с                               |
| Наложение эффектов | Скорость I, 3 с + Регенерация I, 3 с |
| Уровень брони      | Алмаз                             |

---

## Эффект
При ношении полного сета на мицелии каждые 2 секунды накладывает на владельца эффекты **Скорости I** и **Регенерации I** на 3 секунды. Уровень брони соответствует алмазной.

## Использование
1. Наденьте все 4 элемента брони.
2. Находитесь на мицелии - скорость и регенерация срабатывают автоматически.
