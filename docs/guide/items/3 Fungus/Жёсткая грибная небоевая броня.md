# Описание
**Жёсткая грибная небоевая броня** - топовый небоевой сет Бога Расширения, «майнер. Должен. Страдать». Полный сет даёт скорость, прыгучесть и спешку при нахождении на мицелии.

| Характеристика     | Значение                                |
| ------------------ | --------------------------------------- |
| Тип предмета       | Одежда (полный сет)                     |
| Активация          | При ношении (полный сет)                |
| Условие активации  | На мицелии                              |
| Перезарядка        | 2 с                                     |
| Наложение эффектов | Скорость II, 3 с + Прыгучесть II, 3 с + Спешка II, 3 с |
| Уровень брони      | Незерит                                 |

---

## Эффект
При ношении полного сета на мицелии каждые 2 секунды накладывает на владельца эффекты **Скорости II**, **Прыгучести II** и **Спешки II** на 3 секунды. Уровень брони соответствует незериту.

## Использование
1. Наденьте все 4 элемента брони.
2. Находитесь на мицелии - все небоевые баффы срабатывают автоматически.
