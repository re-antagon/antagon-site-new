# Описание
**Токсичный гриб** - расходник Бога Расширения, «я не желаю лежать в твоём инвентаре». При использовании отравляет всех существ вокруг, включая самого владельца.

| Характеристика    | Значение           |
| ----------------- | ------------------ |
| Тип предмета      | Расходник          |
| Активация         | При использовании  |
| Радиус эффекта    | 5 блоков (+ себе)  |
| Наложение эффекта | Отравление I, 20 с |


## Эффект
При использовании накладывает эффект **Отравления I** на всех существ в радиусе 5 блоков, а также на самого владельца. Длительность отравления - 20 секунд.

::: warning Осторожно
Токсичный гриб отравляет **всех** вокруг, включая самого игрока, использовавшего его. Убедитесь, что у вас есть противоядие или молоко.
:::

## Использование
1. Возьмите гриб в руку.
2. Активируйте (ПКМ) - все существа вокруг получают отравление.


## Получение
Падает из **элитных грибных подрывников**.
