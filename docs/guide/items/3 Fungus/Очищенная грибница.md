# Описание
**Очищенная грибница** - компонент Бога Расширения, «сила в единстве». Представляет собой очищенный блок мицелия, используемый для крафта продвинутой брони, оружия и сетей. Сам по себе не имеет активного эффекта.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет     |
| Стакается      | Да       |
