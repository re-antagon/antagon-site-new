# Описание
**Импульсный меч** - оружие Бога Расширения, «слабоумие и отвага». Ускоряет владельца с каждым последовательным убийством. Чем больше убийств подряд, тем сильнее эффект скорости.

| Характеристика    | Значение            |
| ----------------- | ------------------- |
| Тип предмета      | Оружие (меч)        |
| Активация         | При убийстве        |
| Урон              | Алмаз               |
| Прочность         | Алмаз               |
| Перезарядка       | Нет                 |
| Увеличение эффекта | 1 за убийство     |
| Зачаровываемое    | Да                  |

**Шкала ускорения:**

| Убийств | Эффект              |
| ------- | ------------------- |
| 1       | Скорость I, 5 с     |
| 2       | Скорость I, 10 с    |
| 3       | Скорость I, 15 с    |
| 4       | Скорость II, 5 с    |
| 5       | Скорость II, 10 с   |
| 6       | Скорость II, 15 с   |
| 7       | Скорость III, 5 с   |
| 8       | Скорость III, 10 с  |
| 9+      | Скорость III, 15 с  |

---

## Эффект
При убийстве моба накладывает на владельца эффект скорости. С каждым новым убийством уровень и длительность эффекта растут по шкале (см. таблицу выше). Эффект сбрасывается, если не убивать достаточно долго.

## Использование
1. Возьмите меч в руку.
2. Убивайте мобов последовательно - скорость растёт.
3. При 9+ убийствах подряд получаете максимальное ускорение.
