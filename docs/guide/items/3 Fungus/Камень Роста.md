# Описание
**Камень Роста** - компонент Бога Расширения, «первый шаг - самый важный». Базовый ресурс, выпадающий из обычных грибных воинов. Используется для крафта очищенной грибницы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет     |
| Стакается      | Да       |



## Получение
С шансом падает из **обычных грибных воинов**.

## Используется для
- ![Очищенная грибница](/assets/items/custom/big/clean_mycelium.png) [Очищенная грибница](/guide/items/3%20Fungus/Очищенная%20грибница)

- [Очищенная грибница](/guide/items/3%20Fungus/Очищенная%20грибница) - требует Камень Роста.
- [Камень Развития](/guide/items/3%20Fungus/Камень%20Развития) - улучшенная версия камня.
