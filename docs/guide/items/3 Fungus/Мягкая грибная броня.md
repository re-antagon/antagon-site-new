# Описание
**Мягкая грибная броня** - базовый сет брони Бога Расширения, «портативный спальник». Полный сет даёт эффект скорости при нахождении на мицелии.

| Характеристика     | Значение                    |
| ------------------ | --------------------------- |
| Тип предмета       | Одежда (полный сет)         |
| Активация          | При ношении (полный сет)    |
| Условие активации  | На мицелии                  |
| Перезарядка        | 2 с                         |
| Наложение эффектов | Скорость I, 3 с             |
| Уровень брони      | Кольчуга                    |

---

## Эффект
При ношении полного сета на мицелии каждые 2 секунды накладывает на владельца эффект **Скорости I** на 3 секунды. Уровень брони соответствует кольчуге.

## Использование
1. Наденьте все 4 элемента брони (шлем, нагрудник, поножи, ботинки).
2. Находитесь на мицелии - скорость срабатывает автоматически.
