# Описание
**Спора** - расходник Бога Расширения, «спорная тема». При использовании на целевом блоке превращает всю землю вокруг в мицелий. Базовый инструмент расширения грибницы.

| Характеристика         | Значение             |
| ---------------------- | -------------------- |
| Тип предмета           | Расходник            |
| Активация              | При использовании    |
| Радиус эффекта         | Целевой блок         |
| Преобразование блоков  | Вся земля в мицелий  |

---

## Эффект
При использовании (ПКМ) по земле превращает её и окружающие блоки земли в мицелий. Позволяет быстро расширять грибной биом.

## Использование
1. Возьмите Спору в руку.
2. Активируйте (ПКМ) по земле - она превращается в мицелий.
