# Описание
**Камень Развития** - компонент Бога Расширения, «качество вытесняет количество». Улучшенный ресурс, выпадающий из сильных грибных воинов. Используется для крафта мицелиальной сети.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет     |
| Стакается      | Да       |


## Получение
С шансом падает из **сильных грибных воинов**.

## Используется для
- ![Мицелиальная сеть](/assets/items/custom/big/mycelium_net.png) [Мицелиальная сеть](/guide/items/3%20Fungus/Мицелиальная%20сеть)


## Связанные предметы
- [Мицелиальная сеть](/guide/items/3%20Fungus/Мицелиальная%20сеть) - требует Камень Развития.
- [Камень Роста](/guide/items/3%20Fungus/Камень%20Роста) - базовая версия камня.
