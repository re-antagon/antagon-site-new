# Описание
**Меч Превосходства** - оружие Бога Расширения, «адаптация - ключ к успеху». Усиливается с каждым ударом по цели. После 10 ударов входит в перегрузку и начинает наносить урон самому владельцу.

| Характеристика      | Значение            |
| ------------------- | ------------------- |
| Тип предмета        | Оружие (меч)        |
| Активация           | При ударе           |
| Базовый урон        | 4 (дерево)          |
| Прочность           | 240                 |
| Перезарядка         | Нет                 |
| Длительность заряда | 3 с                 |
| Увеличение урона    | +1 за удар          |
| Перегрузка          | Более 10 ударов     |
| Самоурон в перегрузке | Да                |
| Зачаровываемое      | Да                  |

---

## Эффект
При каждом ударе по цели урон меча увеличивается на 1 (база - 4). Если не наносить удары более 3 секунд, заряд сбрасывается. При достижении более 10 ударов (перегрузка) меч начинает наносить урон самому владельцу, но продолжает усиливаться.

::: warning Осторожно
После 10 ударов меч входит в перегрузку и начинает бить **и владельца**. Следите за счётчиком ударов!
:::

## Использование
1. Возьмите меч в руку.
2. Атакуйте цели - урон растёт с каждым ударом.
3. Не допускайте перегрузку (10+ ударов), чтобы не получить самоурон.
