# Описание
**Водная призма** - предмет Бога Космоса, «Луна сегодня в другом доме». За опыт превращает булыжник в призмарин, а незерак в булыжник.

| Активация              | использование |
| ---------------------- | ------------- |
| Расход опыта           | 1 ур.         |
| Шанс не потратить опыт | 95%           |
| Радиус                 | целевой блок  |
