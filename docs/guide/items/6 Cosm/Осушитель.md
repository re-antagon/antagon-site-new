# Описание
**Осушитель** - инструмент Бога Космоса. При использовании превращает водные блоки в воздух.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 1 с |
| Радиус эффекта | Целевой блок |
| Особый эффект  | Заменяет блоки на сухие вариации |

---

## Эффект
При использовании (ПКМ) по водному блоку превращает его в воздух. Может использоваться для быстрого осушения территорий.

## Использование
1. Возьмите осушитель в руку.
2. Активируйте (ПКМ) по водному блоку.
3. Блок воды превращается в воздух.
