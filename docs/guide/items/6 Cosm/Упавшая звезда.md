# Описание
**Упавшая звезда** - предмет Бога Космоса, «Неаккуратная посылка». 

| Спавн              | ночью или в энде, под открытым небом |
| ------------------ | ------------------------------------ |
| Наложение эффектов | свечение --:-- (себе при спавне)     |
| Хп                 | 1                                    |
| Условия дропа      | ночью                                |
| Дроп               | Упавшая звезда х 1                   |

## Получение
Добывается при падении метеоров в Краю и в Верхнем мире.
