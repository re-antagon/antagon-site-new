# Описание
**Кусочек солария** - компонент Бога Космоса. Получается разбором солария на 9 частей.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |
