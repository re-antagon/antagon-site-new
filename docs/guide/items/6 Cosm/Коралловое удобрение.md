# Описание
**Коралловое удобрение** - расходник Бога Космоса. При использовании выращивает случайный коралл в воде.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Условие        | Блок воды |
| Эффект         | Создаёт случайный коралл или коралловый блок |

---

## Эффект
При использовании (ПКМ) по блоку воды создаёт случайный коралл или коралловый блок.

## Использование
1. Возьмите коралловое удобрение в руку.
2. Активируйте (ПКМ) по воде - вырастет коралл.
