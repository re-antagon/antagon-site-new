# Описание
**Коралловое удобрение** - предмет Бога Космоса, «Мочалка». Запускает снаряд выращивающий случайный коралл в воде

| активация          | при использовании                            |
| ------------------ | -------------------------------------------- |
| перезарядка        | -                                            |
| радиус эффекта     | место попадания                              |
| условие эффекта    | блок воды                                    |
| особое             | создаёт случайный коралл или коралловый блок |
| вторичное свойство | зелёный краситель                            |
