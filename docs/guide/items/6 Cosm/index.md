# Бог Космоса

Предметы **Бога Космоса** - уникальные инструменты, оружие, броня, расходники и компоненты сервера Re:Antagon. Механика Бога Космоса строится вокруг небесных тел, света, воды и звёзд: от призыва молний через [Грозу в бутылке](/guide/items/6%20Cosm/Гроза%20в%20бутылке) до поиска упавших звёзд со [Звёздным компасом](/guide/items/6%20Cosm/Звёздный%20компас).

::: info Сводка
Всего предметов: **17**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
