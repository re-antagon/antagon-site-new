# Бог Космоса

Предметы **Бога Космоса** (Cosm) — инструменты, броня, расходники и компоненты сервера Re:Antagon. Механики Бога Космоса связаны со стихиями, эффектами звезд, астрологическими циклами и энергией праны.

::: info Сводка
Всего предметов: **18**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
