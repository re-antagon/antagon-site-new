# Описание
**Медный жезл** - оружие Бога Космоса. При использовании призывает молнию в указанную точку.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие |
| Активация      | При использовании |
| Перезарядка    | 30 с |
| Радиус эффекта | 5 блоков |
| Особое         | Призывает молнию |

---

## Эффект
При использовании (ПКМ) призывает молнию в точку, куда игрок смотрит. Молния наносит урон всем существам в радиусе 5 блоков от точки попадания. Перезарядка - 30 секунд.

## Использование
1. Возьмите медный жезл в руку.
2. Направьте взгляд на цель.
3. Активируйте (ПКМ) - призовётся молния.
