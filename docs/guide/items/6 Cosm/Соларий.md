# Описание
**Соларий** - компонент Бога Космоса, «загар обеспечен!». Солнечный слиток, используемый для крафта звёздного лука, небесного камня и других предметов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |
