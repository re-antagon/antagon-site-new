# Описание
При попадании призывает молнию

| Активация      | при попадании    |
| -------------- | ---------------- |
| Радиус эффекта | место попадания  |
| Особое         | призывает молнию |
# Получение
Получение урона от молниевого угря с пустой бутылкой в руке
# Используется для
[[Медный жезл]]
