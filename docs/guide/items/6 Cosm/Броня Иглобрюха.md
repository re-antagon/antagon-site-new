# Описание
**Броня Иглобрюха** - предмет Бога Космоса, «Последний иглобрюх». При получении урона отравляет противника

| Активация 1                      | при ношении(получение урона) |
| -------------------------------- | ---------------------------- |
| Перезарядка 1                    | -                            |
| Радиус эффекта 1                 | атакующий противник          |
| Наложение эффектов(1 элемент)    | отравление 1 5с              |
| Наложение эффектов(2 элемента)   | отравление 1 10с             |
| Наложение эффектов(3 элемента)   | отравление 2 5с              |
| Наложение эффектов(полный сет)   | отравление 2 10с             |
| Броня                            | кожаная                      |
| Прочность                        | кожаная                      |
| Активация 2                      | при ношении(полный сет)      |
| Радиус эффекта 2                 | себе                         |
| Перезарядка 2                    | -                            |
| Снятие эффектов себе(полный сет) | отравление                   |
