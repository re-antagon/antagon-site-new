# Описание
**Звёздный лук** - оружие Бога Космоса, «Brimstone». Запускает лучи вместо стрел, накладывает эффекты звёзд. ЛКМ переключает активный эффект.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (лук) |
| Активация      | Выстрел |
| Неполное натяжение | Обычный выстрел |
| Радиус эффекта | 30 блоков |
| Пробитие       | Кроме блоков |
| Переключение эффекта | Взмах (ЛКМ) |
| Зачаровываемое | Да |
| Урон           | 8 |

**Эффекты (переключаемые):**

| Эффект | Длительность |
| ------ | ------------ |
| Отравление II | 5 с |
| Горение | 5 с |
| Замедление | 5 с |
| Слабость | 5 с |

---

## Эффект
Стреляет лучами вместо стрел на расстояние до 30 блоков. Лучи пробивают существ, но не блоки. Наносят 8 урона и накладывают выбранный эффект на 5 секунд. ЛКМ переключает между 4 эффектами: отравление, горение, замедление, слабость.

## Использование
1. Возьмите лук в руку.
2. ЛКМ для переключения активного эффекта.
3. Зарядите и выстрелите (ПКМ) - луч наносит урон и накладывает эффект.
