# Описание
**Звёздный лук** - предмет Бога Космоса, «Brimstone». Запускает лучи вместо стрел, накладывает эффекты звёзд, лкм переключает звезду

| Активация            | Выстрел         |
| -------------------- | --------------- |
| Неполное натяжение   | Обычный выстрел |
| Радиус эффекта       | 30 блоков       |
| Пробитие             | Кроме блоков    |
| Переключение эффекта | Взмах           |
| Зачаровываемое       | Да              |
| Урон                 | 8               |
| Эффект       | Длительность |
| ------------ | ------------ |
| Отравление 2 | 5с           |
| Горение      | 5с           |
| Замедление   | 5с           |
| Слабость     | 5с           |
