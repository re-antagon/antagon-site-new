# Описание
**Зелье захвата** - зелье Бога Окончания, «вечный космос чёрных дыр». При использовании притягивает всех существ в радиусе 5 блоков к точке попадания. Существует в обычном и взрывном вариантах.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Зелье |
| Активация      | При использовании |
| Радиус эффекта | 5 блоков |
| Особое         | Толчок к месту активации |


## Эффект
При использовании притягивает всех мобов и игроков в радиусе 5 блоков к точке, где было применено зелье (или к точке попадания взрывного варианта).

## Использование
1. Возьмите зелье в руку.
2. Активируйте (ПКМ) - существа вокруг притянутся к вам (обычное) или к месту попадания (взрывное).
