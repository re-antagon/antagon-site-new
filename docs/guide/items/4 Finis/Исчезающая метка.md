# Описание
**Исчезающая метка** - инструмент Бога Окончания. Даёт неуязвимость (Защита V) и полную невидимость на 5 секунд.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 30 с |
| Длительность   | 5 с |
| Наложение эффектов | Полная невидимость, Защита V |


## Эффект
При использовании (ПКМ) накладывает на владельца **Защиту V** и **полную невидимость** на 5 секунд.

## Использование
1. Возьмите Исчезающую метку в руку.
2. Активируйте (ПКМ) - 5 секунд неуязвимости и невидимости.
3. Перезарядка 30 с.
