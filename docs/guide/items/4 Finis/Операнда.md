# Описание
При взмахе меняет здоровье одним из способов: +1, -1, /2, x2

| Активация                             | при взмахе                   |
| ------------------------------------- | ---------------------------- |
| Смена режима                          | при использовании            |
| Перезарядка(порежимно)                | 1с, 1с, 1с, 1с               |
| Презарядка(смена режима)              | 1с                           |
| Радиус эффекта                        | себе                         |
| Режим 1 (сложение)                    | +1 хп                        |
| Режим 2 (вычитание)                   | -1 хп                        |
| Режим 3 (деление)                     | /2 хп (округление в большую) |
| Режим 4 (умножение)                   | ×2 хп                        |
| Блокировка смены режима в перезарядке | Да                           |
