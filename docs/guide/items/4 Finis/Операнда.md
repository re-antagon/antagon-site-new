# Описание
**Операнда** - инструмент Бога Окончания, «арифмометр плоти». При взмахе изменяет здоровье владельца одним из способов: +1 (сложение), -1 (вычитание), /2 (деление), x2 (умножение).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При взмахе |
| Смена режима   | При использовании |
| Радиус эффекта | Себе |
| Режим 1 (сложение) | +1 хп |
| Режим 2 (вычитание) | -1 хп |
| Режим 3 (деление) | /2 хп (округление вверх) |
| Режим 4 (умножение) | ×2 хп |

---

## Эффект
Операнда имеет 4 режима, которые переключаются ПКМ. Взмах (ЛКМ) применяет выбранную операцию к здоровью владельца.

## Использование
1. Возьмите Операнда в руку.
2. ПКМ для переключения между режимами (+, -, /, ×).
3. ЛКМ (взмах) для применения операции к своему здоровью.
