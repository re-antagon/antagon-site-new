# Описание
**Почтовая руна** - расходник Бога Окончания, «атомный экспресс». Размещается на земле. При повторном использовании телепортирует все предметы в радиусе 2 блоков указанному игроку.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При размещении, при использовании |
| Цель эффекта   | Указанный игрок |
| Радиус сбора предметов | 2 блока |
| Особое         | Телепорт предметов |

---

## Эффект
При первом использовании размещает руну на земле. При повторном использовании (ПКМ по руне) собирает все предметы в радиусе 2 блоков и телепортирует их указанному игроку.

## Использование
1. Разместите Почтовая руна на земле.
2. Нажмите ПКМ по руне - укажите игрока-получателя.
3. Предметы в радиусе 2 блоков телепортируются получателю.
