| Активация      | при ударе, при ношении            |
| -------------- | --------------------------------- |
| Особое(без кд) | удары носителя становятся 1 урона |
| Перезарядка    | -                                 |
| Радиус эффекта | 10 блоков                         |
| Особое         | деспавн фантомов                  |
| Уровень брони  | кожа                              |
| Прочность      | кожа                              |
