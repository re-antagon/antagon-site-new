# Описание
**Осыпающийся осколок** - компонент Бога Окончания, «невосполнимая утрата». Хрупкий осколок, находящийся в сундуках Чистилища. Используется для крафта пепла магии и слепого побега.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |


## Получение
Находится в **сундуках [Чистилища](/guide/mechanics/purgatory)**.

## Используется для
- ![Пепел магии](/assets/items/custom/big/ashes_of_magic.png) [Пепел магии](/guide/items/4%20Finis/Пепел%20магии)
- ![Слепой побег](/assets/items/custom/big/blind_escape.png) [Слепой побег](/guide/items/4%20Finis/Слепой%20побег)
- Осколок зеркала


## Связанные предметы
- [Пепел магии](/guide/items/4%20Finis/Пепел%20магии) - требует Осыпающийся осколок.
- [Слепой побег](/guide/items/4%20Finis/Слепой%20побег) - требует Осыпающийся осколок.
- Осколок зеркала - требует Осыпающийся осколок.
- [Чистилище](/guide/mechanics/purgatory) - измерение, где добывается предмет.
