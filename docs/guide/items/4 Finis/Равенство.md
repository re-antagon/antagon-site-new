# Описание
**Равенство** - расходник Бога Окончания, «эквивалентный материал». При использовании даёт одну дубовую доску.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Количество предметов | 1 |
| Выдаваемые предметы | Дубовая доска |

---

## Эффект
При использовании (ПКМ) выдаёт владельцу 1 дубовую доску. Расходуется за одно применение.

## Использование
1. Возьмите Равенство в руку.
2. Активируйте (ПКМ) - получите дубовую доску.
