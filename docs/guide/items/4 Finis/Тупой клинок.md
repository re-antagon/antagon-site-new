# Описание
**Тупой клинок** - оружие Бога Окончания, «жертва системы». Бьёт широким дробящим ударом по области. Урон - половина каменного меча (неблокируемый).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | Удар |
| Перезарядка    | 1 с |
| Урон           | Каменный меч / 2 (неблокируемый) |
| Прочность      | Каменный меч |
| Радиус эффекта | 3 блока |

---

## Эффект
При ударе наносит **неблокируемый урон** всем существам в радиусе 3 блоков. Урон равен половине урона каменного меча, но игнорирует броню.

## Использование
1. Возьмите клинок в руку.
2. Ударьте - все вокруг получают урон.
