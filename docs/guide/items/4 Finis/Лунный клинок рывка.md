# Описание
**Лунный клинок рывка** - оружие Бога Окончания, «вперёд и только вперёд!». При ПКМ совершает рывок вперёд. Имеет 2 заряда.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | ПКМ |
| Перезарядка    | 6 с (общая) |
| Заряды         | 2 |
| Урон           | Незерит |
| Дальность рывка (с места) | 6 блоков |
| Дальность рывка (в прыжке) | 15 блоков |
| Зачаровываемое | Да |


## Эффект
При ПКМ рывок вперёд: с места на 6 блоков, в прыжке на 15 блоков. 2 заряда.

## Использование
1. Возьмите клинок в руку.
2. Нажмите ПКМ - рывок вперёд.
3. В прыжке рывок дальше (15 блоков).
