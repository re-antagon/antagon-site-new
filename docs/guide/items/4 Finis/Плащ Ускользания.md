# Описание
**Плащ Ускользания** - броня Бога Окончания, «неуловимый». При получении любого урона телепортирует владельца на 3 блока вперёд.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | При уроне |
| Перезарядка    | 5 с |
| Дальность эффекта | 3 блока |

---

## Эффект
При получении любого урона владелец автоматически телепортируется на 3 блока вперёд.

## Использование
1. Наденьте плащ в слот нагрудника.
