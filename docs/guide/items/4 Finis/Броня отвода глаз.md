# Описание
**Броня отвода глаз** - броня Бога Окончания, «включённые шейдеры». Полный сет даёт пассивную невидимость. Шифт+прыжок полностью скрывает на короткое время.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Активация 1    | При ношении (полный сет) |
| Эффект 1       | Невидимость |
| Активация 2    | Шифт+прыжок (полный сет) |
| Перезарядка 2  | 60 с |
| Эффект 2       | Скрытность, 10 с |
| Уровень брони  | Алмаз |
| Зачаровываемое | Да |


## Эффект
**Пассивный:** при ношении полного сета владелец постоянно находится в невидимости.

**Активный:** при нажатии шифт+прыжок (при полном сете) владелец полностью скрывается на 10 секунд (полная скрытность). Перезарядка активного эффекта - 60 секунд.

## Использование
1. Наденьте все 4 элемента брони.
2. Невидимость включается автоматически.
3. Для полного скрытия нажмите шифт+прыжок.
