# Описание
**Тёмно-синие шаровары** - поножи Бога Окончания, «пассивно агрессивный доход». При подборе предмета дают дополнительный случайный камень.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (поножи) |
| Активация      | При подборе предмета |
| Перезарядка    | 5 с |
| Уровень брони  | Алмаз |



## Эффект
При подборе предмета с шансом даёт дополнительный камень, песок или гравий.

## Использование
1. Наденьте шаровары в слот поножей.



## Получение
Крафтится из якоря возрождения, серебряного слитка и алмазных блоков:

- 2x ![Якорь возрождения](/assets/items/respawn_anchor.png) Якорь возрождения
- ![Серебряный слиток](/assets/items/custom/big/silver_ingot.png) [Серебряный слиток](/guide/items/4%20Finis/Серебряный%20слиток)
- 4x ![Алмазный блок](/assets/items/diamond_block.png) Алмазный блок
