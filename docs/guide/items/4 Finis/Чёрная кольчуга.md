# Описание
**Чёрная кольчуга** - броня Бога Окончания, «ход конём». При ношении полного сета каждые 3 секунды снимает **все** эффекты с владельца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Активация      | При ношении (полный сет) |
| Перезарядка    | 3 с |
| Снятие эффектов | Все |
| Совместимость  | Серебряный обруч |
| Уровень брони  | Кольчуга |



## Эффект
Полный сет снимает все эффекты каждые 3 с. Совместим с [Серебряным обручем](/guide/items/4%20Finis/Серебряный%20обруч).
