# Описание
**Сфера криостазиса** - инструмент Бога Окончания, «мгновение растерянности». Снимает эффекты, замедляет и поднимает всех вокруг.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 20 с |
| Радиус эффекта | 10 блоков + себе |
| Снятие эффектов | Все |
| Наложение эффектов | Медлительность III, 5 с |
| Вторичный эффект | Левитация, 3 с |
| Прочность | 80 |

---

## Эффект
При использовании (ПКМ) снимает **все** эффекты с владельца, затем накладывает на всех в радиусе 10 блоков **Медлительность III** на 5 с, а через 1 с — **Левитацию** на 3 с.

## Использование
1. Возьмите Сферу криостазиса в руку.
2. Активируйте (ПКМ) - эффекты сняты, враги замедлены и подняты.
