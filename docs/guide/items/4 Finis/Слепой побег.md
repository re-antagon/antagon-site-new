# Описание
**Слепой побег** - расходник Бога Окончания, «беги Лола, беги!». При смертельном уроне срабатывает автоматически: даёт полёт на 8 секунд, после чего навешивает мощные дебаффы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | Смертельный урон |
| Первичные эффекты | Полёт, 8 с |
| Вторичные эффекты | Замедление, слабость, утомление (120 с), тьма (22 с), невидимость (22 с) |


## Эффект
При получении смертельного урона автоматически активируется, спасая владельца от смерти. Даёт эффект **Полёта** на 8 секунд, позволяя улететь от опасности. После окончания полёта накладывает длительные дебаффы: замедление, слабость и утомление на 120 секунд, а также тьму и невидимость на 22 секунды.

## Использование
1. Держите Слепой побег в инвентаре.
2. При получении смертельного урона он сработает автоматически.
3. Используйте 8 секунд полёта, чтобы спастись.
