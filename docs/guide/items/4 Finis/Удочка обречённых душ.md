# Описание
**Удочка обречённых душ** - инструмент Бога Окончания, «ух ты, говорящая рыба!». При вытягивании поплавка призывает злого союзного эллея.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При повторном использовании (вытягивание) |
| Перезарядка    | 15 с |
| Здоровье моба  | 20 |
| Урон моба      | 2 |
| Время жизни    | 10 минут |

---

## Эффект
Работает как обычная удочка, но при вытягивании поплавка (повторное ПКМ) вместо рыбы призывает **злого союзного эллея**. Эллей атакует врагов владельца, нанося 2 урона. Живёт 10 минут. Перезарядка - 15 секунд.

## Использование
1. Возьмите удочку в руку.
2. Закиньте (ПКМ) и дождитесь поклёвки.
3. Вытяните (ПКМ) - призовётся эллей.

---

## Получение
Дроп с **банши** с шансом **3%**.
