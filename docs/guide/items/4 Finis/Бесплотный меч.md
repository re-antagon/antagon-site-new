# Описание
**Бесплотный меч** - оружие Бога Окончания, «слишком лёгкий, чтобы быть». Наносит неблокируемый чистый урон: 4 по игрокам и 10 по мобам.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | При ударе (полная зарядка) |
| Урон по игрокам | 4 (неблокируемый) |
| Урон по мобам  | 10 (неблокируемый) |

---

## Эффект
Наносит **чистый (неблокируемый) урон**, который игнорирует броню. Требует полной зарядки атаки.

## Использование
1. Возьмите меч в руку.
2. Зарядите атаку полностью и ударьте цель.
3. Урон проходит сквозь броню.

---

Крафтится из ока эндера, заряда ветра и палки:

- 2x ![Заряд ветра](/assets/items/wind_charge.png) Заряд ветра
