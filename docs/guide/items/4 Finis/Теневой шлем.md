# Описание
**Теневой шлем** - шлем Бога Окончания, «бесполезный хлам». Обычный шлем алмазного уровня.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (шлем) |
| Уровень брони  | Алмаз |
| Зачаровываемое | Да |
