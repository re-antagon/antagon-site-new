# Описание
**Вечный ветер** - инструмент Бога Окончания, «хеликоптер-хеликоптер...». Спавнит многоразовый подбрасывающий вихрь.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При размещении, при касании |
| Дроп при разрушении | Да |

---

## Эффект
При размещении (ПКМ) создаёт многоразовый вихрь, который периодически подбрасывает любые коснувшиеся существа в воздух.

## Использование
1. Возьмите Вечный ветер в руку.
2. Разместите (ПКМ) на земле.
3. Существа, касающиеся вихря, подбрасываются вверх.
