# Описание
**Всевидящий глаз** - инструмент Бога Окончания, «с ним титановое кольцо». Подсвечивает игроков в радиусе 35 блоков и боссов в радиусе 75 блоков.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 15 с |
| Радиус (игроки) | 35 блоков |
| Радиус (боссы, мини-боссы) | 75 блоков |
| Наложение эффектов | Свечение, 10 с |

---

## Эффект
При использовании (ПКМ) подсвечивает всех игроков в радиусе 35 блоков и всех боссов/мини-боссов в радиусе 75 блоков на 10 секунд. Позволяет отслеживать цели сквозь стены и на большом расстоянии.

## Использование
1. Возьмите Всевидящий глаз в руку.
2. Активируйте (ПКМ) - все цели в радиусе подсвечиваются.
3. Перезарядка 15 с.
