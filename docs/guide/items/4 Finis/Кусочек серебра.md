# Описание
**Кусочек серебра** - компонент Бога Окончания, «издержки производства». Базовый серебряный ресурс, получаемый из серебряного слитка и используемый во множестве крафтов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---
