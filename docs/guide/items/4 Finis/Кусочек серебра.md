# Описание
**Кусочек серебра** - компонент Бога Окончания, «издержки производства». Базовый серебряный ресурс, получаемый из серебряного слитка и используемый во множестве крафтов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

## Получение
Крафтится по 9 штук из одного серебряного слитка:

- ![Серебряный слиток](/assets/items/custom/big/silver_ingot.png) [Серебряный слиток](/guide/items/4%20Finis/Серебряный%20слиток)
