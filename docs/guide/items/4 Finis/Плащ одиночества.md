# Описание
**Плащ одиночества** - броня Бога Окончания, «рикошет бесконечности». 15% шанс перенаправить полученный урон на случайную цель в радиусе 15 блоков.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Шанс срабатывания | 15% |
| Радиус перенаправления | 15 блоков |


## Эффект
При получении урона с шансом 15% урон отменяется и перенаправляется на случайную цель в радиусе 15 блоков.

## Использование
1. Наденьте плащ в слот нагрудника.
