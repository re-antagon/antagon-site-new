# Описание
**Барьер цепей** - инструмент Бога Окончания, «пробуждение заключённого». Выглядит как зачарованная цепь. При активации призывает снаряд, летящий до 40 блоков. В точке приземления ищет цель в радиусе 3 блоков. Если цель найдена, спавнит невидимого моба (80 хп), который удерживает цель в радиусе 5 блоков в течение 1 минуты.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент (расходник) |
| Активация      | Взмах |
| Дальность снаряда | 40 блоков |
| Поиск цели | 3 блока от точки приземления |
| Здоровье моба-удерживателя | 80 хп |
| Радиус удержания | 5 блоков |
| Время жизни моба | 1 минута |

---

## Эффект
При взмахе (ПКМ) выпускает снаряд, летящий до 40 блоков. При приземлении ищет ближайшее существо в радиусе 3 блоков:

- **Если цель не найдена** - предмет просто падает на землю.
- **Если цель найдена** - спавнится невидимый моб (с частицами, как полтергейст), который запоминает ближайшее существо. Пока моб жив, цель не может покинуть радиус 5 блоков вокруг него - её телепортирует обратно. Моба можно убить (80 хп), и он умирает сам через 1 минуту.

Предмет расходник - тратится при выстреле.

## Использование
1. Возьмите Барьер цепей в руку.
2. Взмахните (ПКМ) в сторону цели.
3. Цель оказывается запертой в радиусе 5 блоков на 1 минуту.

## Получение
Будет в луте **[Чистилища](/guide/mechanics/purgatory)**. С шансом **50%** дропается в точках привязки полтергейстов при их смерти.
