# Описание
**Прочная кожа** - компонент Бога Войны, «новая эра - новая мода». Выделанная солью кожа, используемая для крафта лёгкой брони и поясного запаса.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Выделывается в кузнице из кожи и соли:
- ![Кожа](/assets/items/leather.png) Кожа
- ![Соль](/assets/items/custom/big/salt.png) [Соль](/guide/items/2%20Mater/Соль)
