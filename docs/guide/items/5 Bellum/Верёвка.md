# Описание
**Верёвка** - компонент Бога Войны, «гордиев узел». Служит скрученной верёвкой для изготовления тетивы лука Сталевара. Сам по себе не имеет активного эффекта.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |
