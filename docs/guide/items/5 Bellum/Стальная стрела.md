# Описание
**Стальная стрела** - расходник Бога Войны, «есть пробитие». Служит боеприпасом для ![Лук Сталевара](/assets/items/custom/big/steel_bow.png) [Лука Сталевара](/guide/items/5%20Bellum/Лук%20Сталевара).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активный эффект | Нет (боеприпас) |
| Стакается      | Да |


## Получение
Крафтится из кремня и кусочков оружейной стали:
- ![Кремень](/assets/items/flint.png) Кремень
- 2x ![Кусочек оружейной стали](/assets/items/custom/big/steel_nugget.png) [Кусочек оружейной стали](/guide/items/5%20Bellum/Кусочек%20оружейной%20стали)

/>
