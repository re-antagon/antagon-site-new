# Описание
**Оружейная сталь** - компонент Бога Войны, «Severed Steel». Основной металлический ресурс Бога, используемый для крафта брони, оружия и щита Сталевара.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---
