# Описание
**Боевой горн** - инструмент Бога Войны, «лучший из команды». Даёт несколько боевых усилений в ограниченном радиусе.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 5 мин |
| Длительность   | 1 мин |
| Радиус эффекта | 4 блока |
| Наложение эффектов | Сила I, Скорость I, Сопротивление I |



## Эффект
При использовании (ПКМ) накладывает на всех в радиусе 4 блоков эффекты **Силы I**, **Скорости I** и **Сопротивления I** на 1 минуту. Перезарядка - 5 минут.

## Использование
1. Возьмите горн в руку.
2. Активируйте (ПКМ) для усиления себя и союзников рядом.
