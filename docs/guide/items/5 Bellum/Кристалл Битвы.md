# Описание
**Кристалл Битвы** - компонент Бога Войны, «сверкающая мощь». Собирается из осколков битвы и служит основой для крафта большинства предметов Бога.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Крафтится из 9 осколков битвы:
