# Описание
**Сапоги Удара** - ботинки Бога Войны, «тошнотная комета». При получении урона от падения бьют всех вокруг ударной волной.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (ботинки) |
| Активация      | При высоком падении |
| Радиус эффекта | 3 + 0,2 × урон |
| Ограничение урона | 50 |
| Броня          | 3 (алмаз) |
| Зачаровываемое | Да |
| Улучшаемое     | Да |

---

## Эффект
При получении урона от падения наносит всем существам вокруг ударной волной урон, равный полученному (но не более 50). Радиус поражения: 3 + 0,2 × урон от падения. Броня на уровне алмаза.

## Использование
1. Наденьте сапоги в слот ботинок.
2. Упадите с высоты - ударная волна поразит всех вокруг.
