# Описание
**Броня Сталевара** - броня Бога Войны, «лежит на сердце тяжкий груз». При полном сете даёт иммунитет к замедлению и скорости, сильно уменьшает отбрасывание.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Активация      | Периодическая (полный сет) |
| Броня          | 3, 8, 6, 3 (незерит) |
| Снятие эффектов | Замедление, Скорость |
| Зачаровываемое | Да |
| Сопротивление отбрасыванию | 3, 3, 3, 3 |

---

## Эффект
Полный сет снимает эффекты замедления и скорости, а также даёт **сопротивление отбрасыванию** на каждый элемент брони (по 3 единицы). Броня соответствует незериту.

## Использование
1. Наденьте все 4 элемента брони.
2. Эффекты срабатывают автоматически.
