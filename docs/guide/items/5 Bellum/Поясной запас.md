# Описание
**Поясной запас** - инструмент Бога Войны, «чёрный день наступил». После активации снижает расход еды.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | Использование |
| Перезарядка    | 3 мин |
| Длительность   | 3 мин |
| Наложение эффектов | 40% не потратить голод |
| Зачаровываемое | Да |


## Эффект
При использовании (ПКМ) накладывает эффект экономии голода на 3 минуты: с шансом 40% еда не расходуется при употреблении. Перезарядка - 3 минуты.

## Использование
1. Возьмите поясной запас в руку.
2. Активируйте (ПКМ) для получения экономии еды на 3 минуты.


## Получение
Крафтится из золотых яблок, кристалла битвы, связки и прочной кожи:
- 2x ![Золотое яблоко](/assets/items/golden_apple.png) Золотое яблоко
- ![Кристалл Битвы](/assets/items/custom/big/fight_crystal.png) [Кристалл Битвы](/guide/items/5%20Bellum/Кристалл%20Битвы)
- 2x ![Связка](/assets/items/bundle.png) Связка
- 2x ![Прочная кожа](/assets/items/custom/big/tough_leather.png) [Прочная кожа](/guide/items/5%20Bellum/Прочная%20кожа)
