# Описание
**Плащ Берсерка** - броня Бога Войны, «в самое пекло». При получении урона всё лучше защищает владельца, не даёт базовую броню.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | При получении урона (экипировано) |
| Длительность   | 3 с |
| Наложение эффектов | Сопротивление +1 (макс. 3) |
| Броня          | 0 (элитры) |
| Зачаровываемое | Да |


## Эффект
При получении урона накладывает на владельца эффект **Сопротивления**, уровень которого растёт с каждым попаданием (до Сопротивления III). Эффект длится 3 секунды и обновляется при новом уроне. Плащ не даёт базовой брони (как элитры).

## Использование
1. Наденьте плащ в слот нагрудника.
2. При получении урона защита автоматически усиливается.
