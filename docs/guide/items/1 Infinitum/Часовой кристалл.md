# Описание
**Часовой кристалл** - компонент Бога Постижения, основанный на энергии пара и редстоуна. Служит ключевой деталью в механизмах, связанных с управлением временем и прокладкой туннелей. Сам по себе не имеет активного эффекта и используется исключительно как материал для крафта более сложных предметов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

## Используется для
- ![MiH](/assets/items/custom/big/MiH.png) [MiH](/guide/items/1%20Infinitum/MiH)
- ![Туннелепроходец](/assets/items/custom/big/void_hammer.png) [Туннелепроходец](/guide/items/1%20Infinitum/Туннелепроходец)

## Примечания
- Является промежуточным компонентом: без него невозможно скрафтить ни расходник [MiH](/guide/items/1%20Infinitum/MiH), ни инструмент [Туннелепроходец](/guide/items/1%20Infinitum/Туннелепроходец).
- Как компонент не обладает собственным действием и применяется только в составе других предметов.


## Связанные предметы
- [MiH](/guide/items/1%20Infinitum/MiH) - расходник, перематывающий время мира (требует Часовой кристалл).
- [Туннелепроходец](/guide/items/1%20Infinitum/Туннелепроходец) - инструмент для прокладки туннелей (требует Часовой кристалл).
- [Паровой кристалл](/guide/items/1%20Infinitum/Паровой%20кристалл) - основной расходуемый материал в рецепте.
