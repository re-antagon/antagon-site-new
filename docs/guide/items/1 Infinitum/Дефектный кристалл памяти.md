# Описание
**Дефектный кристалл памяти** - расходный компонент Бога Постижения, получаемый при повреждении заряженного кристалла памяти. Несмотря на «дефект», он служит важным материалом для крафта продвинутых устройств.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Расходник    |
| Активный эффект | Нет        |
| Стакается      | Да           |

---

## Получение
Выпадает при ломании [Заряженного кристалла памяти](/guide/items/1%20Infinitum/Заряженный%20кристалл%20памяти) (использование с ножницами на уровне опыта 15+).

- ![Заряженный кристалл памяти](/assets/items/custom/big/powerd_crystal.png) [Заряженный кристалл памяти](/guide/items/1%20Infinitum/Заряженный%20кристалл%20памяти) - источник дефектного кристалла при поломке.

## Используется для
- ![Свиток антигравитации](/assets/items/custom/big/antigravity_scroll.png) [Свиток антигравитации](/guide/items/1%20Infinitum/Свиток%20антигравитации)
- ![Лазуритовый резонатор](/assets/items/custom/big/lapis_rezonator.png) [Лазуритовый резонатор](/guide/items/1%20Infinitum/Лазуритовый%20резонатор)

## Примечания
- Является побочным продуктом работы с кристаллами памяти и не крафтится напрямую.
- Несмотря на название, активно применяется в рецептах свитков и резонаторов Бога Постижения.
