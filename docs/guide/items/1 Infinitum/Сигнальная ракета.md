# Описание
**Сигнальная ракета** - расходник Бога Постижения, «мобильный ракетомёт». Запускает яркую ракету в небо, служащую сигналом или средством освещения.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Расходник    |
| Активный эффект | Запуск ракеты в небо |
| Стакается      | Да           |


## Эффект
При использовании запускает в небо яркую ракету, видимую издалека. Полезна для подачи сигналов союзникам или освещения местности.

## Использование
1. Возьмите ракету в руку.
2. Активируйте (ПКМ) для запуска.
3. Ракета взлетает и сгорает в небе.


## Получение
Крафтится по 3 штуки из пороха, бумаги, красного красителя и драконьего дыхания:

- ![Порох](/assets/items/gunpowder.png) Порох
- ![Бумага](/assets/items/paper.png) Бумага
- ![Красный краситель](/assets/items/red_dye.png) Красный краситель
- ![Драконье дыхание](/assets/items/dragon_breath.png) Драконье дыхание

## Примечания
- Крафтится сразу по 3 штуки.
- Требует редкого драконьего дыхания, что делает ракеты ценным расходником.
