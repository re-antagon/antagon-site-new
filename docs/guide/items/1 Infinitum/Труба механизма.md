# Описание
**Труба механизма** - компонент Бога Постижения, «проводник давления». Служит каналом передачи пара и усилия в механических устройствах.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

## Примечания
- Базовый трубопроводный компонент для паровых и силовых механизмов.
- Как компонент не обладает собственным действием.
