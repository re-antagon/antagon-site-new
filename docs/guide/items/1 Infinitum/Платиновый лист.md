# Описание
**Платиновый лист** - компонент Бога Постижения, «новая степень очистки». Служит очищенным полуфабрикатом платины для сборки премиальных механизмов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

---

## Получение
Выплавляется в печи из обломков незерита:

- ![Обломок незерита](/assets/items/netherite_scrap.png) Обломок незерита (в печи)

- ![Динамо-машина](/assets/items/custom/big/dynamo_machine.png) [Динамо-машина](/guide/items/1%20Infinitum/Динамо-машина)

## Примечания
- Промежуточный продукт очистки платины, необходимый для премиальных деталей.
- Как компонент не обладает собственным действием.
