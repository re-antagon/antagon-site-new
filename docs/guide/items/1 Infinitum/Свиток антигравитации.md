# Описание
**Свиток антигравитации** - расходник Бога Постижения, «я верю, я могу летать!». Даёт эффект левитации IV на 10 секунд, после чего резко бросает владельца вниз.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Расходник            |
| Активация         | Использование        |
| Длительность      | 10 с                 |
| Наложение эффектов | Левитация 4         |
| Радиус эффекта    | Себе                 |
| Вторичный эффект  | Быстрое падение      |
| Вторичная активация | По окончании левитации |

---

## Эффект
При использовании накладывает на владельца левитацию IV на 10 секунд. По истечении времени эффект сменяется резким падением вниз - важно заранее подготовиться к приземлению.

## Использование
1. Возьмите свиток в руку.
2. Активируйте (ПКМ) для получения левитации.
3. Через 10 секунд начнётся быстрое падение.

## Примечания
- Левитация IV поднимает очень быстро - будьте осторожны с высотой перед применением.
- После окончания эффекта следует резкое падение, что может быть опасно без защиты от урона при падении.
