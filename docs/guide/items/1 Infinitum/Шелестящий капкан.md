# Описание
**Шелестящий капкан** - расходник Бога Постижения, «ловушка, что шепчет». При срабатывании накладывает на цель стан на 3 секунды.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Расходник            |
| Перезарядка       | 10 с                 |
| Длительность активации | 20 тиков        |
| Активация         | Приближение          |
| Радиус эффекта    | 3 блока              |
| Наложение эффектов | Невидимость 10 с    |



## Эффект
При срабатывании накладывает на попавшую в радиус 3 блоков цель стан на 3 секунды. После срабатывания активен 20 тиков и уничтожается. Перезарядка между установками - 10 секунд.

## Использование
1. Разместите капкан на земле.
2. При приближении цели в радиусе 3 блоков капкан сработает.
3. Цель оглушится на 3 с, после чего капкан исчезает.

## Примечания
- В отличие от Мины, не наносит урона, а даёт союзнику (или врагу) невидимость.
- Радиус срабатывания - 3 блока, длительность невидимости - 10 секунд.
