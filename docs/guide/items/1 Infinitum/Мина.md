# Описание
**Мина** - расходник Бога Постижения, ловушка, наносящая урон при приближении. При срабатывании активируется на 20 тиков и уничтожается. Можно разминировать ножницами или разливанием воды.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Расходник            |
| Длительность активации | 20 тиков        |
| Активация         | Приближение          |
| Радиус эффекта    | 3 блока              |
| Урон              | 25-40                |



## Эффект
При размещении мина срабатывает при приближении любого игрока в радиусе 3 блоков, нанося 10 урона. После срабатывания она активна 20 тиков и затем уничтожается.

## Использование
1. Разместите мину на земле.
2. При приближении цели в радиусе 3 блоков мина сработает.
3. После срабатывания мина исчезает.



## Получение
Крафтится из двух вариантов начинки (камень + редстоун-блок, либо камень + редстоун-блок + паровой кристалл):

- 4x ![Камень](/assets/items/stone.png) Камень
- 2x ![Редстоун-блок](/assets/items/redstone_block.png) Редстоун-блок
- ![Кристалл Края](/assets/items/end_crystal.png) Кристалл Края
- ![Паровой кристалл](/assets/items/custom/big/steam_crystal.png) [Паровой кристалл](/guide/items/1%20Infinitum/Паровой%20кристалл)
