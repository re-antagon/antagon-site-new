# Описание
**Лазуритовый резонатор** - инструмент Бога Постижения, случайным образом зачаровывающий книгу из инвентаря при использовании. Своеобразный «колодец мудрости» для получения случайных чар.

| Характеристика       | Значение |
| -------------------- | -------- |
| Тип предмета         | Инструмент |
| Активация            | Использование |
| Перезарядка          | -        |
| Требуемые книги      | 1        |
| Уровень чар          | 1        |
| Количество чар       | 1        |
| Количество использований | 15   |
| Мерцание             | Да       |



## Эффект
При использовании берёт одну книгу из инвентаря и накладывает на неё случайное зачарование 1-го уровня. Инструмент имеет ограниченное число применений (15) и мерцает при готовности.

## Использование
1. Положите книгу в инвентарь.
2. Возьмите Лазуритовый резонатор в руку.
3. Активируйте (ПКМ) - книга случайно зачаруется.



## Получение
Крафтится из Страниц вечности, песчаника, блока лазурита и Дефектного кристалла памяти:

- 2x ![Песчаник](/assets/items/sandstone.png) Песчаник
- ![Блок лазурита](/assets/items/lapis_block.png) Блок лазурита
- ![Дефектный кристалл памяти](/assets/items/custom/big/defected_memory_crystal.png) [Дефектный кристалл памяти](/guide/items/1%20Infinitum/Дефектный%20кристалл%20памяти)

## Примечания
- Даёт только одно случайное зачарование 1-го уровня за применение.
- Ограничен 15 использованиями, после чего инструмент исчерпан.
- Требует Дефектный кристалл памяти, получаемый из Заряженного кристалла памяти.
