# Описание
**Зелье свечения** - кулинарное зелье Бога Постижения, дающее эффект свечения. Существует в обычном и взрывном (splash) вариантах, а также двух уровней длительности.

| Характеристика  | Значение               |
| --------------- | ---------------------- |
| Тип предмета    | Кулинария / Зелье     |
| Зелья           | обычное, взрывное      |
| Эффект          | свечение               |
| Длительность I  | 1:00                   |
| Длительность II | 3:00                   |

## Используется для
_Не используется в других рецептах (конечный продукт зельеварения)._

## Примечания
- Эффект свечения делает цель видимой в темноте, что полезно в бою и разведке.
- Взрывные варианты позволяют применять эффект на союзников или себя на расстоянии.
