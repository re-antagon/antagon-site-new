# Описание
**Паровой кристалл** - базовый компонент Бога Постижения, насыщенный энергией пара. Служит фундаментальным материалом для множества механизмов и устройств Бога Постижения. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта более сложных предметов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

---

## Получение
Паровой кристалл **не крафтится**. Он добывается путём применения расходника [Ингибитор](/guide/items/1%20Infinitum/Ингибитор) на руду - после воздействия ингибитора руда превращается в паровой кристалл.

- ![Ингибитор](/assets/items/custom/big/inhibitor.png) [Ингибитор](/guide/items/1%20Infinitum/Ингибитор) - применяется на руду для превращения её в паровой кристалл.

- ![Часовой кристалл](/assets/items/custom/big/clock_crystal.png) [Часовой кристалл](/guide/items/1%20Infinitum/Часовой%20кристалл)

## Примечания
- Добыча зависит от наличия [Ингибитора](/guide/items/1%20Infinitum/Ингибитор), который сам является расходником, поэтому запас паровых кристаллов ограничен доступностью ингибиторов.
- Как компонент не обладает собственным действием и применяется только в составе других предметов.

## Связанные предметы
- [Ингибитор](/guide/items/1%20Infinitum/Ингибитор) - расходник для добычи парового кристалла из руды.
- [Заряженный уголь](/guide/items/1%20Infinitum/Заряженный%20уголь) - эффективное топливо (требует Паровой кристалл).
- [Часовой кристалл](/guide/items/1%20Infinitum/Часовой%20кристалл) - компонент управления временем (требует Паровой кристалл).
- [Мина](/guide/items/1%20Infinitum/Мина) - расходник-ловушка (требует Паровой кристалл).
- [Силовой молот](/guide/items/1%20Infinitum/Силовой%20молот) - силовой инструмент (требует Паровой кристалл).
