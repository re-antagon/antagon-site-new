# Описание
**Туннелепроходец** - оружие Бога Постижения, «прорыв в никуда». Прокапывает туннель сквозь блоки.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Оружие       |
| Перезарядка    | 5 с          |
| Активация      | Удар         |
| Зачаровываемое | Нет          |
| Скорость толчка | макс 15 б/с |

---

## Эффект
При ударе прокапывает туннель сквозь блоки (до 15 блоков/сек). Перезарядка - 5 секунд.

## Использование
1. Возьмите туннелепроходец в руку.
2. Ударьте по блоку или цели - прокапывается туннель и происходит отталкивание.
3. После удара перезарядка 5 с.

---
