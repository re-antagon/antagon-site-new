# Описание
**Медная шестерня** - базовый компонент Бога Постижения, «символ прогресса». Служит простейшей деталью механизмов, передающей вращение и входящей во множество инструментальных крафтов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

## Примечания
- Одна из самых востребованных базовых деталей: входит в крафты силовых инструментов и механических узлов.
- Как компонент не обладает собственным действием.
