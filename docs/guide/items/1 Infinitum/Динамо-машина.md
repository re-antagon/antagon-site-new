# Описание
**Динамо-машина** - инструмент Бога Постижения, создающий защитное поле при последовательной активации. Эффект защиты накладывается слоями (до Защиты IV) и постепенно ослабевает со временем.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Инструмент           |
| Перезарядка       | -                    |
| Длительность      | 5 с                  |
| Активация         | Использование        |
| Радиус эффекта    | Себе                 |
| Наложение эффектов | Защита 1-4           |
| Максимум зарядов  | 40                   |
| Штраф зарядов     | 10                   |

---

## Эффект
При использовании накладывает на владельца эффект защиты, уровень которого растёт с каждой последовательной активацией (от Защиты I до Защиты IV). Эффект держится 5 секунд и со временем ослабевает. Каждая активация расходует заряды (до 40), при этом неправильное использование даёт штраф в 10 зарядов.

## Использование
1. Возьмите Динамо-машину в руку.
2. Активируйте (ПКМ) для наложения слоя защиты на себя.
3. Повторяйте активацию для усиления эффекта до Защиты IV.

## Примечания
- Защита накладывается только на владельца (радиус - «Себе»).
- Эффект временный (5 с) и требует накопления зарядов; штраф в 10 зарядов делает важным правильное использование.
- Требует Платиновый лист и Медную шестерню, что связывает его с цепочкой механических компонентов Бога.
