# Описание
**Кристалл памяти** - компонент Бога Постижения, изначально пустой. Расходует 30 уровней опыта на заполнение и превращается в [Заряженный кристалл памяти](/guide/items/1%20Infinitum/Заряженный%20кристалл%20памяти), способный хранить и обменивать опыт.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет (до зарядки) |
| Стакается      | Да           |

---

## Примечания
- Пустой кристалл бесполезен до заполнения опытом (30 уровней).
- Служит первым звеном в цепочке кристаллов памяти, ведущей к дефектным кристаллам для крафтов.
