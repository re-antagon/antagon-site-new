# Описание
**Платиновая шестерня** - продвинутый компонент Бога Постижения, «лучшая из лучших». Служит премиальной деталью механизмов, входящей в сборку Механического сердца.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

## Примечания
- Продвинутая версия Медной шестерни, требующая предварительной очистки платины в листы.
- Как компонент не обладает собственным действием.
