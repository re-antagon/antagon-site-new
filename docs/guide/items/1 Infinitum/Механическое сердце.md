# Описание
**Механическое сердце** - вторичный компонент Механизмов Бога Постижения. Служит связующим узлом, объединяющим трубы, шестерни и корпус механизма в единый работающий блок. Само по себе не имеет активного эффекта и применяется исключительно как материал для крафта более сложных предметов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

---

- 2x ![Платиновая шестерня](/assets/items/custom/big/platinum_gear.png) [Платиновая шестерня](/guide/items/1%20Infinitum/Платиновая%20шестерня)
- ![Заготовка механизма](/assets/items/custom/big/copper_box.png) [Заготовка механизма](/guide/items/1%20Infinitum/Заготовка%20механизма)

## Примечания
- Является вторичным компонентом Механизмов: собирается из более простых деталей (труб, шестерен и корпуса) и в свою очередь входит в крафт расходника [MiH](/guide/items/1%20Infinitum/MiH).
- Как компонент не обладает собственным действием и применяется только в составе других предметов.
