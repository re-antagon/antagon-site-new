# Описание
**Парамагнетический молот** - оружие Бога Постижения в виде булавы, «невольная синергия». Притягивает двух игроков друг к другу при использовании (ПКМ с целеуказанием дважды, либо взмах).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (булава) |
| Активация      | ПКМ (2 раза, целеуказание), взмах |
| Перезарядка    | 15 с     |
| Зачаровываемое | Да       |

---

## Эффект
При использовании притягивает двух выбранных игроков друг к другу, заставляя их сблизиться. Требует двойного целеуказания (ПКМ) или срабатывает при взмахе. Перезарядка - 15 секунд. Можно зачаровывать.

## Использование
1. Возьмите молот в руку.
2. ПКМ по первому игроку, затем ПКМ по второму (целеуказание).
3. Игроки притянутся друг к другу. Перезарядка 15 с.
