# Описание
**Пергамент** - компонент Бога Постижения, «полированная шкура». Служит основой для написания свитков и договоров Бога.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

---

## Используется для
- [Свиток антигравитации](/guide/items/1%20Infinitum/Свиток%20антигравитации)
- Договор Замены
- Договор Ремонта

## Примечания
- Базовый письменный материал Бога, без которого невозможно создание свитков и договоров.
- Как компонент не обладает собственным действием.
