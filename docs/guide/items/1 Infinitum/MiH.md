# Описание
**MiH** - одноразовый расходник Бога Постижения, способный перемотать время всего мира вперед. При активации игровые часы мира принудительно сдвигаются на 12 часов, мгновенно прокручивая цикл дня и ночи для всех игроков на сервере.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Расходник            |
| Перезарядка       | 20 минут (для всех)  |
| Перемотка времени | 12 игровых часов     |
| Стакается         | Нет                  |

---

## Эффект
При использовании время мира принудительно перематывается вперед на 12 игровых часов. Изменение затрагивает весь мир целиком, а не отдельного игрока:

- Меняется фаза дня и ночи - ночь может смениться утром, днем или вечером в зависимости от текущего времени.
- Перемотка действует глобально и одновременно для всех, кто находится в мире.

> Перезарядка общего назначения: повторное применение невозможно, пока не пройдет 20 минут с момента последнего использования предмета любым игроком.

## Использование
1. Возьмите предмет в руку.
2. Активируйте его (ПКМ), чтобы перемотать время мира вперед.
3. После срабатывания предмет расходуется и исчезает из инвентаря.

Поскольку предмет не стакается, для повторного применения потребуется скрафтить новый экземпляр.
