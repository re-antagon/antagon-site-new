# Описание
**Пружина** - компонент Бога Постижения, «колебательный контур». Служит упругим элементом механизмов, передающим усилие и входящим в силовые инструменты.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |

## Примечания
- Упругий элемент, необходимый для силовых и механических устройств Бога.
- Как компонент не обладает собственным действием.
