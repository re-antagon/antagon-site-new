# Описание
**Заряженный кристалл памяти** - расходник Бога Постижения, хранящий уровни опыта. При использовании обменивает накопленный опыт местами. Если применить его вместе с ножницами (только на уровне опыта 15+), кристалл ломается, превращаясь в [Дефектный кристалл памяти](/guide/items/1%20Infinitum/Дефектный%20кристалл%20памяти).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Начальное значение | 15   |

---

## Эффект
Хранит уровни опыта и при активации меняет их местами с владельцем. Начальное значение - 15 уровней. При использовании совместно с ножницами (при уровне опыта 15 и выше) кристалл разрушается, давая дефектный вариант.

## Использование
1. Возьмите кристалл в руку.
2. Активируйте (ПКМ), чтобы обменять опыт местами.
3. Для поломки используйте с ножницами на уровне опыта 15+ - получите дефектный кристалл.

---

## Получение
Заряжается опытом из [Кристалла памяти](/guide/items/1%20Infinitum/Кристалл%20памяти) (изначально пустой кристалл расходует 30 уровней на заполнение).

- ![Кристалл памяти](/assets/items/custom/big/memory_crystal.png) [Кристалл памяти](/guide/items/1%20Infinitum/Кристалл%20памяти) - источник заряженного кристалла.

## Используется для
- ![Дефектный кристалл памяти](/assets/items/custom/big/defected_memory_crystal.png) [Дефектный кристалл памяти](/guide/items/1%20Infinitum/Дефектный%20кристалл%20памяти)

## Примечания
- Служит связующим звеном между хранением опыта и получением дефектных кристаллов для крафтов.
- Поломка требует высокого уровня опыта (15+), что делает дефектные кристаллы ресурсозатратными.
