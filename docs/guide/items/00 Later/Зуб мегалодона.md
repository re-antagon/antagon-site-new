# Описание
При атаке с шансом 50% накладывает кровотечение (3 урона каждые 3 секунды 4 раза)

| Активация          | при ударе                     |
| ------------------ | ----------------------------- |
| Шанс срабатывания  | 50%                           |
| Радиус эффекта     | цель                          |
| Наложение эффектов | кровотечение 12с (3 урона/3с) |
| Урон               | 5                             |
| Диапазон атаки     | Одиночный (топор)             |
| Скорость атаки     | Каменный топор х3             |
| Прочность          | -                             |
# Получение
Дроп из мегалодона
