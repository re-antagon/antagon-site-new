# Описание

**Злой эллей** — союзник, который атакует врагов владельца. Его призывает ![Удочка обречённых душ](/assets/items/custom/models_preview/udochka_obrechennih_dush_gui.png) [удочка обречённых душ](/gods/items/4_finis/Удочка%20обречённых%20душ), когда игрок вытягивает поплавок.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Окончание](/gods/4_finis) |
| Здоровье | 20 хп |
| Урон | 2 |
| Время жизни | 10 минут |
