# Описание

**Каменный миньон** обитает на острове Жизни.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Моб |
| Спавн | Остров Жизни |
| Здоровье | 20 хп |
| Урон | 7 |

## Поведение

Катится к цели, вращаясь. При столкновении наносит 7 урона и слегка отбрасывает её.

## Дроп

Всегда выпадает 3–10 блоков ![Мшистый булыжник](/assets/items/mossy_cobblestone.png) мшистого булыжника. С вероятностью 50% дополнительно выпадает 2–3 ![Азалия](/assets/items/azalea.png) азалии. Миньон также оставляет немного <img src="/assets/utils/Experience_Orb_Value_-32768-2.png" alt="Опыт" width="32" height="32" style="display: inline-block" /> опыта.
