# Описание

**Сфера небесного света** — сфера, которая действует под открытым небом.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Космос](/gods/6_cosm) |
| Здоровье | 10 хп |
| Интервал действия | 1 секунда |

## Поведение

У размещённой [![сферы небесного света](/assets/items/custom/small/sphere_sky_light.png) сферы небесного света](/gods/items/6_cosm/Сфера%20небесного%20света) **10 ХП**. Её можно уничтожить ударами.

Под открытым небом сфера каждую секунду накладывает ![Свечение](/assets/items/glowing.png) свечение на всех в радиусе **20 блоков** и снимает ![Слепота](/assets/items/blindness.png) слепоту и ![Тьма](/assets/items/darkness.png) тьму со всех сущностей в радиусе **10 блоков**.
