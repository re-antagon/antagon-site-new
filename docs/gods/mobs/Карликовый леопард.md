# Описание
**Карликовый леопард** - агрессивный моб, с внешностью обычного оцелота. Обитает в тёплых биомах и охотится стаями, следуя за вожаком.

| Характеристика | Значение |
| -------------- | -------- |
| Тип            | Агрессивный моб |
| Здоровье       | 20 хп |
| Урон           | 10 |
| Спавн          | Тёплые биомы (джунгли, саванны и т.п.) |
| Размер группы  | 3-5 особей |
| Дроп           | Кости, нити, опыт |



## Поведение
Леопарды появляются **группами по 3-5 особей**. В каждой группе есть **альфа**, за которым следуют остальные, поэтому стая всегда передвигается вместе.

Заметив игрока, леопарды нападают всей стаей. По отдельности они не слишком опасны, но вместе наносят очень много уронаы

## Спавн
Появляются в **тёплых биомах**, таких как джунгли и саванны.

Также двое леопардов всегда сопровождают [Браконьера](/gods/mobs/Браконьер) в качестве питомцев.
