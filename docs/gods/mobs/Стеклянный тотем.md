# Описание

**Стеклянный тотем** — размещаемый тотем, который накладывает хрупкость на окружающих.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Искажение](/gods/7_distorta) |
| Здоровье | 50 хп |
| Дистанция до владельца | До 29 блоков |

## Поведение

У размещённого [![стеклянного тотема](/assets/items/custom/small/glass_totem.png) стеклянного тотема](/gods/items/7_distorta/Стеклянный%20тотем) **50 ХП**. Он накладывает [![Хрупкость](/assets/items/glass_pane.png) хрупкость II](/gods/items/7_distorta/Стеклянный%20тотем#эффект-хрупкость) на всех вокруг, кроме владельца. Каждый уровень хрупкости увеличивает урон от удара по игроку на 1. При хрупкости II каждый удар наносит на 2 урона больше.

- Если кто-то другой ударит тотем, владелец получит половину урона, нанесённого тотему.
- Если владелец отойдёт дальше чем на 29 блоков, тотем исчезнет. Владелец получит урон, равный половине **оставшегося здоровья тотема**.
- Владелец может снять тотем одним ударом. При этом тотем выпадет как предмет.
