# Описание

**Мина** — ловушка, которая взрывается при приближении игрока.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Постижение](/gods/1_infinitum) |
| Дистанция срабатывания | Менее 3 блоков |
| Радиус поражения | 10 блоков |
| Урон | 25–30 |

## Срабатывание

После установки [![мина](/assets/items/custom/small/mine.png) мина](/gods/items/1_infinitum/Мина) остаётся на месте. Её нельзя ударить или убить.

Когда игрок подходит **ближе чем на 3 блока**, начинается анимация срабатывания. Радиус взрыва — около 15 блоков. Все сущности в радиусе **10 блоков** получают от 25 до 30 урона. После взрыва мина уничтожается.

Чтобы разминировать её, нажмите ПКМ ![Ножницы](/assets/items/shears.png) ножницами по мине или разлейте на неё ![Ведро воды](/assets/items/water_bucket.png) воду. Обезвреженная мина выпадает как предмет.
