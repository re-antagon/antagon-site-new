# Описание

**Почтовая руна** — руна для передачи предметов между игроками.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Окончание](/gods/4_finis) |
| Рун на сервере | 1 одновременно |
| Время жизни | 1,5 минуты с момента призыва |
| Время на отправку | 30 секунд |
| Время на ответ | 30 секунд |

## Действие руны

[![Почтовая руна](/assets/items/custom/small/post_rune.png) Почтовая руна](/gods/items/4_finis/Почтовая%20руна) передаёт лежащие на земле предметы другому игроку с его согласия. Руну нельзя ударить или убить. Через **1,5 минуты после призыва** руна исчезает сама.

## Как отправить вещи

1. Призовите руну. В чате появится подсказка «Положите предметы на пол в область и впишите имя получателя».
2. Положите вещи в область руны и введите ник получателя в чат. На оба действия даётся **30 секунд**. Полоса вверху экрана показывает оставшееся время.
3. Получатель увидит сообщение «Вам были отправлены вещи от &lt;ник игрока&gt; напишите + если принимаете, - если нет». У него есть ещё **30 секунд** на ответ. Полоса показывает, сколько времени осталось.
4. При ответе `+` вещи перемещаются в инвентарь получателя. Если инвентарь полон, они выпадают под ним на землю. Отправитель видит «Получатель принял ваш запрос». При ответе `-` вещи остаются на месте, руна исчезает, а отправитель видит «Получатель отклонил ваш запрос». В обоих случаях предмет призыва расходуется.

## Ограничения

Одновременно на сервере может действовать одна почтовая руна. При попытке призвать вторую появится сообщение «В мире уже есть одна заспавленная руна, подождите и попробуйте снова».

Если отправитель дважды неправильно введёт имя получателя, руна исчезнет с сообщением «Вы потратили 2 попытки, почтовая руна потратила на вас слишком много времени».
