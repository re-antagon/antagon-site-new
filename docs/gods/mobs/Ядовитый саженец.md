# Описание

**Ядовитый саженец** - статичный моб, выглядящий как ![Саженец тропического дерева](/assets/items/jungle_sapling.png) саженец тропического дерева. Растёт в джунглях и травит всех, кто подойдёт слишком близко.

| Характеристика | Значение |
| -------------- | -------- |
| Тип сущности | Статичный моб |
| Радиус ауры    | 5 блоков |
| Эффект ауры    | Слабый урон + ![Отравление](/assets/items/poison.png) отравление |
| Иммунитеты     | ![Отравление](/assets/items/poison.png) Отравление, ![Иссушение](/assets/items/wither_effect.png) Иссушение |
| Спавн          | Джунгли |
| Дроп           | 1 ![Саженец тропического дерева](/assets/items/jungle_sapling.png) саженец тропического дерева |

## Поведение
Саженец не двигается, но распространяет вокруг себя **ауру**, которая **слабо ранит и отравляет** всех в радиусе **5 блоков**.

Медленно **регенерирует** здоровье и имеет **иммунитет к ![Отравление](/assets/items/poison.png) отравлению и ![Иссушение](/assets/items/wither_effect.png) иссушению**.

## Спавн
Появляется в **джунглях**.
