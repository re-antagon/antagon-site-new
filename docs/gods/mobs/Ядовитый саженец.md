# Описание
**Ядовитый саженец** - статичный моб, выглядящий как саженец тропического дерева. Растёт в джунглях и травит всех, кто подойдёт слишком близко.

| Характеристика | Значение |
| -------------- | -------- |
| Тип            | Статичный моб |
| Радиус ауры    | 5 блоков |
| Эффект ауры    | Слабый урон + отравление |
| Иммунитеты     | Отравление, Иссушение |
| Спавн          | Джунгли |
| Дроп           | 1 саженец тропического дерева |



## Поведение
Саженец не двигается, но распространяет вокруг себя **ауру**, которая **слабо ранит и отравляет** всех в радиусе **5 блоков**.

Медленно **регенерирует** здоровье и имеет **иммунитет к отравлению и иссушению**.

## Спавн
Появляется в **джунглях**.
