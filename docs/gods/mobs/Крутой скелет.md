# Описание

**Крутой скелет** — скелет-лучник, которого призывает скипетр призраков.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Искажение](/gods/7_distorta) |
| Здоровье | 20 хп |
| Время жизни | 1 минута |

## Поведение

[![Скипетр призраков](/assets/items/custom/small/scepter_of_ghosts.png) Скипетр призраков](/gods/items/7_distorta/Скипетр%20призраков) расходует 3 [![Проклятая кость](/assets/items/custom/small/cursed_bone.png) проклятых кости](/gods/items/7_distorta/Проклятая%20кость) и случайно призывает одного из двух помощников. Второй возможный помощник — [Крутой зомби](./Крутой%20зомби). Оба принадлежат к одной фракции.

У помощника **20 ХП**, урон такой же, как у обычного скелета в Minecraft. Он не горит и не исчезает при естественном деспавне. Через минуту после призыва он пропадает.
