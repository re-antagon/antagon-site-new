# Описание
**Мимик** - агрессивный моб, похожий на игрока. Обитает под землёй и выдаёт себя за других игроков, копируя их внешность и никнеймы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип            | Агрессивный моб |
| Оружие         | Меч (вблизи), лук (издалека) |
| Спавн          | Под землёй |
| Особое         | Маскируется под игроков |
| Дроп           | Опыт |



## Поведение
- При появлении мимик **имитирует других игроков** и выглядит как они.
- Когда цель **рядом**, берёт в руки **меч**; когда **далеко** - **лук**.
- Если цель находится **выше**, мимик может **строиться вверх булыжником**, чтобы до неё добраться.
- При получении урона мимик **маскируется под никнейм игрока, который его ударил**. То же самое происходит, когда мимик атакует сам.

## Спавн
Появляется **под землёй**.

## Дроп
- Опыт
