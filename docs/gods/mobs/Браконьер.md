# Описание

**Браконьер** - агрессивный моб в облике игрока, вооружённый ![Арбалет](/assets/items/crossbow.png) арбалетом. Всегда охотится в сопровождении двух ручных [карликовых леопардов](/gods/mobs/Карликовый%20леопард).

| Характеристика | Значение |
| -------------- | -------- |
| Тип сущности | Агрессивный моб |
| Здоровье       | 30 хп |
| Оружие         | ![Арбалет](/assets/items/crossbow.png) Арбалет |
| Спавн          | Тёплые биомы |
| Питомцы        | 2 карликовых леопарда |
| Дроп           | 1-2 ![Поводок](/assets/items/lead.png) поводка, <img src="/assets/utils/Experience_Orb_Value_-32768-2.png" alt="Опыт" width="32" height="32" style="display: inline-block" /> опыт |

## Поведение
Браконьер атакует издалека из **![Арбалет](/assets/items/crossbow.png) арбалета**, пока его питомцы - **два карликовых леопарда** - нападают в ближнем бою.

Пока браконьер жив, он **пассивно лечит и усиливает** своих леопардов.

## Спавн
Появляется в **тёплых биомах**. Всегда спавнится вместе с двумя [карликовыми леопардами](/gods/mobs/Карликовый%20леопард).
