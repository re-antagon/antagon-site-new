# Описание

**Цветочный монстр** обитает на острове Жизни.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Моб |
| Спавн | Остров Жизни |
| Здоровье | 35 хп |
| Урон | 10 |

## Поведение

Неподвижно ждёт в точке появления. Когда цель подходит на 2 блока, монстр кусает её, притягивает к себе и наносит 10 урона.

## Дроп

Немного <img src="/assets/utils/Experience_Orb_Value_-32768-2.png" alt="Опыт" width="32" height="32" style="display: inline-block" /> опыта. С вероятностью 25% выпадает 1 ![Цветок цветочного монстра](/assets/items/allium.png) цветок цветочного монстра, которым можно призвать такого же моба.
