# Описание

**Капкан** — ловушка, которая обездвиживает наступившую в неё цель.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Постижение](/gods/1_infinitum) |
| Радиус срабатывания | 2 блока |
| Урон | 10 сквозь броню |
| Обездвиживание | 3 секунды |

## Срабатывание

[![Шелестящий капкан](/assets/items/custom/small/paper_trap.png) Шелестящий капкан](/gods/items/1_infinitum/Шелестящий%20капкан) остаётся на месте установки. Его нельзя ударить или убить.

Как только в радиусе **2 блоков** оказывается любая сущность, капкан захлопывается. Цель получает **10 урона сквозь броню** и на **3 секунды** теряет возможность двигаться. Сработавший капкан исчезает, а на его месте выпадает предмет призыва.
