# Описание
**Древень** - моб Бога Естества, «живое древо». Служит источником уникальных компонентов: коры, сока, вечнозелёного листа и древесного волокна. При взаимодействии с разными инструментами даёт различные материалы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип сущности   | Моб      |
| Активный эффект | Нет   |
| Источник компонентов | Да |



## Добыча компонентов
В зависимости от используемого инструмента Древень даёт разные материалы:

- [![Кора древня](/assets/items/custom/small/treebeard_bark.png) Кора древня](/gods/items/2_mater/Кора%20древня) - дроп при убийстве топором.
- [![Сок древня](/assets/items/orange_potion.png) Сок древня](/gods/items/2_mater/Сок%20древня) - добывается [![Краник](/assets/items/custom/small/kranik.png) Краником](/gods/items/2_mater/Краник) (ПКМ по Древню при наличии пустой бутылки).
- [![Вечнозелёный лист](/assets/items/custom/small/evergreen_leaf.png) Вечнозелёный лист](/gods/items/2_mater/Вечнозелёный%20лист) - состригается ножницами.
- [![Древесное волокно](/assets/items/custom/small/wood_fiber.png) Древесное волокно](/gods/items/2_mater/Древесное%20волокно) - дроп при убийстве мечом.
