# Описание

**Конь в кубе** — временная ездовая лошадь.

| Характеристика | Значение |
| --- | --- |
| Тип сущности | Болванчик |
| Бог | [Окончание](/gods/4_finis) |
| Время жизни | 5 минут |
| Дроп | Нет |

## Поведение

[![Конь в кубе](/assets/items/custom/small/vacuum_horse.png) Конь в кубе](/gods/items/4_finis/Конь%20в%20кубе) призывает обычную лошадь на **5 минут**. Её нельзя ударить, и она не исчезает при естественном деспавне. Когда время истекает, лошадь пропадает без добычи.

Инвентарь коня закрывается сразу при открытии, поэтому надеть на него свою конскую броню нельзя.
