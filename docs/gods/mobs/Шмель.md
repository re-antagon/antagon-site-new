# Описание
**Шмель** выглядит как уменьшенная пчела. В отличие от обычных пчёл, имеет **неограниченный запас жал**: не теряет жало после удара и не умирает. Защищает того, кто его призвал.

| Характеристика | Значение |
| -------------- | -------- |
| Тип            | Призываемый моб-защитник |
| Здоровье       | 30 хп |
| Урон           | 6 |
| Особое         | Неограниченные жала, усиливающийся яд |
| Спавн          | Не спавнится естественно |
| Дроп           | Нет |



## Поведение
Шмели **защищают того, кто их призвал**, и атакуют его врагов.

При атаке шмель с шансом накладывает отравление, которое может усиливаться с каждым следующим ужаленным ударом:

| Стадия | Эффект |
|:------:|:-------|
| **1** | Отравление I на 5 с |
| **2** | Отравление II на 7.5 с |
| **3** | Отравление III и Иссушение II на 12.5 с |

## Спавн
Не появляется обычными способами. Шмелей можно **призвать частями сета Королевы пчёл**.

Раньше шмели также могли появляться из **больших ульев** в качестве их защитников.

## Дроп
Ничего не выпадает.
