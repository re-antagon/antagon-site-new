# Описание
**Честная монетка** - инструмент Бога Хаоса, «даже не пробуй стрелять». Монетка, которую можно подбросить, чтобы решить свою судьбу: орёл или решка.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | ПКМ |
| Перезарядка    | - |
| Особое         | Подбрасывает монетку (орёл/решка) |

## Использование
1. Возьмите честную монетку в руку.
2. Нажмите ПКМ - монетка подбросится и выпадет орлом или решкой.

::: tip Примечание
Честная монетка - идеальный способ решить спор или принять сложное решение. Впрочем, как и всё у Бога Хаоса, результат всегда случаен.
:::
