# Описание
**Кисть реальности** - инструмент Бога Хаоса, «CMYK». Перекрашивает цветной блок в случайный цвет, внося хаос в любое строение.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | Использование |
| Радиус эффекта | Целевой блок |
| Перезарядка    | Нет |
| Особое         | Перекрашивает большинство цветных блоков |

## Использование
1. Возьмите кисть реальности в руку.
2. Нажмите ПКМ по цветному блоку - он перекрасится в случайный цвет.

::: tip Примечание
Кисть перекрашивает большинство цветных блоков: бетон, шерсть, стекло, керамику и другие. Результат всегда случаен - вы не можете предугадать, в какой цвет окрасится блок.
:::
