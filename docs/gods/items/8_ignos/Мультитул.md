# Описание
**Мультитул** - инструмент Бога Хаоса, «план надёжный как часы». Универсальный инструмент, который при использовании переключается между киркой, лопатой, топором и мотыгой.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | - |
| Особое         | Превращается в следующий инструмент |
| Ротация инструментов | Кирка, лопата, топор, мотыга |
| Основа         | Железо |

## Использование
1. Возьмите мультитул в руку.
2. Нажмите ПКМ - инструмент переключится на следующий в ротации.
3. Ротация: кирка → лопата → топор → мотыга → кирка...

::: tip Примечание
Мультитул позволяет носить с собой сразу четыре инструмента в одном слоте инвентаря. Идеален для путешествий и шахтёрских вылазок.
:::
