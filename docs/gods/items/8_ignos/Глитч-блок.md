# Описание
**Глитч-блок** — блок Бога Хаоса. При разрушении использует один из 5 случайных эффектов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активация      | При разрушении |
| Особый эффект  | 1 из 5 случайных эффектов (лава, вода, динамит, фрагмент реальности) |

---

## Получение
Появляется при превращении обсидиана или плачущего обсидиана с помощью Глитча. Невозможно добыть напрямую.
