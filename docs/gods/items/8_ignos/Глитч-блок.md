# Описание
**Глитч-блок** - компонент Бога Хаоса. Нестабильный блок, созданный из искажённой реальности. При разрушении использует один из пяти случайных эффектов, поэтому добывать его крайне опасно.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активация      | При разрушении |
| Особое         | Использует один из 5 эффектов |

## Эффекты при разрушении

| Эффект | Результат |
| ------ | --------- |
| Эффект 1 | Заменяет себя на блок лавы |
| Эффект 2 | Заменяет себя на блок воды |
| Эффект 3 | Взрывается как динамит |
| Эффект 4 | Дропает ![Фрагмент реальности](/assets/items/custom/small/reality_fragment.png) [фрагмент реальности](/gods/items/8_ignos/Фрагмент%20реальности) |

::: danger Осторожно
Глитч-блок непредсказуем: при разрушении он может взорваться, как динамит, или залить всё лавой. Подходите к нему с осторожностью!
:::

## Получение
Появляется при превращении обсидиана или плачущего обсидиана с помощью ![Глитч](/assets/items/custom/small/glitch.png) [Глитча](/gods/items/8_ignos/Глитч). Невозможно добыть обычными инструментами.
