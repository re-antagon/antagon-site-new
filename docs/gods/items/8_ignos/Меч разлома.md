# Описание
**Меч разлома** - оружие Бога Хаоса, «синяя изолента». Нестабильный меч, который при ударе может утроить урон, поджечь врага, призвать молнию или... просто сломаться.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | При ударе |
| Перезарядка    | - |
| Особое         | Использует один из четырёх эффектов |

## Эффекты при ударе

| Эффект | Результат |
| ------ | --------- |
| Эффект 1 | Урон удара x3 |
| Эффект 2 | Призыв молнии |
| Эффект 3 | Удар поджигает цель |
| Эффект 4 | Меч ломается (без удара) |

::: danger Осторожно
Меч разлома крайне непредсказуем: в любой момент он может сломаться прямо в руках, не нанеся урона. Но если удача на вашей стороне, он способен утроить урон или призвать молнию на врага.
:::

## Использование
1. Возьмите меч разлома в руку.
2. Атакуйте цель - меч применит один из четырёх случайных эффектов.
