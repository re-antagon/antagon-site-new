# Описание
**Глитч** - компонент Бога Хаоса, «нестерпимый шум». Сгусток хаотической магии, способный искажать реальность. При использовании превращает обсидиан или плачущий обсидиан в глитч-блок.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активация      | При использовании |
| Радиус эффекта | Целевой блок |
| Особое         | Превращает обсидиан или плачущий обсидиан в глитч-блок |

## Эффект
При использовании на блоке обсидиана или плачущего обсидиана превращает его в [глитч-блок](/gods/items/8_ignos/Глитч-блок).

## Получение
Выпадает при убийстве мобов [Неколлинеарным мечом](/gods/items/8_ignos/Неколлинеарный%20меч).
