# Описание
**Неколлинеарный меч** - оружие Бога Хаоса, «векторная сумма». Меч, который наносит случайный урон от 0.1x до 2x от базового. При убийстве моба с высокой вероятностью выпадает глитч.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | При ударе |
| Перезарядка    | - |
| Множитель урона | 0.1 - 2x |
| Дополнительный дроп при убийстве | Глитч |
| Урон           | Железный меч |
| Прочность      | Железный меч |

## Эффект
При ударе наносит случайный урон в диапазоне от **0.1x** до **2x** от базового урона железного меча. При убийстве моба выпадает [глитч](/gods/items/8_ignos/Глитч).

::: danger Осторожно
Неколлинеарный меч непредсказуем: один удар может нанести лишь десятую часть урона, а следующий - удвоенный. Но именно он - единственный источник глитча.
:::

## Использование
1. Возьмите неколлинеарный меч в руку.
2. Атакуйте цель - урон будет случайным.
3. Убивайте мобов, чтобы получать глитч.
