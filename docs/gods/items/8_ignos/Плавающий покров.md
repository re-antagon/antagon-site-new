# Описание
**Плавающий покров** - броня Бога Хаоса, «мы у случая прекрасного в гостях!». Полный сет брони, который хаотично защищает владельца: множитель получаемого урона случаен и зависит от количества надетых элементов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (броня) |
| Активация      | При уроне, при ношении |
| Перезарядка    | - |
| Особое         | Случайный множитель урона |
| Множитель урона (мин.) | 1 - 0.2 × (надето элементов) |
| Множитель урона (макс.) | 1.2 + 0.2 × (надето элементов) |
| Уровень брони  | Кожаная |
| Прочность      | - |

## Эффект
При получении урона броня применяет случайный множитель в диапазоне от **1 - 0.2 × N** до **1.2 + 0.2 × N**, где **N** - количество надетых элементов брони.

| Надето элементов | Множитель урона (мин.) | Множитель урона (макс.) |
|:----------------:|:----------------------:|:------------------------:|
| 1 | 0.8 | 1.4 |
| 2 | 0.6 | 1.6 |
| 3 | 0.4 | 1.8 |
| 4 | 0.2 | 2.0 |

::: danger Осторожно
Чем больше элементов покрова надето, тем шире диапазон случайного множителя. Полный сет может как снизить урон до 0.2x, так и удвоить его. Хаос не знает пощады!
:::

## Использование
1. Наденьте элементы плавающего покрова.
2. При получении урона броня применит случайный множитель.
