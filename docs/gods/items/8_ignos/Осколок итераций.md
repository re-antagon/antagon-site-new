# Описание
**Осколок итераций** - расходник Бога Хаоса, «одноразовая посуда». Нестабильный осколок, который при использовании с шансом 50% удваивается, давая два осколка вместо одного.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | ПКМ |
| Перезарядка    | - |
| Шанс активации | 50% |
| Особое         | Даёт 2 осколка итераций |
| Прочность      | 1 |

## Эффект
При использовании (ПКМ) с шансом **50%** даёт **2 осколка итераций** вместо одного. Предмет расходуется при использовании.

::: tip Примечание
Осколок итераций - одноразовый предмет. При неудачном броске он просто исчезает, при удачном - удваивается. Отличный способ размножить ресурс, если удача на вашей стороне.
:::

## Получение
Выпадает из любой руды при добыче без шёлкового касания с шансом **1%**.
