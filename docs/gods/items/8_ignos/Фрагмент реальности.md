# Описание
**Фрагмент реальности** - компонент Бога Хаоса, «теория всего». Осколок искажённой реальности, выпадающий из глитч-блоков. Используется для крафта инструментов Хаоса.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

## Получение
Выпадает из ![Глитч-блок](/assets/items/custom/small/glitch_block.png) [глитч-блока](/gods/items/8_ignos/Глитч-блок) при его разрушении.

- ![Мультитул](/assets/items/iron_pickaxe.png) [Мультитул](/gods/items/8_ignos/Мультитул)
