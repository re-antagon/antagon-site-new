# Описание
**Сломанный жезл** - компонент Бога Постижения, «потерянная мощь». Служит восстанавливаемой основой для сборки Лазуритового резонатора.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Крафтится из медной шестеренки и громоотводов:

- ![Медная шестерня](/assets/items/custom/big/copper_cog.png) [Медная шестерня](/gods/items/1_infinitum/Медная%20шестерня)
- 2х ![Громоотвод](/assets/items/lightning_rod.png) Громоотвод

## Примечания
- Промежуточный компонент, собираемый из частей сломанного жезла.
- Как компонент не обладает собственным действием.
