# Описание
**Часовой кристалл** - компонент Бога Постижения, основанный на энергии пара и редстоуна. Служит ключевой деталью в механизмах, связанных с управлением временем и прокладкой туннелей. Сам по себе не имеет активного эффекта и используется исключительно как материал для крафта более сложных предметов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Крафтится из следующих компонентов:
- 4x ![Редстоун](/assets/items/redstone_block.png) Редстоун блок 
- 4x ![Паровой кристалл](/assets/items/custom/small/steam_crystal.png) [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл)

## Примечания
- Является промежуточным компонентом: без него невозможно скрафтить ни расходник [MiH](/gods/items/1_infinitum/MiH), ни инструмент [Туннелепроходец](/gods/items/1_infinitum/Туннелепроходец).
- Как компонент не обладает собственным действием и применяется только в составе других предметов.



## Связанные предметы
- [MiH](/gods/items/1_infinitum/MiH) - расходник, перематывающий время мира (требует Часовой кристалл).
- [Туннелепроходец](/gods/items/1_infinitum/Туннелепроходец) - инструмент для прокладки туннелей (требует Часовой кристалл).
- [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл) - основной расходуемый материал в рецепте.
