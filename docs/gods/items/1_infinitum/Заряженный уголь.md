# Описание
**Заряженный уголь** - эффективное топливо Бога Постижения, получаемое путём насыщения обычного угля энергией пара. Горит значительно дольше стандартного топлива.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Время горения  | 800 с    |



## Получение
Крафтится по 8 штук из угля и [Парового кристалла](/gods/items/1_infinitum/Паровой%20кристалл):

- ![Паровой кристалл](/assets/items/custom/small/steam_crystal.png) [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл)

## Примечания
- Время горения 800 секунд делает его одним из самых долговечных видов топлива Бога.
- Требует [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл), добыча которого зависит от Ингибитора.
