# Описание
**Гаечный ключ** - инструмент Бога Постижения, предназначенный для точной настройки стендов для брони, рамок предметов и некоторых механизмов. Позволяет вращать и фиксировать декоративные и функциональные объекты в нужном положении.

| Характеристика | Значение        |
| -------------- | --------------- |
| Тип предмета   | Инструмент      |
| Активный эффект | Настройка объектов |
| Стакается      | Нет             |

Крафтится из железных слитков в следующем порядке:

## Примечания
- Является вспомогательным инструментом для тонкой настройки стендов, рамок и механизмов.
- Входит в крафт [Заготовки механизма](/gods/items/1_infinitum/Заготовка%20механизма) как компонент сборки корпуса.
