# Описание
**Кристалл памяти** - компонент Бога Постижения, изначально пустой. Расходует 30 уровней опыта на заполнение и превращается в [Заряженный кристалл памяти](/gods/items/1_infinitum/Заряженный%20кристалл%20памяти), способный хранить и обменивать опыт.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет (до зарядки) |
| Стакается      | Да           |



## Получение
Крафтится из осколков аметиста и бутылки опыта:

- 5x ![Осколок аметиста](/assets/items/amethyst_shard.png) Осколок аметиста
- ![Бутылка опыта](/assets/items/experience_bottle.png) Бутылка опыта

## Используется для
- ![Заряженный кристалл памяти](/assets/items/custom/small/powerd_crystal.png) [Заряженный кристалл памяти](/gods/items/1_infinitum/Заряженный%20кристалл%20памяти)

## Примечания
- Пустой кристалл бесполезен до заполнения опытом (30 уровней).
- Служит первым звеном в цепочке кристаллов памяти, ведущей к дефектным кристаллам для крафтов.



## Связанные предметы
