# Описание
**Необычное зелье** - базовый компонент зельеварения Бога Постижения, «неожиданный результат». Служит основой для варки [Зелья свечения](/gods/items/1_infinitum/Зелье%20свечения). Существует в обычном и взрывном (splash) вариантах.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Варианты       | обычное, взрывное |

## Примечания
- Является промежуточным звеном зельеварения Бога.
- Взрывной вариант получается добавлением пороха, как и в стандартном зельеварении.
