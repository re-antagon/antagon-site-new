# Бог Постижения

Предметы **Бога Постижения** (Infinitum) - уникальные инструменты, оружие, расходники и компоненты сервера Re:Antagon. Механика Бога Постижения строится вокруг пара, механизмов и манипуляций временем: от добычи паровых кристаллов через [Ингибитор](/gods/items/1_infinitum/Ингибитор) до перемотки времени мира предметом [MiH](/gods/items/1_infinitum/MiH).

::: info Сводка
Всего предметов: **28**. Ниже они сгруппированы по назначению. Каждая карточка ведет на подробную страницу с описанием, эффектом и рецептом крафта.
:::
