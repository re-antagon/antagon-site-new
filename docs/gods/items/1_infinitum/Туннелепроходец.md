# Описание
**Туннелепроходец** - оружие Бога Постижения, «прорыв в никуда». Прокапывает туннель сквозь блоки.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Оружие       |
| Перезарядка    | 15 с          |
| Активация      | ПКМ         |
| Зачаровываемое | Нет          |
| Скорость толчка | макс 15 б/с |



## Эффект
На ПКМ прокапывает туннель сквозь блоки (до 15 блоков/сек). Перезарядка - 5 секунд.

## Использование
1. Возьмите туннелепроходец в руку.
2. ПКМ по блоку - прокапывается туннель.
3. После удара перезарядка 15 с.
