# Описание
**Страница вечности** - компонент Бога Постижения, «вечная страница». Служит мистической основой для сборки Лазуритового резонатора.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Может выпасть при добыче книжных полок с шансом в **5%**.

## Используется для
- ![Лазуритовый резонатор](/assets/items/custom/small/lapis_rezonator.png) [Лазуритовый резонатор](/gods/items/1_infinitum/Лазуритовый%20резонатор)
- ![Шелестящий капкан](/assets/items/custom/small/paper_trap.png) [Шелестящий капкан](/gods/items/1_infinitum/Шелестящий%20капкан)

## Примечания
- Мистический компонент, требующий золотого самородка для «вечной» связи.
- Как компонент не обладает собственным действием.
