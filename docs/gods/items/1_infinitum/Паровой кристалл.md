# Описание
**Паровой кристалл** - базовый компонент Бога Постижения, насыщенный энергией пара. Служит фундаментальным материалом для множества механизмов и устройств Бога Постижения. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта более сложных предметов.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Паровой кристалл **не крафтится**. Он добывается путём применения расходника [Ингибитор](/gods/items/1_infinitum/Ингибитор) на руду - после воздействия ингибитора руда превращается в паровой кристалл.

- ![Ингибитор](/assets/items/custom/big/inhibitor.png) [Ингибитор](/gods/items/1_infinitum/Ингибитор) - применяется на руду для превращения её в паровой кристалл.

## Примечания
- Добыча зависит от наличия [Ингибитора](/gods/items/1_infinitum/Ингибитор), который сам является расходником, поэтому запас паровых кристаллов ограничен доступностью ингибиторов.
- Как компонент не обладает собственным действием и применяется только в составе других предметов.



## Связанные предметы
- [Ингибитор](/gods/items/1_infinitum/Ингибитор) - расходник для добычи парового кристалла из руды.
- [Заряженный уголь](/gods/items/1_infinitum/Заряженный%20уголь) - эффективное топливо (требует Паровой кристалл).
- [Часовой кристалл](/gods/items/1_infinitum/Часовой%20кристалл) - компонент управления временем (требует Паровой кристалл).
- [Мина](/gods/items/1_infinitum/Мина) - расходник-ловушка (требует Паровой кристалл).
- [Силовой молот](/gods/items/1_infinitum/Силовой%20молот) - силовой инструмент (требует Паровой кристалл).
