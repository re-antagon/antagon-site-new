# Описание
**Пергамент** - компонент Бога Постижения, «полированная шкура». Служит основой для написания свитков и договоров Бога.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Крафтится из шариков глины и кожи:

- 3x ![Шарик глины](/assets/items/clay_ball.png) Шарик глины
- ![Кожа](/assets/items/leather.png) Кожа

## Используется для
- [Свиток антигравитации](/gods/items/1_infinitum/Свиток%20антигравитации)
- Договор Замены
- Договор Ремонта

## Примечания
- Базовый письменный материал Бога, без которого невозможно создание свитков и договоров.
- Как компонент не обладает собственным действием.



## Связанные предметы
- [Свиток антигравитации](/gods/items/1_infinitum/Свиток%20антигравитации) - требует Пергамент.
- Договор Замены - требует Пергамент.
- Договор Ремонта - требует Пергамент.
