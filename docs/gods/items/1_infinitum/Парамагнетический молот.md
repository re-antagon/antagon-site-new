# Описание
**Парамагнетический молот** - оружие Бога Постижения в виде булавы, «невольная синергия». Притягивает двух игроков друг к другу при использовании (ПКМ с выбором 1-ой цели и ЛКМ с выбором 2-ой цели).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (булава) |
| Активация      | ПКМ (1-ая цель), ЛКМ (2-ая цель) |
| Перезарядка    | 15 с     |
| Зачаровываемое | Да       |



## Эффект
При использовании притягивает двух выбранных игроков друг к другу, заставляя их сблизиться. Требует двойного целеуказания ЛКМ и ПКМ. Перезарядка - 15 секунд. Можно зачаровывать.

## Использование
1. Возьмите молот в руку.
2. ПКМ по первому игроку, затем ЛКМ по второму (целеуказание).
3. Игроки притянутся друг к другу. Перезарядка 15 с.

## Примечания
- Притягивает именно двух игроков, что полезно для сближения союзников или стягивания врагов.
- Зачаровываемое оружие, совместимое с чарами булавы.
