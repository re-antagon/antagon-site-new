# Описание
**Дефектный кристалл памяти** - расходный компонент Бога Постижения, получаемый при повреждении заряженного кристалла памяти. Несмотря на «дефект», он служит важным материалом для крафта продвинутых устройств.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Расходник    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение
Выпадает при ломании [Заряженного кристалла памяти](/gods/items/1_infinitum/Заряженный%20кристалл%20памяти) (использование с ножницами на уровне опыта 15+).

- ![Заряженный кристалл памяти](/assets/items/custom/small/powerd_crystal.png) [Заряженный кристалл памяти](/gods/items/1_infinitum/Заряженный%20кристалл%20памяти) - источник дефектного кристалла при поломке.

## Используется для
- ![Свиток антигравитации](/assets/items/custom/small/antigravity_scroll.png) [Свиток антигравитации](/gods/items/1_infinitum/Свиток%20антигравитации)
- ![Лазуритовый резонатор](/assets/items/custom/small/lapis_rezonator.png) [Лазуритовый резонатор](/gods/items/1_infinitum/Лазуритовый%20резонатор)

## Примечания
- Является побочным продуктом работы с кристаллами памяти и не крафтится напрямую.
- Несмотря на название, активно применяется в рецептах свитков и резонаторов Бога Постижения.
