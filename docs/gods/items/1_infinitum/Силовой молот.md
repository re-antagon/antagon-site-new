# Описание
**Силовой молот** - оружие Бога Постижения, «пневматическая мощь». Отталкивает цель без урона и мгновенно ломает блоки за один удар.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Оружие       |
| Перезарядка    | 5 с          |
| Активация      | Удар         |
| Радиус эффекта | Цель         |
| Зачаровываемое | Нет          |
| Урон           | 0            |
| Скорость толчка | макс 15 б/с |



## Эффект
При ударе отталкивает цель мощным толчком (до 15 блоков/сек) без нанесения урона. Также мгновенно ломает блоки за один удар, что делает его эффективным инструментом разрушения. Перезарядка - 5 секунд.

## Использование
1. Возьмите молот в руку.
2. Ударьте цель или блок - произойдёт отталкивание и разрушение.
3. После удара перезарядка 5 с.

## Примечания
- Не наносит урона, но мощно отталкивает и ломает блоки - идеален для прорыва и контроля пространства.
- Не зачаровывается.
- Требует Паровой кристалл, добыча которого зависит от Ингибитора.
