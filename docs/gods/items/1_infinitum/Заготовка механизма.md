# Описание
**Заготовка механизма** - корпусной компонент Бога Постижения, «корпус без начинки». Служит базовым каркасом для сборки более сложных механизмов, таких как Механическое сердце.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Компонент    |
| Активный эффект | Нет        |
| Стакается      | Да           |



## Получение

## Используется для
- ![Механическое сердце](/assets/items/custom/big/mechanic_heart.png) [Механическое сердце](/gods/items/1_infinitum/Механическое%20сердце)

## Примечания
- Является промежуточным корпусом: без него невозможно собрать [Механическое сердце](/gods/items/1_infinitum/Механическое%20сердце).
- Как компонент не обладает собственным действием и применяется только в составе других предметов.



## Связанные предметы
- [Механическое сердце](/gods/items/1_infinitum/Механическое%20сердце) - требует Заготовку механизма.
