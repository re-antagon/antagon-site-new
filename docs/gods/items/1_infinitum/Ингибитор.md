# Описание
**Ингибитор** - расходник Бога Постижения, применяемый на руду для её превращения в [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл). Основной инструмент добычи базового материала Бога.

| Характеристика | Значение     |
| -------------- | ------------ |
| Тип предмета   | Расходник    |
| Активный эффект | Превращение руды в паровой кристалл |
| Стакается      | Да           |



## Эффект
При использовании на руде превращает её в паровой кристалл. Расходуется за одно применение.

## Использование
1. Возьмите Ингибитор в руку.
2. Активируйте (ПКМ) на руде.
3. Руда превращается в паровой кристалл, ингибитор расходуется.



## Получение
Крафтится из медных слитков, Трубы механизма, воды и пороха:

- 2x ![Труба механизма](/assets/items/custom/big/copper_pipe.png) [Труба механизма](/gods/items/1_infinitum/Труба%20механизма)

## Используется для
- ![Паровой кристалл](/assets/items/custom/big/steam_crystal.png) [Паровой кристалл](/gods/items/1_infinitum/Паровой%20кристалл)

## Примечания
- Является ключевым расходником: без него невозможно добывать паровые кристаллы, от которых зависит большинство крафтов Бога.
- Расходуется при каждом применении, поэтому запас паровых кристаллов ограничен количеством ингибиторов.
