# Описание
**Тотем Кровавого долга** - инструмент Бога Искажения, «собирай пластыри». Тотем бессмертия, снижает здоровье и усиливает атаки.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При удержании |
| Радиус эффекта | Себе |
| Перезарядка    | - |
| Длительность эффекта | - |
| Наложение эффектов | -6 макс хп, +1 наносимый урон |
| Основа          | Тотем бессмертия |

---

## Эффект
При удержании в руке снижает максимальное здоровье владельца на **6 хп**, но увеличивает наносимый урон на **+1**. Основа - тотем бессмертия.

## Использование
1. Возьмите тотем в руку.
2. Получите +1 к урону ценой 6 максимального здоровья.
