# Описание
**Проклятый слиток** - компонент Бога Искажения, «лавовый реактор». Служит проклятым металлическим слитком, используемым для крафта оружия и жезлов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

Крафтится из проклятых костей и ведра лавы:
