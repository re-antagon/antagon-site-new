# Описание
**Незавершённый договор** - расходник Бога Искажения, «теперь твоя очередь». Мощно лечит, но после получения урона вскоре убивает.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | 2 мин |
| Радиус эффекта | Себе |
| Наложение эффектов | Дыхание смерти, 1 мин |
| Лечение        | 40 хп |

---

## Эффект: Дыхание смерти

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При уроне |
| Отложенное срабатывание | 30 с |
| Наложение эффектов | Смерть |
| Отложенный эффект оффлайн | Да |

::: warning Осторожно
После использования вы получаете 40 хп лечения, но эффект **Дыхание смерти** убьёт вас через 30 секунд после получения любого урона. Даже оффлайн!
:::

## Использование
1. Возьмите договор в руку.
2. Активируйте (ПКМ) - получите 40 хп лечения.
3. Избегайте урона, иначе через 30 секунд наступит смерть.
