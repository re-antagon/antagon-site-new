# Описание
**Свеча Пронзания** - предмет Бога Искажения, «Мы едем на шашлыки». Запускает пронзающий снаряд, который усиливается с каждым пробитием Цена: 4 сердца

| Активация                      | при использовании |
| ------------------------------ | ----------------- |
| Перезарядка                    | -                 |
| Расход хп на использование     | 8                 |
| Урон снаряда                   | 4                 |
| Усиление снаряда при попадании | 4                 |
| Пронзание                      | Да                |
| Размер стака                   | 64                |
