# Описание
**Свеча Пронзания** - расходник Бога Искажения, «мы едем на шашлыки». Запускает пронзающий снаряд, который усиливается с каждым пробитием. Цена: 4 сердца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Расход хп на использование | 8 |
| Урон снаряда   | 4 |
| Усиление снаряда при попадании | 4 |
| Пронзание      | Да |
| Размер стака   | 64 |

---

## Эффект
При использовании (ПКМ) запускает пронзающий снаряд с уроном 4. При каждом пробитии цели урон увеличивается на **+4**. Использование стоит **8 хп** (4 сердца).

## Использование
1. Возьмите свечу в руку.
2. Активируйте (ПКМ) - запустится пронзающий снаряд.
3. С каждым пробитием урон растёт.
