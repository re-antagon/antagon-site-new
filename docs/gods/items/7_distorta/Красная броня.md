# Описание
**Красная броня** - предмет Бога Искажения, «Целиком не стоит того». Иногда призывает лужи крови при уроне

| Активация      | при ношении, при уроне |
| -------------- | ---------------------- |
| Перезарядка    | нет                    |
| Шанс активации | 5% (каждый компонент)  |
| Особое         | Спавнит Лужу крови     |
| Основа         | алмаз                  |
