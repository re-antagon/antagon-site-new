# Описание
**Свеча Проклятия** - расходник Бога Искажения, «палки в колёса». Накладывает Проклятие по области. При любом действии наносит урон, также увеличивает входящий урон. Цена: 2 сердца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Расход хп на использование | 4 |
| Радиус эффекта | 5 блоков + себе |
| Наложение эффекта | Проклятие, 20 с |
| Размер стака   | 64 |

---

## Эффект: Проклятие

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При использовании, при взмахе, при уроне |
| Радиус эффекта | Себе |
| Урон           | 1 (неблокируемый) |

## Использование
1. Возьмите свечу в руку.
2. Активируйте (ПКМ) - все в радиусе 5 блоков получают Проклятие на 20 с.
3. Проклятые получают 1 неблокируемый урон при любом действии.
