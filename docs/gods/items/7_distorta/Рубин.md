# Описание
**Рубин** - компонент Бога Искажения, «он всё ещё зелёный». Служит красным драгоценным камнем, выпадающим с жителей. Используется для крафта брони, колец и тотемов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

## Получение
Крафтится из изумрудов, сгутстков крови и полой кости:

- 4x ![Сгусток крови](/assets/items/custom/big/blood_ball.png) [Сгусток крови](/gods/items/7_distorta/Сгусток%20крови)
- 4x ![Изумруд](/assets/items/emerald.png) Изумруд
- ![Полая кость](/assets/items/custom/big/blood_hollow_bone.png) [Полая кость](/gods/items/7_distorta/Полая%20кость)
