# Описание
**Свеча Скачка** - расходник Бога Искажения, «это всё ещё ты?». Мгновенно перемещает на 5 блоков по курсору. Цена: 2 сердца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Расход хп на использование | 4 |
| Особое         | Телепортирует вперёд |
| Дистанция эффекта | 5 блоков |
| Размер стака   | 64 |

---

## Эффект
При использовании (ПКМ) мгновенно телепортирует владельца на **5 блоков** вперёд по направлению взгляда. Использование стоит **4 хп** (2 сердца).

## Использование
1. Возьмите свечу в руку.
2. Активируйте (ПКМ) - телепорт вперёд на 5 блоков.
