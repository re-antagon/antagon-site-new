# Описание
**Чаша крови** - расходник Бога Искажения, «пакет крови и самогонный аппарат!». Требует 5 сердец для наполнения. В наполненном виде раскидывает перед владельцем 5 луж крови.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Стакается      | Нет |
| Расход хп для наполнения | 10 |
| Особое (в наполненном виде) | Призывает 5 луж крови |

---

## Эффект
Пустая чаша наполняется кровью владельца за **10 хп** (5 сердец). В наполненном виде при использовании (ПКМ) призывает **5 луж крови** перед владельцем.

## Использование
1. Возьмите пустую чашу в руку.
2. Активируйте (ПКМ) - чаша наполнится кровью за 10 хп.
3. Активируйте наполненную чашу - призовутся 5 луж крови.
