# Описание
**Кольцо Кровавого долга** - инструмент Бога Искажения, «доминируй». Сильно ускоряет владельца, когда связанный игрок держит Тотем Кровавого долга.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При удержании |
| Перезарядка    | ? |
| Условие активации | Связанный игрок держит Тотем Кровавого долга |
| Радиус эффекта | Себе |
| Наложение эффекта | Скорость IV |

---

## Эффект
При удержании в руке накладывает на владельца эффект **Скорости IV**, если связанный игрок держит [Тотем Кровавого долга](/gods/items/7_distorta/Тотем%20Кровавого%20долга).

## Использование
1. Возьмите кольцо в руку.
2. Убедитесь, что связанный игрок держит Тотем Кровавого долга.
3. Скорость IV срабатывает автоматически.
