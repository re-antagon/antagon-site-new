# Описание
**Свеча Восполнения** - расходник Бога Искажения, «пулемёт не завезли». Запускает снаряд, создающий лужу крови. Цена: 1 сердце.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | - |
| Расход хп на использование | 2 |
| Дальность снаряда | 10 блоков |
| Урон снаряда   | 2 |
| Призыв при попадании | Лужа крови |
| Размер стака   | 64 |

---

## Эффект
При использовании (ПКМ) запускает снаряд на 10 блоков, наносящий 2 урона. При попадании призывает [Лужу крови](/gods/items/7_distorta/Лужа%20крови). Использование стоит **2 хп** (1 сердце).

## Использование
1. Возьмите свечу в руку.
2. Активируйте (ПКМ) - запустится снаряд.
3. При попадании появится лужа крови.
