# Описание
**Свеча Восполнения** - предмет Бога Искажения, «Пулемёт не завезли». Запускает снаряд создающий лужу крови Цена: 1 сердце

| Активация                  | при использовании |
| -------------------------- | ----------------- |
| Перезарядка                | -                 |
| Расход хп на использование | 2                 |
| Дальность снаряда          | 10 блоков         |
| Урон снаряда               | 2                 |
| Призыв при попадании       | Лужа крови        |
| Размер стака               | 64                |
