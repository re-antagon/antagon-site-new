# Описание
**Кровопускатель** - оружие Бога Искажения, «отбеливатель». При ударах оставляет лужи крови.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | При ударе |
| Перезарядка    | - |
| Шанс активации | 20% |
| Особое         | Спавнит Лужу крови |
| Урон           | Алмазный меч |
| Прочность      | Алмазный меч |

---

## Эффект
При ударе с шансом **20%** спавнит ![Лужа крови](/assets/items/custom/big/blood_ball.png) [Лужу крови](/gods/items/7_distorta/Лужа%20крови). Урон и прочность соответствуют алмазному мечу.

## Использование
1. Возьмите меч в руку.
2. Атакуйте цель - с шансом 20% появится лужа крови.

---

## Получение
Крафтится из полых костей с кровью и алмазного меча:

- 3x ![Полая кость с кровью](/assets/items/custom/big/blood_hollow_bone.png) [Полая кость](/gods/items/7_distorta/Полая%20кость)
- ![Алмазный меч](/assets/items/diamond_sword.png) Алмазный меч
