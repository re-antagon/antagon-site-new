# Описание
**Сердце Жертвы** - инструмент Бога Искажения, «красный телефон». При получении урона иногда лечит и даёт голод.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При удержании, при уроне |
| Перезарядка    | 5 с |
| Наложение эффектов | Лечение 4 хп, Голод I, 1,5 с |

---

## Эффект
При получении урона лечит владельца на **4 хп** и накладывает **Голод I** на 1,5 секунд. Перезарядка - 5 секунд.

## Использование
1. Держите сердце в руке.
2. При получении урона есть шанс получить мощное лечение ценой голода.
