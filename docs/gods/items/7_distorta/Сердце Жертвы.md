# Описание
**Сердце Жертвы** - предмет Бога Искажения, «Красный телефон». При получении урона иногда лечит и даёт голод

| Активация          | при удержании, при уроне  |
| ------------------ | ------------------------- |
| Шанс активации     | 30%                       |
| Перезарядка        | 5с                        |
| Наложение эффектов | лечение 40хп, голод 1 10с |
