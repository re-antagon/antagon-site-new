# Описание
**Плащ Могильщика** - броня Бога Искажения, «чёрный селезень». Даёт силу в пещерах и в незере, усиливает горение.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | При ношении |
| Радиус эффекта | Себе |
| Наложение эффектов | +1 урон от горения |
| Наложение эффектов (с условием) | Сила I |
| Условие эффекта | В верхнем мире (ниже 48 высоты) или в незере |
| Основа          | Элитры |

---

## Эффект
При ношении плащ усиливает урон от горения на **+1**. В верхнем мире ниже высоты 48 или в незере дополнительно даёт ![Сила](/assets/items/strength.png) **Силу I**. Основа - элитры.

## Использование
1. Наденьте плащ в слот нагрудника.
2. В пещерах или незере сила срабатывает автоматически.
