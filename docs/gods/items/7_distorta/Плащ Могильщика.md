# Описание
**Плащ Могильщика** - предмет Бога Искажения, «Чёрный селезень». Даёт силу в пещерах и в незере, усиливает горение

| Активация                       | При ношении                                  |
| ------------------------------- | -------------------------------------------- |
| Перезарядка                     | 20 тиков                                     |
| Радиус эффекта                  | себе                                         |
| Наложение эффектов              | +1 урон от горения                           |
| Наложение эффектов (с условием) | Сила 1                                       |
| Условие эффекта                 | в верхнем мире (ниже 48 высоты) или в незере |
| Основа                          | Элитры                                       |
