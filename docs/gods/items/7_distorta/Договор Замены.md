# Описание
**Договор Замены** - инструмент Бога Искажения, «немного не в себе». При использовании рядом с игроком, держащим такой же договор, связывает обоих эффектом. При повторном использовании меняет игроков местами.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 5 мин |
| Радиус эффекта | 4 блока + себе |
| Наложение эффектов | Договор Замены, 5 мин |

---

## Эффект: Договор Замены

| Характеристика | Значение |
| -------------- | -------- |
| Активация      | При использовании Договора Замены |
| Радиус эффекта | Связанный игрок |
| Особое         | Меняет игроков местами |
| Прекращение эффекта | При потере Договора Замены одним из игроков |
| При завершении эффекта | Даёт Незавершённый договор, уничтожение Договора Ремонта |

## Использование
1. Возьмите договор в руку.
2. Активируйте (ПКМ) рядом с игроком, держащим такой же договор - вы свяжетесь эффектом.
3. Повторное использование меняет вас местами.
