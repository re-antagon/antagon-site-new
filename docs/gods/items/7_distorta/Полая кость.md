# Описание
**Полая кость** - предмет Бога Искажения, «Шкала HP». Наполняется при убийстве в ближнем бою

| Активация                | при убийстве, при удержании   |
| ------------------------ | ----------------------------- |
| Перезарядка              | -                             |
| Особое                   | чинит себя                    |
| Восстановление прочности | 1 от мобов, 16 от игроков     |
| При полной прочности     | превращается в Кость с кровью |
| Стакается                | нет                           |
