# Описание
**Прах банши** - компонент Бога Окончания, «ты мне песню не пой». Редкий материал, выпадающий с банши. Используется для крафта плаща одиночества.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Выпадает с **банши** с определённым шансом.
