# Описание
**Клок тени** - компонент Бога Окончания, «платок фокусника». Теневой материал, выпадающий с теневых мобов. Используется для крафта брони отвода глаз и других теневых предметов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Падает с **теневых мобов**.
