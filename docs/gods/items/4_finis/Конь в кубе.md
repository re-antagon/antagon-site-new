# Описание
**Конь в кубе** - инструмент Бога Окончания, «вакуум прилагается». Призывает временную лошадь на 5 минут.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 5 минут |
| Здоровье моба  | 10 хп |
| Время жизни    | 5 минут |



## Эффект
При использовании (ПКМ) призывает временную лошадь, которая живёт 5 минут.

## Использование
1. Возьмите Конь в кубе в руку.
2. Активируйте (ПКМ) - лошадь появится рядом.
3. Перезарядка 5 минут.
