# Описание
**Широкополая шляпа** - шлем Бога Окончания, «музыка бессонной ночи». Деспавнит фантомов в радиусе 10 блоков, но сводит удары носителя к 1 урону.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (шлем) |
| Радиус деспавна фантомов | 10 блоков |
| Урон носителя  | 1 |
| Уровень брони  | Кожа |



## Эффект
- Фантомы деспавнятся в радиусе 10 блоков.
- Урон всех атак владельца = 1.

## Использование
1. Наденьте шляпу в слот шлема.
