# Описание
**Серебряный слиток** - компонент Бога Окончания, «бесконечно матовое». Основной металлический ресурс Бога, используемый для крафта брони, инструментов и других компонентов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |
