# Описание
**Кольцо теней** - оружие Бога Окончания, «Gunfire Reborn». При зажатии ПКМ создаёт вокруг владельца кольцо, наносящее 1 урон при контакте.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие |
| Активация      | Зажатие ПКМ |
| Радиус эффекта | 2 блока |
| Урон           | 1 |



## Эффект
При зажатии ПКМ создаёт вокруг владельца кольцо радиусом 2 блока. Контакт наносит 1 урон.

## Использование
1. Возьмите Кольцо теней в руку.
2. Зажмите ПКМ.



## Получение
Крафтится из капельников, тумана ожидания и осыпающегося осколка:

- 4x ![Капельник](/assets/items/pointed_dripstone.png) Капельник
- 4x ![Туман ожидания](/assets/items/custom/small/waiting_fog.png) [Туман ожидания](/gods/items/4_finis/Туман%20ожидания)
- ![Осыпающийся осколок](/assets/items/custom/small/crumbling_shard.png) [Осыпающийся осколок](/gods/items/4_finis/Осыпающийся%20осколок)
