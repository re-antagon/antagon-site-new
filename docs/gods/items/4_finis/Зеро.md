# Описание
**Зеро** - компонент Бога Окончания, «любимое число бухгалтеров». При нажатии меняет текстуру на следующую цифру (от 0 до 9). Используется во множестве крафтов Бога Окончания.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активация      | При использовании |
| Перезарядка    | 1 с |
| Особое         | Смена цифры |
| Стакается      | Да |



## Эффект
При использовании (ПКМ) меняет свою текстуру на следующую цифру (0→1→2→...→9→0). Существует в 10 вариантах: от ![зеро 0](/assets/items/custom/big/zerozero.png) до ![зеро 9](/assets/items/custom/big/zeronine.png). Разные варианты могут требоваться в разных рецептах.

Крафтится из двух кусочков серебра или из глаза эндера и палки:
