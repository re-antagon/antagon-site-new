# Описание
**Ветер** - инструмент Бога Окончания, «крышесносно». Спавнит одноразовый подбрасывающий вихрь при размещении. При разрушении не дропается.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При размещении, при касании |
| Высота подбрасывания | ? |
| Дроп при разрушении | Нет |



## Эффект
При размещении (ПКМ) создаёт вихрь, который подбрасывает в воздух любое существо, коснувшееся его. Вихрь одноразовый и исчезает после срабатывания. При разрушении не выпадает.

## Использование
1. Возьмите Ветер в руку.
2. Разместите (ПКМ) на земле.
3. При касании существо подбрасывается в воздух.



## Получение
Дроп из **элементалей в [Чистилище](/gods/purgatory)**.
