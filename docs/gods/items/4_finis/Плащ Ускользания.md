# Описание
**Плащ Ускользания** - броня Бога Окончания, «неуловимый». При получении любого урона телепортирует владельца на 3 блока вперёд.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | При уроне |
| Перезарядка    | 5 с |
| Дальность эффекта | 3 блока |



## Эффект
При получении любого урона владелец автоматически телепортируется на 3 блока вперёд.

## Использование
1. Наденьте плащ в слот нагрудника.



## Получение
Крафтится из элитр, плода хоруса и кусочков серебра:

- ![Элитры](/assets/items/elytra.png) Элитры
- ![Плод хоруса](/assets/items/chorus_fruit.png) Плод хоруса
- 4x ![Кусочек серебра](/assets/items/custom/big/silver_nugget.png) [Кусочек серебра](/gods/items/4_finis/Кусочек%20серебра)
