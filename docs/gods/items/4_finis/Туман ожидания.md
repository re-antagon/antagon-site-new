# Описание
**Туман ожидания** - расходник Бога Окончания, «время пришло». Снимает эффект горения при использовании. Имеет 80% шанс не потратиться.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Снятие эффектов | Горение |
| Шанс не потратить | 80% |



## Эффект
При использовании (ПКМ) снимает с владельца эффект горения. С вероятностью 80% предмет не расходуется.

## Использование
1. Возьмите Туман ожидания в руку.
2. Активируйте (ПКМ) при горении - огонь потухнет.



## Получение
Собирается в **пустыне в полнолуние и новолуние** при клике ПКМ пеплом магии по блоку воды.

- ![Пепел магии](/assets/items/custom/small/ashes_of_magic.png) [Пепел магии](/gods/items/4_finis/Пепел%20магии) + блок воды (в полнолуние/новолуние в пустыне)

## Используется для
- ![Кольцо теней](/assets/items/custom/small/ring_of_shadows.png) [Кольцо теней](/gods/items/4_finis/Кольцо%20теней)
- Лунный амулет
