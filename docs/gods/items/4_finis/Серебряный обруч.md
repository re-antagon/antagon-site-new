# Описание
**Серебряный обруч** - шлем Бога Окончания, «остались башмачки». При получении урона ненадолго скрывает владельца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (шлем) |
| Активация      | При уроне |
| Перезарядка    | 2 с |
| Наложение эффектов | Скрытность, 1 с |
| Уровень брони  | Железная |



## Эффект
При получении урона накладывает **Скрытность** на 1 секунду.

## Использование
1. Наденьте обруч в слот шлема.



## Получение
Крафтится из серебряных слитков:
