# Описание
**Пепел магии** - расходник Бога Окончания, «охота на ведьм окончена». При использовании с шансом 20% даёт 1 уровень опыта.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Перезарядка    | 1 с |
| Шанс активации | 20% |
| Добавочный опыт | 1 уровень |



## Эффект
При использовании (ПКМ) с шансом 20% начисляет владельцу 1 уровень опыта. В остальных 80% случаев пепел расходуется без эффекта.

## Использование
1. Возьмите Пепел магии в руку.
2. Активируйте (ПКМ) - есть шанс получить уровень опыта.



## Получение
Выплавляется в печи из осыпающегося осколка:
