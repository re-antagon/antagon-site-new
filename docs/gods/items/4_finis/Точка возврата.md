# Описание
**Точка возврата** - расходник Бога Окончания, «док, ты жив!». При взмахе запоминает текущее местоположение игрока. При повторном взмахе телепортирует обратно к запомненной точке за 15 уровней опыта. Работает даже между разными мирами.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании (взмах) |
| Запоминание места | При взмахе |
| Расход опыта (активация возврата) | 15 уровней |
| Телепорт в другой мир | Да |



## Эффект
При первом использовании (взмах) запоминает текущие координаты игрока. При повторном использовании телепортирует владельца к запомненной точке, расходуя 15 уровней опыта. Работает даже если игрок находится в другом измерении.

## Использование
1. Возьмите Точку возврата в руку.
2. Взмахните (ПКМ) - место запомнено.
3. Взмахните снова - возвращайтесь за 15 уровней опыта.
