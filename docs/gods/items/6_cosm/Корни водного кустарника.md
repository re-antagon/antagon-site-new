# Описание
**Корни водного кустарника** - расходник Бога Космоса. При использовании создаёт платформу из корней на воде.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При использовании |
| Условие        | Блок воды |
| Эффект         | Создаёт платформу корней |

---

## Эффект
При использовании (ПКМ) по воде создаёт платформу из корней, по которой можно ходить.

## Использование
1. Возьмите корни водного кустарника в руку.
2. Активируйте (ПКМ) по воде - появится платформа.

---
