# Описание
**Гроза в бутылке** - расходник Бога Космоса, «клетка Фарадея». При попадании в цель призывает молнию.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При попадании |
| Радиус эффекта | Место попадания |
| Особое         | Призывает молнию |

---

## Эффект
При попадании в блок или существо призывает молнию в точке попадания. Предмет расходуется при использовании.

## Использование
1. Возьмите грозу в бутылке в руку.
2. Бросьте (ПКМ) в цель.
3. При попадании в цель ударяет молния.

---

## Получение
Добывается при получении урона от **молниевого угря** с пустой бутылкой в руке.
