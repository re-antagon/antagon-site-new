# Описание
**Фиолетовая эссенция** - компонент Бога Космоса, осколок стихии гравитации. Выглядит как маленький фиолетовый кубик, окружённый частицами. Выпадает с **Гравитационного (фиолетового) пилона** во время битвы со [Звёздным драконом](/guide/mechanics/star_dragon). Используется для создания звёздной брони и звёздного оружия.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Стихия         | Гравитация |
| Источник       | Гравитационный (фиолетовый) пилон |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
- При уничтожении **Гравитационного (фиолетового) пилона** в первой фазе битвы со [Звёздным драконом](/guide/mechanics/star_dragon#фаза-1-пилоны) вокруг него выпадает в среднем **около 20** эссенций.
- С шансом выпадает с мобов гравитационного пилона во время [Элементального бурана](/guide/mechanics/star_dragon#элементальныи-буран).

::: tip Совет
С одного пилона эссенции разлетаются вокруг места его гибели - не забудьте собрать их все, пока не начался бой с самим драконом.
:::

## Используется для
- [Звёздная броня](/guide/mechanics/star_armor) - наборы брони из эссенций пилонов.
- Звёздное оружие.
- ![Чаша Здравия](/assets/items/custom/small/health_cup.png) [Чаша Здравия](/gods/items/2_mater/Чаша%20Здравия) - подходит эссенция любого пилона.
- Элементальный буран - требует по 2 эссенции каждого вида и [подозрительное яйцо дракона](/guide/mechanics/star_dragon#подозрительное-яицо-дракона).
