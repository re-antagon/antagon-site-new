# Описание
**Звёздная пыль** - компонент Бога Космоса, «кучка чистого света». Получается путём переплавки упавшей звезды в печи. Используется для крафта звёздного компаса, лунного амулета и небесного камня.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |
