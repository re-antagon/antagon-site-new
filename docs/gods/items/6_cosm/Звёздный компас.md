# Описание
**Звёздный компас** - инструмент Бога Космоса, «кладоискатель». Показывает направления к упавшим звездам в радиусе 200 блоков при удержании в руке. Отображается в виде полоски компаса сверху экрана.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При удержании |
| Радиус эффекта | 200 блоков |
| Отображение    | Полоска компаса сверху |

---

## Эффект
При удержании в руке показывает направление к ближайшей ![Упавшая звезда](/assets/items/custom/big/fallen_star.png) [упавшей звезде](/gods/items/6_cosm/Упавшая%20звезда) в радиусе 200 блоков с помощью полоски компаса сверху экрана.

## Использование
1. Возьмите звездный компас в руку.
2. На экране отобразится полоска компаса, указывающая направление к упавшей звезде.
3. Следуйте по указанию.
