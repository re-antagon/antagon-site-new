# Описание
**Небесный камень** - компонент Бога Космоса. Используется для крафта сферы небесного света и солария.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |

---

## Получение
Крафтится из упавшей звезды, звёздной пыли и алмаза:

- ![Упавшая звезда](/assets/items/custom/small/fallen_star.png) [Упавшая звезда](/gods/items/6_cosm/Упавшая%20звезда)
- 3x ![Звёздная пыль](/assets/items/custom/small/star_dust.png) [Звёздная пыль](/gods/items/6_cosm/Звёздная%20пыль)
- ![Алмаз](/assets/items/diamond.png) Алмаз
