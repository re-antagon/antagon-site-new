# Описание
**Водная призма** - инструмент Бога Космоса. Превращает блоки за опыт при использовании.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Стоимость      | Опыт |

---

## Эффект
При использовании (ПКМ) превращает целевой блок, расходуя опыт.

## Использование
1. Возьмите водную призму в руку.
2. Активируйте (ПКМ) по блоку для превращения.
