# Описание
**Броня Иглобрюха** - броня Бога Космоса, «последний иглобрюх». При получении урона отравляет противника. Уровень отравления зависит от количества надетых элементов.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Активация 1    | При ношении (получение урона) |
| Радиус эффекта 1 | Атакующий противник |
| Броня          | Кожаная |
| Прочность      | Кожаная |
| Активация 2    | При ношении (полный сет) |
| Радиус эффекта 2 | Себе |
| Снятие эффектов себе (полный сет) | Отравление |

**Наложение эффектов (отравление):**

| Элементов | Эффект |
|:---------:|:-------|
| 1 | Отравление I на 5 с |
| 2 | Отравление I на 10 с |
| 3 | Отравление II на 5 с |
| Полный сет (4) | Отравление II на 10 с |

---

## Эффект
При получении урона отравляет атакующего противника. Уровень и длительность отравления зависят от количества надетых элементов брони. Полный сет дополнительно снимает с владельца эффект отравления.

## Использование
1. Наденьте один или несколько элементов брони.
2. При получении урона атакующий получает отравление.
3. Полный сет защищает владельца от отравления.
