# Описание
**Лунный амулет** - инструмент Бога Космоса. Даёт положительные эффекты в ночное время, в зависимости от фазы луны.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При ношении |
| Условие        | Ночное время |

**Эффекты по фазе луны:**

| Фаза луны | Эффект |
| --------- | ------ |
| Новолуние | Невидимость |
| Растущая 1-3 | Регенерация |
| Полнолуние | Сопротивление |
| Убывающая 1-3 | Спешка |

---

## Эффект
В ночное время даёт эффект, зависящий от текущей фазы луны: в новолуние - невидимость, в полнолуние - сопротивление, на растущей луне - регенерацию, на убывающей - спешку.

## Использование
1. Держите амулет в инвентаре или экипируйте.
2. Ночью эффект активируется автоматически.
