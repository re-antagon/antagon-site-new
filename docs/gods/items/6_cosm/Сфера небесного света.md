# Описание
**Сфера небесного света** - инструмент Бога Космоса. Ставится на землю, накладывает свечение на всех поблизости и снимает слепоту. Работает только под открытым небом.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | Пока поставлено |
| Частота эффекта | 1 с |
| Радиус наложения эффекта | 20 блоков |
| Радиус снятия эффекта | 10 блоков |
| Наложение эффекта | Свечение |
| Снятие эффектов | Тьма, слепота |
| Ограничение работы | Под открытым небом |

---

## Эффект
При размещении на земле создаёт область света радиусом 20 блоков, накладывая на всех существ свечение. Снимает эффекты тьмы и слепоты в радиусе 10 блоков. Работает только под открытым небом.

## Использование
1. Возьмите сферу в руку.
2. Разместите (ПКМ) на земле.
3. Эффекты срабатывают автоматически пока сфера стоит.
