# Описание
**Пёстрый веер** - инструмент Бога Космоса. При использовании в воде призывает случайных рыб в радиусе 3 блоков.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент |
| Активация      | При использовании |
| Перезарядка    | 30 с |
| Радиус эффекта | 3 блока (только в воде) |
| Призываемые мобы | Любые рыбы |
| Количество призывов | 5 |

---

## Эффект
При использовании (ПКМ) в воде призывает 5 случайных рыб в радиусе 3 блоков. Работает только в водной среде. Перезарядка - 30 секунд.

## Использование
1. Возьмите пёстрый веер в руку.
2. Активируйте (ПКМ) в воде.
3. В радиусе 3 блоков появляется 5 случайных рыб.
