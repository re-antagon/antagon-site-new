# Описание
**Пёстрый веер** - предмет Бога Космоса, «На вкус и цвет». Пытается призвать 5 случайных рыб в воде в радиусе 3 блоков, перезарядка 30с

| активация           | при использовании       |
| ------------------- | ----------------------- |
| перезарядка         | 30с                     |
| радиус эффекта      | 3 блоков(только в воде) |
| призываемые мобы    | любые рыбы              |
| количество призывов | 5                       |
