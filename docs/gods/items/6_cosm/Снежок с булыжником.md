# Описание
**Снежок с булыжником** - расходник Бога Космоса, «убийца дружбы». При попадании наносит урон.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | При попадании |
| Урон           | ? |

---

## Эффект
При попадании в цель наносит урон. Точное значение урона не задокументировано.

## Использование
1. Возьмите снежок в руку.
2. Бросьте (ПКМ) в цель.
3. При попадании цель получает урон.
