# Описание
**Окрашиваемая незеритовая броня** - одежда Бога Войны. Незеритовая броня, обтянутая [прочной кожей](/gods/items/5_bellum/Прочная%20кожа). Сохраняет все боевые свойства незерита, но технически является кожаной бронёй, поэтому её можно перекрашивать.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (полный сет) |
| Основа         | Кожаная броня |
| Защита и прочность | Как у незеритовой брони |
| Огнестойкость  | Не горит в лаве и огне |
| Особое         | Окрашивается красителями |



## Эффект
- Имеет **прочность и защиту незеритовой брони**.
- **Не горит** в лаве и огне, как незеритовые предметы.
- Является **кожаной бронёй**, поэтому её можно окрашивать красителями, не теряя защиты и других характеристик.

## Использование
1. Скрафтите нужные элементы брони.
2. Окрасьте их красителями, как обычную кожаную броню.
