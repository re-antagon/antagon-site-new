# Описание
**Стальная стрела** - расходник Бога Войны, «есть пробитие». Служит боеприпасом для ![Лук Сталевара](/assets/items/custom/big/steel_bow.png) [Лука Сталевара](/gods/items/5_bellum/Лук%20Сталевара).

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активный эффект | Нет (боеприпас) |
| Стакается      | Да |



## Получение
Крафтится из кремня и кусочков оружейной стали:
- ![Кремень](/assets/items/flint.png) Кремень
- 2x ![Кусочек оружейной стали](/assets/items/custom/big/steel_nugget.png) [Кусочек оружейной стали](/gods/items/5_bellum/Кусочек%20оружейной%20стали)
