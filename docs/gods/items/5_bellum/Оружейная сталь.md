# Описание
**Оружейная сталь** - компонент Бога Войны, «Severed Steel». Основной металлический ресурс Бога, используемый для крафта брони, оружия и щита Сталевара.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Крафтится по 4 штуки из кусочков оружейной стали и незеритового слитка:
- 8x ![Кусочек оружейной стали](/assets/items/custom/big/steel_nugget.png) [Кусочек оружейной стали](/gods/items/5_bellum/Кусочек%20оружейной%20стали)
- ![Незеритовый слиток](/assets/items/netherite_ingot.png) Незеритовый слиток
