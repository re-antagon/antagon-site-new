# Описание
**Щит Сталевара** - инструмент Бога Войны, «легко не будет!». При использовании сильно защищает, но замедляет владельца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Инструмент (щит) |
| Активация      | При использовании |
| Длительность   | 2 с |
| Наложение эффектов | Медлительность III, Сопротивление III |
| Зачаровываемое | Да |
| Нерушимый | Да |



## Эффект
При использовании (ПКМ) накладывает на владельца **Сопротивление III** (сильное снижение урона) и **Медлительность III** на 2 секунды.
При ударе имеет **5%** шанс уйти в перезарядку как у ванильного щита.

## Использование
1. Возьмите щит в руку.
2. Активируйте (ПКМ) для получения защиты ценой замедления.
