# Описание
**Осколок битвы** - компонент Бога Войны, «кто ты, воин?». Выпадает с мини-боссов и боссов при убийстве игроком.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Падает с **мини-боссов и боссов** при убийстве игроком.
