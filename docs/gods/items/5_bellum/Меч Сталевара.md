# Описание
**Меч Сталевара** - оружие Бога Войны, «урон: оглушающий». Медленный меч, наносящий 8 урона и замедляющий цель на миг.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (меч) |
| Активация      | Удар |
| Урон           | 8 |
| Наложение эффектов | Оглушение, 10 тиков |
| Зачаровываемое | Да |
| Прочность      | Незерит |



## Эффект
При ударе накладывает на цель эффект **оглушения** на 10 тиков (0.5 секунды). Урон меча - 8 единиц. Прочность соответствует незериту.

## Использование
1. Возьмите меч в руку.
2. Атакуйте цель - та получает урон и кратковременное оглушение.

Крафтится из оружейной стали и палки:
