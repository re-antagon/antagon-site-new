# Описание
**Лук Сталевара** - оружие Бога Войны, «поднимет не каждый». Долго заряжается, стреляет только при полной зарядке, расходует стальные стрелы. Стрела падает быстрее обычной.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (лук) |
| Активация      | Зарядка |
| Урон           | 10–15 |
| Наложение эффектов | Оглушение, 20 тиков |
| Скорость снаряда | Обычная |
| Гравитация стрелы | Усиленная |
| Зачаровываемое | Нет |
| Прочность      | ∞ |



## Эффект
Лук требует полной зарядки для выстрела и использует в качестве боеприпаса ![Стальные стрелы](/assets/items/custom/big/steel_arrow.png) [Стальные стрелы](/gods/items/5_bellum/Стальная%20стрела). Наносит 10–15 урона и оглушает цель на 20 тиков (1 секунду). Стрела имеет усиленную гравитацию, поэтому падает быстрее обычной.

## Использование
1. Возьмите лук в руку.
2. Зарядите до полной зарядки.
3. Выстрелите - стрела наносит повышенный урон и оглушает цель.
