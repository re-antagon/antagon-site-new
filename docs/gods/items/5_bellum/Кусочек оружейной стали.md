# Описание
**Кусочек оружейной стали** - компонент Бога Войны, «лишь малый шаг на пути к бессмертию». Базовый стальной ресурс, выплавляемый из железных слитков. Используется для крафта оружейной стали и стальных стрел.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет |
| Стакается      | Да |



## Получение
Выплавляется в печи из железного слитка:
