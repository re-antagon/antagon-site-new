# Описание
**Лёгкая броня** - броня Бога Войны, «композитные материалы». Полный сет ускоряет владельца.

| Характеристика     | Значение                    |
| ------------------ | --------------------------- |
| Тип предмета       | Одежда (полный сет)         |
| Активация          | Периодическая (полный сет)  |
| Перезарядка        | 2 с                         |
| Длительность       | 3 с                         |
| Наложение эффектов | Скорость I                  |
| Броня              | 2, 6, 5, 2 (шлем-нагрудник-штаны-ботинки) |
| Зачаровываемое     | Да                          |



## Эффект
При ношении полного сета каждые 2 секунды накладывает на владельца эффект **Скорости I** на 3 секунды.

## Использование
1. Наденьте все 4 элемента брони.
2. Скорость срабатывает автоматически.
