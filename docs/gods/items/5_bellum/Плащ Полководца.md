# Описание
**Плащ Полководца** - броня Бога Войны, «веди же нас!». Ускоряет при получении урона.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (плащ) |
| Активация      | Получение урона (экипировано) |
| Длительность   | 10 с |
| Наложение эффектов | Скорость II |
| Броня          | 0 (элитры) |
| Зачаровываемое | Да |



## Эффект
При получении урона накладывает на владельца эффект **Скорости II** на 10 секунд. Плащ не даёт базовой брони (как элитры).

## Использование
1. Наденьте плащ в слот нагрудника.
2. При получении урона скорость автоматически активируется.



## Получение
Крафтится из кристалла битвы, элитр и полотна:

- ![Элитры](/assets/items/elytra.png) Элитры
