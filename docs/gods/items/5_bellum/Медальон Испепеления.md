# Описание
**Медальон Испепеления** - оружие Бога Войны, «моё последнее желание». При смерти поджигает всех вокруг длительным нетушимым огнём.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Оружие (аксессуар) |
| Активация      | Смерть |
| Длительность   | 30 с |
| Радиус эффекта | 10 блоков, прямая видимость |
| Наложение эффектов | Огонь (нетушимый) |
| Броня          | 3 |



## Эффект
При смерти владельца поджигает всех существ в радиусе 10 блоков (прямая видимость) нетушимым огнём на 30 секунд.

## Использование
1. Держите медальон в инвентаре.
2. При смерти он срабатывает автоматически.
