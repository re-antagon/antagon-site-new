# Описание
**Грибной шлем** - одежда Бога Расширения. Нерушимый кожаный шлем, который позволяет долго находиться под водой и распространяет грибницу по земле под ногами владельца.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Одежда (шлем) |
| Основа         | Кожаный шлем |
| Прочность      | Нерушимый |
| Зачарования    | Подводное дыхание X, Защита II |
| Особое         | Превращает блоки под ногами в мицелий |



## Эффект
- Шлем **нерушимый** и имеет зачарования **Подводное дыхание X** и **Защита II**.
- При ходьбе по заражаемым блокам (земля, трава и т.п.) превращает их в **мицелий**.

::: warning Внимание
Каждое превращение блока в мицелий вызывает **сильный голод**. Носите с собой достаточно еды.
:::

## Использование
1. Наденьте шлем.
2. Ходите по земле - она будет превращаться в мицелий.



## Получение
Выпадает из **грибных големов**.
