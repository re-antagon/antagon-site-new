# Описание
**Светящийся гриб** - компонент Бога Расширения, «он ненавидит и выплёвывает солнце». Служит альтернативой светящимся чернилам для крафта Глаза Грибницы.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Компонент |
| Активный эффект | Нет     |
| Стакается      | Да       |



## Получение
Крафтится по 4 штуки из одного грибного светильника:

- ![Грибной светильник](/assets/items/shroomlight.png) Грибной светильник

<CraftingRecipe
  input1="shroomlight"
  output="glow_mushroom"
  shapeless="true"
/>
