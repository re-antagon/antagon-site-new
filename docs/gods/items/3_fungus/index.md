# Бог Расширения

Предметы **Бога Расширения** - уникальные инструменты, оружие, броня, расходники и компоненты сервера Re:Antagon. Механика Бога Расширения строится вокруг грибницы, спор и мицелия: от превращения земли в мицелий через [Спору](/gods/items/3_fungus/Спора) до продвинутой брони, работающей только на мицелии.

::: info Сводка
Всего предметов: **17**. Ниже они сгруппированы по назначению. Каждая карточка ведёт на подробную страницу с описанием, эффектом и рецептом крафта.
:::
