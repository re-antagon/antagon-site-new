# Описание
**Грибной картофель** - кулинария Бога Расширения, «коммунистическая грибница». Картофель, проросший грибницей. Есть его неприятно, зато так можно приблизиться к Расширению.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Кулинария (расходник) |
| Активация      | При поедании |
| Наложение эффекта | Слабость, Слепота, Медлительность, 10 с |
| Особое         | Шанс 20% получить +10 репутации с Расширением |



## Эффект
При поедании накладывает **Слабость**, **Слепоту** и **Медлительность** на **10 секунд**.

С шансом **20%** поедание также даёт **+10 репутации** с [Богом Расширения](/gods/3_fungus).

## Использование
1. Найдите безопасное место - на 10 секунд вы станете почти беззащитны.
2. Съешьте картофель.



## Получение
Выпадает из **грибных големов**.
