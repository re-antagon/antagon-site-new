# Описание
**Гриб-споровик** - расходник Бога Расширения, «пуфф-гриб». Метательный гриб, который при попадании взрывается облаком спор: заражает землю мицелием и травит всех, кто не является грибом.

| Характеристика | Значение |
| -------------- | -------- |
| Тип предмета   | Расходник |
| Активация      | Бросок (ПКМ) |
| Траектория     | Навесом вперёд |
| Урон           | 15 |
| Наложение эффекта | Слабость, Слепота, Отравление, 2.5 с |
| Особое         | Заражает землю мицелием |



## Эффект
При использовании гриб кидается **навесом вперёд**. В точке попадания:
- заражает землю, превращая её в **мицелий**;
- наносит **15 урона** всем, кто не является грибом;
- накладывает **Слабость**, **Слепоту** и **Отравление** на **2.5 секунды**.


## Использование
1. Возьмите гриб в руку.
2. Активируйте (ПКМ) - гриб полетит навесом вперёд.
3. Целитесь с упреждением: споровик летит по дуге.



## Получение
Выпадает из **грибных монстров**.
