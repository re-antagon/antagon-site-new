# Описание
**Жёсткая грибная боевая броня** - топовый боевой сет Бога Расширения, «теперь мне нужен только мотоцикл». Полный сет даёт сопротивление, регенерацию и силу при нахождении на мицелии.

| Характеристика     | Значение                                   |
| ------------------ | ------------------------------------------ |
| Тип предмета       | Одежда (полный сет)                        |
| Активация          | При ношении (полный сет)                   |
| Условие активации  | На мицелии                                 |
| Перезарядка        | 2 с                                        |
| Наложение эффектов | Сопротивление I, 3 с + Регенерация I, 3 с + Сила I, 3 с |
| Уровень брони      | Незерит                                    |



## Эффект
При ношении полного сета на мицелии каждые 2 секунды накладывает на владельца эффекты **Сопротивления I**, **Регенерации I** и **Силы I** на 3 секунды. Уровень брони соответствует незериту.

## Использование
1. Наденьте все 4 элемента брони.
2. Находитесь на мицелии - все боевые баффы срабатывают автоматически.
