# Описание
**Снежок с ледышкой** - расходник Бога Естества, «будет больно». При попадании в цель наносит урон.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При попадании |
| Урон             | ?         |



## Эффект
При попадании в моба или игрока наносит урон. Точное значение урона не задокументировано (отмечено как «?» в исходных данных).

## Использование
1. Возьмите снежок в руку.
2. Бросьте (ПКМ) в цель.
3. При попадании цель получает урон.
