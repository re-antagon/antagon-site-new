# Описание
**Талисман морской звезды** - инструмент Бога Естества, «голова не отрастает». При удержании в руке даёт пассивную регенерацию в воде, но отравляет на суше.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Инструмент |
| Активация       | При удержании |
| Перезарядка     | - |
| Эффект в воде   | Регенерация 2 |
| Эффект на суше  | Отравление 1 |



## Эффект
Пока талисман находится в руке, владелец получает пассивные эффекты: в воде - Регенерацию II, на суше - Отравление I. Перезарядки нет, эффект действует постоянно при удержании.

## Использование
1. Возьмите талисман в руку.
2. Находясь в воде, получайте регенерацию; на суше - будьте готовы к отравлению.



## Получение
Выпадает с морской звезды. Не крафтится.

## Используется для
_Не используется в других рецептах._

## Примечания
- Полезен при подводных вылазках, но опасен на суше из-за отравления.
- Эффект чисто пассивный, требует удержания в руке.



## Связанные предметы
_Нет._
