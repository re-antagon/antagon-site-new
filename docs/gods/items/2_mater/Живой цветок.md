# Описание
**Живой цветок** - расходник Бога Естества, «наследие Травяной Коровы». При использовании чистит мицелий рядом и лечит окружающих.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При использовании |
| Стак            | 64 |
| Перезарядка     | - |
| Радиус эффекта | 8 блоков |
| Лечение         | 8 хп |



## Эффект
При использовании (ПКМ) очищает мицелий в радиусе 8 блоков и лечит всех окружающих на 8 единиц здоровья (4 сердца). Предмет не имеет перезарядки, стакается до 64.

## Использование
1. Возьмите Живой цветок в руку.
2. Активируйте (ПКМ) для лечения союзников и очистки мицелия.
