# Описание
**Соль** - кулинарный предмет Бога Естества, «рассыпая кличи беду». Служит кристаллической солью, выпариваемой изо льда в печи. Сама по себе не обладает активным эффектом и используется как сырьё для крафта солёного снежка и прочной кожи.

| Характеристика | Значение |
| -------------- | --------- |
| Тип предмета   | Кулинария |
| Активный эффект | Нет      |
| Стакается      | Да        |



## Получение
Выпаривается в печи изо льда (любого).

- Выпаривается изо льда.
