# Описание
**Чаша Здравия** - расходник Бога Естества, «за ваше здоровье». При выпивании даёт владельцу много дополнительных сердец (щит).

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При выпивании |
| Наложение эффектов | 20 щита |



## Эффект
При выпивании накладывает на владельца 20 единиц поглощения урона (щит/абсорбция). Эффект действует до полного расхода щита.

## Использование
1. Возьмите Чашу Здравия в руку.
2. Выпейте (ПКМ), чтобы получить щит.
3. Чаша расходуется.



## Получение
Крафтится из золотых слитков, эфирного масла, вечнозелёного листа и эссенции пилона:

- 2x ![Золотой слиток](/assets/items/gold_ingot.png) Золотой слиток
- ![Эфирное масло](/assets/items/blue_potion.png) [Эфирное масло](/gods/items/2_mater/Эфирное%20масло)
- 2x ![Вечнозелёный лист](/assets/items/custom/small/evergreen_leaf.png) [Вечнозелёный лист](/gods/items/2_mater/Вечнозелёный%20лист)
- <InventorySlot item="nether_star" /> Эссенция пилона (любого)

## Примечания
- Даёт значительный запас щита (20 единиц), что делает её мощным защитным расходником.
- Требует [Эфирное масло](/gods/items/2_mater/Эфирное%20масло) и [Вечнозелёный лист](/gods/items/2_mater/Вечнозелёный%20лист), связывая её с растительным циклом Бога.
