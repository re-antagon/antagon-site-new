# Описание
**Снежок с золотым яблоком** - расходник Бога Естества, «дистанционное лечение». При попадании в цель накладывает эффект регенерации.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета    | Расходник |
| Активация       | При попадании |
| Наложение эффектов | Регенерация (урон ?) |



## Эффект
При попадании в моба или игрока накладывает эффект регенерации. Точные уровень и длительность не задокументированы (отмечено как «?» в исходных данных).

## Использование
1. Возьмите снежок в руку.
2. Бросьте (ПКМ) в цель.
3. При попадании цель получает регенерацию.



## Получение
Крафтится из снежка и золотого яблока:

- ![Снежок](/assets/items/snowball.png) Снежок
- ![Золотое яблоко](/assets/items/golden_apple.png) Золотое яблоко
