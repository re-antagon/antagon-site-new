# Описание
**Солёный снежок** - метательное оружие Бога Естества, «осторожно: гололёд». При попадании в цель накладывает на неё эффект замедления.

| Характеристика    | Значение             |
| ----------------- | -------------------- |
| Тип предмета      | Оружие (метательное) |
| Активация         | При попадании        |
| Радиус эффекта   | Цель                 |
| Наложение эффектов | Замедление 2 (5 с) |



## Эффект
При попадании в моба или игрока накладывает эффект Замедления II на 5 секунд. Полезен для контроля целей на расстоянии.

## Использование
1. Возьмите снежок в руку.
2. Метните (ПКМ) в цель.
3. При попадании цель замедляется на 5 с.
