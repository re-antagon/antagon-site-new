# Описание
**Венец Цветения** - шлем Бога Естества, «главенство в поле». Периодически применяет эффект костной муки к растениям поблизости, ускоряя их рост.

| Характеристика            | Значение            |
| ------------------------- | ------------------- |
| Тип предмета             | Одежда (шлем)     |
| Активация                | Прыжок в шифте         |
| Перезарядка             | 5 с                 |
| Радиус эффекта          | 5 блоков           |
| Количество попыток       | 10                  |
| Зачаровываемое          | Да                  |
| Броня                    | 2 (железная)      |
| Совместимость с костюмом | лёгкая броня       |



## Эффект
Находясь на игроке, при нажатии шифта пытается применить костную муку к растениям в радиусе 5 блоков (до 10 попыток за цикл). Это автоматически подкармливает и ускоряет рост культур вокруг владельца.

## Использование
1. Наденьте Венец Цветения на слот шлема.
2. Находитесь рядом с растениями - нажмите шифт и пробел.
