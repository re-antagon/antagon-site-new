# Описание
**Бинты** - инструмент Бога Естества, «красная по борту полоса». При использовании накладывает на владельца временную регенерацию.

| Характеристика      | Значение             |
| -------------------- | -------------------- |
| Тип предмета        | Инструмент          |
| Активация           | При использовании    |
| Длительность        | 5 с                 |
| Радиус эффекта     | Себе                 |
| Наложение эффектов | Регенерация 2        |



## Эффект
При использовании (ПКМ) накладывает на владельца эффект Регенерации II на 5 секунд. Полезно для быстрого восстановления здоровья в бою.

## Использование
1. Возьмите Бинты в руку.
2. Активируйте (ПКМ) - на вас ложится регенерация на 5 с.



## Получение
Крафтится из медовой мази и полотна:
