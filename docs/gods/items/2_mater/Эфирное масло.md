# Описание
**Эфирное масло** - компонент Бога Естества, «физика покинула чат». Служит невесомым эфирным маслом, добываемым из тихоней. Само по себе не имеет активного эффекта и используется исключительно как сырьё для крафта древесной брони и Чаши Здравия.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |



## Получение
- С шансом **50%** выпадает из Эллея при смерти.
- Также может быть добыто из Эллея [Краником](/gods/items/2_mater/Краник) (но ценой снижения здоровья Эллея до 50% от максимума).

- Эллей - источник эфирного масла (шанс 50% с дропа, либо отбор краником на 50% ХП).
- ![Краник](/assets/items/custom/small/kranik.png) [Краник](/gods/items/2_mater/Краник) - инструмент отбора масла.

## Используется для
- [Чаша Здравия](/gods/items/2_mater/Чаша%20Здравия)

## Примечания
- Невесомый компонент, ключевой для сборки древесной брони и чаши Бога Естества.
- Как компонент не обладает собственным действием.



## Связанные предметы
- Эллей - моб, с которого добывается масло.
- [Краник](/gods/items/2_mater/Краник) - инструмент добычи.
- [Чаша Здравия](/gods/items/2_mater/Чаша%20Здравия) - требует Эфирное масло.
