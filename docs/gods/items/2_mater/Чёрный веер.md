# Описание
**Чёрный веер** - инструмент Бога Естества, «инструкция по выживанию не прилагается». Призывает случайных водных существ в радиусе вокруг.

| Характеристика    | Значение                  |
| ------------------ | ------------------------- |
| Тип предмета       | Инструмент               |
| Активация          | При использовании         |
| Перезарядка        | 2 мин                    |
| Радиус эффекта    | 5 блоков (только в воде) |
| Призываемые мобы  | Любые водные (кроме рыб) |
| Количество призывов | 3                       |



## Эффект
При использовании (ПКМ) в воде призывает 3 случайных водных существа (кроме рыб) в радиусе 5 блоков. Перезарядка - 2 минуты.

## Использование
1. Возьмите Чёрный веер в руку.
2. Активируйте (ПКМ) в воде для призыва водных существ.
3. Ждите перезарядки 2 минуты.

## Примечания
- Призывает только водных существ (не рыб) и работает исключительно в воде.
- Долгая перезарядка (2 мин) ограничивает частоту призыва.
