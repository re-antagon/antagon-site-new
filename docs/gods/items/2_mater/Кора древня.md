# Описание
**Кора древня** - компонент Бога Естества, «жизненный проводник». Служит прочным растительным материалом для сборки древесной брони и посоха природы. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |



## Получение
Выпадает с [Древня](/gods/items/2_mater/Древень) при убийстве топором (без шёлкового касания).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/gods/items/2_mater/Древень) - источник коры при убийстве топором.

## Используется для
- [Посох природы](/gods/items/2_mater/Посох%20природы)
- [Древесная броня](/gods/items/2_mater/Древесная%20броня)

## Примечания
- Прочный базовый материал древесной брони и посоха Бога Естества.
- Как компонент не обладает собственным действием.



## Связанные предметы
- [Древень](/gods/items/2_mater/Древень) - моб, с которого добывается кора.
- [Посох природы](/gods/items/2_mater/Посох%20природы) - требует Кору древня.
- [Древесная броня](/gods/items/2_mater/Древесная%20броня) - требует Кору древня.
