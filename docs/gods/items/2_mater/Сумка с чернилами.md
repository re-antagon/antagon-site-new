# Описание
**Сумка с чернилами** - инструмент Бога Естества, «тактическая аэрография». При использовании накладывает на врагов вокруг слепоту, а на владельца - слабость и скорость.

| Характеристика          | Значение              |
| ----------------------- | --------------------- |
| Тип предмета            | Инструмент           |
| Активация               | При использовании     |
| Перезарядка            | 20 с                  |
| Радиус эффекта         | 6 блоков             |
| Наложение эффектов     | Слепота 10 с          |
| Эффект (себе)         | Слабость 1 (10 с), Скорость 1 (10 с) |
| Прочность               | 80                    |



## Эффект
При использовании (ПКМ) накладывает на всех существ в радиусе 6 блоков эффект Слепоты на 10 секунд. Сам владелец получает Слабость I и Скорость I на 10 секунд. Прочность предмета - 80.

## Использование
1. Возьмите Сумку с чернилами в руку.
2. Активируйте (ПКМ) для ослепления врагов вокруг.
3. Учитывайте собственные эффекты (слабость и скорость).



## Получение
Выпадает с гигантского кальмара. Не крафтится.

## Используется для
_Не используется в других рецептах._

## Примечания
- Мощный инструмент контроля: ослепляет группу врагов, но даёт владельцу слабость.
- Прочность 80 ограничивает количество применений.



## Связанные предметы
_Нет._
