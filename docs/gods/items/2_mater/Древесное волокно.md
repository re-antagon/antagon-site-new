# Описание
**Древесное волокно** - компонент Бога Естества, «перекати-поле». Служит растительным волокном для изготовления тканей и деталей лёгкой брони. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |



## Получение
Выпадает при убийстве [Древня](/gods/items/2_mater/Древень) мечом (без шёлкового касания).

- ![Древень](/assets/items/custom/small/treebeard_bark.png) [Древень](/gods/items/2_mater/Древень) - источник волокна при убийстве мечом.

## Используется для
- Нить
- [Сапоги Лесника](/gods/items/2_mater/Сапоги%20Лесника)
- [Полотно](/gods/items/2_mater/Полотно)

## Примечания
- Базовый материал лёгкой брони и тканей Бога Естества.
- Как компонент не обладает собственным действием.



## Связанные предметы
- [Древень](/gods/items/2_mater/Древень) - моб, с которого добывается волокно.
- [Сапоги Лесника](/gods/items/2_mater/Сапоги%20Лесника) - требует Древесное волокно.
- [Полотно](/gods/items/2_mater/Полотно) - требует Древесное волокно.
