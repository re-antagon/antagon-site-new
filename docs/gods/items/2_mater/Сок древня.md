# Описание
**Сок древня** - компонент Бога Естества, «живительный нектар». Служит целебным соком, добываемым из Древня с помощью Краника. При выпивании накладывает на владельца эффект исцеления. Сам по себе не имеет активного эффекта до употребления и используется также как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активация       | При выпивании |
| Радиус эффекта | Себе      |
| Наложение эффектов | Исцеление 2 |
| Стакается       | Да        |



## Эффект
При выпивании накладывает на владельца эффект исцеления II, постепенно восстанавливая здоровье. Действует только на себя.

## Использование
1. Возьмите сок в руку.
2. Выпейте (ПКМ) для получения исцеления II.
3. Сок расходуется.



## Получение
Добывается с [Древня](/gods/items/2_mater/Древень) с помощью [Краника](/gods/items/2_mater/Краник) (ПКМ краником по древню при наличии пустых бутылок в инвентаре).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/gods/items/2_mater/Древень) - источник сока.
- ![Краник](/assets/items/custom/big/kranik.png) [Краник](/gods/items/2_mater/Краник) - инструмент добычи сока.

## Используется для
- [Перчатка Лекаря](/gods/items/2_mater/Перчатка%20Лекаря)

## Примечания
- Целебный компонент, совмещающий свойства расходника и материала крафта.
- Как компонент не обладает иным действием до выпивания.
