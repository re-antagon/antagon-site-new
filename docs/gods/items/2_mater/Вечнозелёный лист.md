# Описание
**Вечнозелёный лист** - компонент Бога Естества, «линия жизни». Служит базовым растительным материалом для множества предметов Бога Естества. Сам по себе не имеет активного эффекта и используется исключительно как сырьё для крафта.

| Характеристика | Значение |
| --------------- | --------- |
| Тип предмета    | Компонент |
| Активный эффект | Нет      |
| Стакается       | Да        |



## Получение
Состригается с [Древня](/gods/items/2_mater/Древень) ножницами (ПКМ по мобу с ножницами в руке).

- ![Древень](/assets/items/custom/big/древень.gif) [Древень](/gods/items/2_mater/Древень) - источник листьев при состригании ножницами.

## Используется для
- [Чаша Здравия](/gods/items/2_mater/Чаша%20Здравия)
- [Плащ Листьев](/gods/items/2_mater/Плащ%20Листьев)
- [Венец Цветения](/gods/items/2_mater/Венец%20Цветения)

## Примечания
- Базовый растительный компонент, без которого невозможно собрать броню, головной убор и защитную чашу Бога Естества.
- Как компонент не обладает собственным действием.
