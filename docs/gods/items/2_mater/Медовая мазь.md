# Описание
**Медовая мазь** - расходник Бога Естества, «кто-нибудь знает как открыть?». При использовании мгновенно лечит 3 сердца.

| Характеристика | Значение |
| ---------------- | --------- |
| Тип предмета     | Расходник |
| Активация        | При использовании |
| Перезарядка      | 1 с |
| Радиус эффекта  | Себе |
| Лечение           | 3 |



## Эффект
При использовании (ПКМ) мгновенно восполняет 3 единицы здоровья (1.5 сердец). Перезарядка между применениями - 1 секунда.

## Использование
1. Возьмите Медовую мазь в руку.
2. Активируйте (ПКМ) для мгновенного лечения.
3. Ждите перезарядки 1 с.



## Получение
Крафтится из сот и крапивы:

- ![Сота](/assets/items/honeycomb.png) Сота
- ![Крапива](/assets/items/custom/big/nettle.png) [Крапива](/gods/items/2_mater/Крапива)
