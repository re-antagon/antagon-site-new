# Бог Расширения

**Fungus** - Бог Расширения, покровитель болезней, чумы и заразы. Его последователи распространяют споры, используют второй желудок для переваривания любых веществ и могут принимать форму грибного существа.

---

## Благословения

Благословения Расширения улучшают второй желудок и атаку спорами:

| Уровень | Новые возможности | Дополнительные эффекты |
|:-------:|:------------------|:-----------------------|
| 1 | Второй желудок (лимит 40) | - |
| 2 | Атака спорами | - |
| 3 | Лимит второго желудка 60 | - |
| 4 | Шанс 10% позитивный баф второго желудка не потратится | Отрицательные эффекты тратятся с обычной скоростью |
| 5 | Лимит второго желудка 80 | - |
| 6 (Макс.) | Шанс 20% атака спорами добавляет +2 к зараженности | Вместо +1 |

::: tip Совет
На 6 уровне атака спорами становится особенно эффективной - с шансом 20% вы добавляете +2 зараженности вместо +1, что позволяет быстрее накапливать зараженность на целях.
:::

---

## Проклятия

Проклятия Расширения связаны с системой **заражения спорами**. При ходьбе по грязным блокам игрок накапливает зараженность:

| Уровень | Эффекты |
|:-------:|:--------|
| -1 | Заражение спорами более не выводится от времени |
| -2 | Хождение по грязным блокам дает +1 зараженности раз в 10с |
| -3 | Хождение по грязным блокам дает +1 зараженности раз в 10с |
| -4 | Хождение по грязным блокам дает +2 зараженности раз в 10с |
| -5 | Хождение по грязным блокам дает +2 зараженности раз в 10с |
| -6 (Макс.) | Хождение по грязным блокам дает +3 зараженности раз в 10с |

::: info Грязные блоки
К грязным блокам относятся: мицелий (×2 мощнее), подзол, грязь, земля, песок душ, почва душ, глина, корнистая земля, каменистая земля, коричневый сухой бетон, булыжник, колотый глубинный сланец.
:::

## Механика заражения спорами

### Накопление зараженности

**Атака спорами** - нанесение урона в ближнем бою:
- Игрокам: добавляет **+1 к зараженности** (КД 3с)
- Неигрокам: накладывает один из дебафов (![Медлительность](/assets/items/slowness.png) Медлительность, ![Слабость](/assets/items/weakness.png) Слабость, ![Отравление](/assets/items/poison.png) Отравление) на 10с

### Выведение спор

Споры выводятся из организма двумя способами:
1. **Растительная пища** - выводит споры (выводится столько спор, сколько было у еды сытости)
2. **От времени** - 1 единица зараженности каждые 15 секунд

::: warning Важно
При выведении спор:
- Наносится **2 урона** за каждую выведенную спору
- С шансом 10% на каждую единицу выведенного заражения тратится **1 прана**
- С шансом 50% вызывает один из дебафов (![Тошнота](/assets/items/nausea.png) Тошнота, ![Слабость](/assets/items/weakness.png) Слабость I, ![Медлительность](/assets/items/slowness.png) Медлительность I, ![Отравление](/assets/items/poison.png) Отравление) на 15с
:::

::: info Ограничение траты праны
Трата праны при выведении спор **не может понизить прану ниже 20**. Если у игрока 20 праны или меньше, прана при выведении спор не тратится.
:::

::: info Особенности пищи
- **Мясная пища** - не выводит споры, дебафов не вызывает
- **Смешанная пища** (растения + мясо, например тушеный кролик) - выводит споры, дебафов не вызывает
- **Грибная пища** (грибной суп) - при наличии заражения добавляет **+1** к зараженности
:::

### Уровни зараженности

| Зараженность | Эффекты |
|:-------------:|:--------|
| 0-4 | Нет эффектов |
| 5-14 | ![Медлительность](/assets/items/slowness.png) Медлительность I, приступы голода. При смерти появление зараженного скелета или зомби |
| 15-24 | ![Медлительность](/assets/items/slowness.png) Медлительность I, ![Голод](/assets/items/hunger.png) Голод I, приступы тошноты |
| 25-49 | ![Медлительность](/assets/items/slowness.png) Медлительность II, ![Голод](/assets/items/hunger.png) Голод III, приступы тошноты, ![Тьма](/assets/items/darkness.png) Тьма. Перестает выводиться от времени. Естественное восстановление праны замедлено в **2 раза**. При смерти появление усиленного зараженного зомби |
| 50-80 | ![Медлительность](/assets/items/slowness.png) Медлительность II, ![Голод](/assets/items/hunger.png) Голод V, ![Слабость](/assets/items/weakness.png) Слабость I, приступы тошноты, ![Тьма](/assets/items/darkness.png) Тьма, ![Отравление](/assets/items/poison.png) Отравление I. Мясная пища вызывает ![Иссушение](/assets/items/wither_effect.png) Иссушение I на 5с, грибная наносит 4 урона. Естественное восстановление праны не действует |

::: warning Важно
При зараженности 50+ мясная пища вызывает иссушение, а грибная наносит урон. Используйте растительную пищу для снижения зараженности.
:::

## Особенности тела

Начиная с **3 уровня благословений**, игрок выбирает одну из двух особенностей тела. У Бога Расширения доступно **2 варианта**:

### Прожорливое тело

Прожорливое тело превращает игрока в существо, способное переваривать любые вещества и получать от них пользу.

**Характеристики:**
- **Эффекты второго желудка**: Всегда II уровня (вместо I)
- ![Голод](/assets/items/hunger.png) **Пассивный эффект**: Голод I
- ![Поедатель](/assets/items/eater.png) **Поедатель II** на любую пищу
- **Вместимость второго желудка**: +40

**Особенности:**
- **Съедание блоков**: Восстанавливает **1 HP**
- **Получение урона**: Тратит сытость и съеденное во втором желудке, может наложить ![Тошнота](/assets/items/nausea.png) Тошноту на атаковавшего
- **Пустой желудок**: Получает ![Слабость](/assets/items/weakness.png) Слабость I, ![Утомление](/assets/items/mining_fatigue.png) Утомление II и приступы тошноты
- **Поедание камней**: Возможность кушать некоторые природные камни
- **Пока желудок не пустой**: ![Сопротивление](/assets/items/resistance.png) Сопротивление I, скорость восстановления праны повышена на **25%**

**Уязвимости:**
- Урон от голода повышен в **10 раз**

---

### Споровое тело

Споровое тело превращает игрока в грибное существо, распространяющее споры и мицелий.

**Характеристики:**
- При выборе тела **мгновенно восполняет зараженность** до 40
- Хождение по грязным блокам накапливает зараженность (как в проклятии)
- **Зараженность не вызывает дерганий экрана** (в отличие от обычного заражения)
- **Отсутствие дебафов** от зараженности
- **Зараженность не выводится** от времени

**Механики:**
- **Атаки**: Накладывают **+1 дополнительной зараженности** по цели
- **Получение урона**: Заражает тех, кто ударил (**+3 зараженности**, не чаще чем раз в 5с)
  - Мобы получают случайным образом ![Слабость](/assets/items/weakness.png) Слабость/![Медлительность](/assets/items/slowness.png) Медлительность/![Отравление](/assets/items/poison.png) Отравление вместо заражения
- **При накоплении >40 заражения**: Пассивная регенерация, скорость восстановления праны повышена на **25%**
- **При накоплении >70 заражения**: Начинает заражать мягкие блоки под ногами мицелием
- **Получение урона**: Тратит набранное заражение (**1 ед. за каждые 3 полученных урона**)
- **При зараженности <10**: Получает ![Медлительность](/assets/items/slowness.png) Медлительность и ![Слабость](/assets/items/weakness.png) Слабость
- **При зараженности = 0**: Получает ![Иссушение](/assets/items/wither_effect.png) Иссушение

**Особенности блоков:**
- Поломанные блоки травы/грязи/земли/тропинок/подзола **без шелкового касания**: 50% шанс выпасть как мицелий
- Установка тех же блоков: 50% шанс быть поставленными как мицелий

::: warning Важно
Съеденная растительная пища все также болезненно выводит из организма споры, даже у Спорового тела.
:::

**Уязвимости:**
- Урон от электричества, огня, иссушения увеличен на **50%**

::: tip Совет
Споровое тело позволяет активно распространять мицелий и накапливать зараженность для получения пассивной регенерации. Управляйте уровнем зараженности, чтобы избежать негативных эффектов при низких значениях.
:::
